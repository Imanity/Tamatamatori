# Tamatamatori

摄影规划 Web App：通过地图选择机位和视角，设置时间与镜头参数，预览地面、天空和可选天文信息。

当前具备 P2 地形与时间天空，进入 P3 日月构图辅助，使用 React + TypeScript + Vite + MapLibre GL JS + Astronomy Engine。

已编写地图大栏、右侧预览与参数的工作区；分隔条可拖动调整大小，面板标题把手可拖动交换位置，也可使用位置下拉框操作。重置布局不会修改拍摄计划。窄屏使用面板标签切换。

核心参数共用同一份拍摄计划：机位、方向、焦距、传感器与画幅共同更新地图水平视场和三维取景框；预览可拖动调整拍摄方向。时间按显式时区与 UTC 转换，切换时区或机位保留实际时刻。

地图使用 OpenFreeMap Liberty 底图；拍摄预览以 Mapterhorn DEM 渲染实际山体，以 OpenMapTiles 的水体边界显示静态水面。相机由机位高程加离地高度定位，匹配朝向、俯仰、焦距和横竖幅。天空、地表明暗和坡面光照随拍摄时刻变化；太阳、月亮按角尺寸叠加，月相随时刻与观察方向变化。其他天文图层仍标记为“规划中”。布局、浏览状态、图层和计划在刷新后恢复默认值。

## 本地运行

需要 Node.js 22.18 或更新版本。首次安装及启动：

```sh
npm ci
npm run dev
```

打开终端输出的 Local 地址；默认端口为 5173，已占用时 Vite 会自动选择其他端口。

桌面拖动分隔条调整大小；聚焦分隔条后可用方向键、Shift + 方向键、Home/End 操作。面板位置下拉框提供拖拽的键盘替代路径。

## 地图操作

- 默认浏览，点击地图空白不改变机位或朝向。“放置机位”按钮启用一次选点，放置后自动回到浏览；再次点按钮或在地图中按 Escape 取消。
- “定朝向”同样启用一次目标点选择；也可直接拖动绿色方向把手。拖动机位和方向把手时，参数及扇形在手势过程中连续更新。
- 平移、缩放和旋转只改变地图浏览状态。右键拖动或双指旋转地图，机位与扇形仍保持其地理方向；通过方向把手、预览拖动或方位角输入修改拍摄方向。
- 缩放过程逐帧重算扇形，定位与全球视图采用平滑过渡。预览可拖动调整方位和俯仰，也可聚焦取景框后使用方向键，按 Shift 加速；此操作不改变机位。
- “回到机位”定位当前拍摄位置；“全球视图”方便浏览其他地区。经纬度、方位角和俯仰角仍可在参数区输入。
- 地图扇形只表示水平视场角，示意长度随缩放变化，不表示实际拍摄距离或地形遮挡。
- 底图加载失败或图形环境无法启动时显示提示，可重试；参数编辑继续可用。

当前底图及平面投影的纬度范围约为 ±85.05°。更高纬度可在参数中输入并保留，地图会提示限制，不把机位移动到别的位置；极区完整选点能力仍待后续验证。

默认底图无需密钥，但需要网络访问 OpenFreeMap；保留地图内署名。可复制 `.env.example` 为 `.env.local` 并设置 `VITE_MAP_STYLE_URL` 替换样式，随后重启开发服务。`VITE_` 配置对浏览器公开，不可放保密凭据；自定义提供方需自行匹配许可、覆盖和署名。

## 时间与镜头

时间滑杆在当前日期和时区内按 00:00—23:59 调整，步长一分钟，与日期时间输入同步。遇到夏令时重复或跳过的钟点时保留原时刻并提示。

焦距数字输入与滑杆支持 8—1000 mm；横幅/竖幅与画幅比例独立设置。竖幅会交换有效成像宽高，同时更新预览宽高比和地图水平视场。

## 山体与水体预览

- 移动机位后先读取对应 DEM 高程，再建立摄影相机；等待时隐藏旧机位画面，避免位置错配。相机离地高度支持 0.1—100 米。
- 山体采用实际高程、地表参考色和地形阴影；地形不夸大。拖动预览、改变镜头或画幅会更新相机，保持机位不变。
- 湖泊、海洋和河流按水体边界显示静态颜色，水面贴附当前 DEM，高程仅为近似；尚未做独立水平水位校准、潮汐、波纹或倒影。
- 本轮使用基础级 DEM（瓦片上限 z12）；近景、岸线接缝、地形缺失区域及长焦细节需要进一步核对，不承诺建筑或植被遮挡。
- 高程、地形或水体请求失败时提供重试，不用零高程替代缺失数据。预览同样受约 ±85.05° 覆盖限制。
- 数据来源署名位于取景框外。`.env.example` 提供地形与水体 TileJSON 配置；替换来源需要匹配 Terrarium / OpenMapTiles 格式，并同步核对覆盖、许可与署名。

时间滑杆同时更新天空、地平线、远景雾、地表及水体明度；坡面阴影方向由太阳方位驱动。模型使用机位与 UTC 时刻计算太阳几何高度，区分白昼、低角度日照、三种暮光与夜间，切换显示时区不改变结果。夜间保留构图参考明度；这是晴空近似，不模拟天气、真实曝光、月光、星空或地形投影阴影，也不判断太阳是否被山体遮挡。

## 太阳与月亮

- 侧栏独立开关控制日月构图叠加，关闭太阳不关闭基础天空或地形光照；银河、深空天体与空间站继续标为“规划中”。
- 日月圆盘按测站距离和摄影视场显示角尺寸，不设置最小像素大小；长焦会放大圆盘，横竖幅正确裁切。月亮亮区与方向由日月关系决定，轮廓与名称是构图辅助，不是月面照片。
- 状态区分“已关闭”“地平线下”“视场外”“画面内”和计算失败。主动点击“朝向”仅调整方位与俯仰，不改变机位、时间或镜头；地平线下禁用居中。
- 日月目前以 SVG 叠加，**地形遮挡未校验，可能覆盖山体**；不能据此判定可见、日出日落、日月食或实拍亮度。不模拟大气折射、月面纹理与地照。天文观测高度暂取参考椭球面 0 m，未混入基准未核定的 DEM 高程。
- Astronomy Engine 本地计算，不请求在线星历；完整许可随应用提供，见[第三方许可](THIRD_PARTY_NOTICES.md)。

## 验证

```sh
npm test
npm run test:terrain
npm run build
```

[GitHub Actions CI](.github/workflows/ci.yml) 在推送到 `main`、创建或更新 PR 时运行，也可手动触发。使用 Node.js 22.18.0 和 24 分别执行 `npm ci`、`npm test` 和 `npm run build`；构建已包含类型检查。CI 不执行真实浏览器或 GPU 画面验收。

69 项自动检查覆盖既有交互、地形加载、日月位置、完整三维投影与昼夜配色。日月对照离线 JPL Horizons 样本与 USNO 月相时刻；真实 SDK 相机覆盖广角、长焦、竖幅和天顶投影，组件检查开关与朝向不改变其他计划参数。既有相机校准保留 132 组配置、276 个投影采样及 12 组瓦片覆盖回归，新增日月方向的 72 组相机配置。组件测试使用 JSDOM 与地图 SDK 测试替身，数据加载测试使用合成像素；这些检查不模拟 WebGL 或浏览器图像解码。构建包含 TypeScript 检查，并独立打包地图 Worker。

Chrome 连接已恢复，三组固定场景完成基础 GPU 画面检查，覆盖镜头、画幅、布局、窄屏恢复和覆盖提示，并修复长焦及水平视角引发的瓦片越界。山峰投影精度、网格防碰撞后的相机高度、真实网络失败恢复及触屏设备仍有待验项；湖岸长焦存在岸线锯齿与接缝限制，详见验收记录。

时间天空已在 Chrome 对同一富士山机位的正午、暮光、夜间画面验收，并检查快速调时、时区切换、竖幅与窄屏恢复；截图与边界见[时间天空验收](docs/plan/time-sky-validation.md)。

日月已在 Chrome 检查太阳与山体广角构图、太阳与月亮长焦、月相、独立开关、时区、竖幅与窄屏；截图与待验边界见[日月验收](docs/plan/sun-moon-validation.md)。
