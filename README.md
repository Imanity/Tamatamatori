# Tamatamatori

摄影规划 Web App：通过地图选择机位和视角，设置时间与镜头参数，预览地面、天空和可选天文信息。

当前具备 P2 地形与时间天空，P3 已接入日月、亮星、金木星、银河及 8 个深空目标构图辅助，使用 React + TypeScript + Vite + MapLibre GL JS + Astronomy Engine。

已编写地图大栏、右侧预览与参数的工作区；分隔条可拖动调整大小，面板标题把手可拖动交换位置，也可使用位置下拉框操作。重置布局不会修改拍摄计划。窄屏使用面板标签切换。

核心参数共用同一份拍摄计划：机位、方向、焦距、传感器与画幅共同更新地图水平视场和三维取景框；预览可拖动调整拍摄方向。时间按显式时区与 UTC 转换，切换时区或机位保留实际时刻。

地图使用 OpenFreeMap Liberty 底图；拍摄预览以 Mapterhorn DEM 渲染实际山体，以 OpenMapTiles 的水体边界显示静态水面。相机由机位高程加离地高度定位，匹配朝向、俯仰、焦距和横竖幅。天空、地表明暗和坡面光照随拍摄时刻变化；太阳、月亮按角尺寸叠加，月相随时刻与观察方向变化。星空、银河与深空轮廓提供构图参考；空间站仍标记为“规划中”。布局、浏览状态、图层和计划在刷新后恢复默认值。

## 本地运行

需要 Node.js 22.18 或更新版本。首次安装及启动：

```sh
npm ci
npm run dev
```

打开终端输出的 Local 地址；默认端口为 5173，已占用时 Vite 会自动选择其他端口。

MapLibre 固定为 6.16.0，`npm ci` 自动应用地形 LOD、空间投影与深度补丁。Vite 启动和构建时会再次校验并同步补丁；开发期间修改补丁或共享着色器会自动重启服务、切换预构建缓存，避免继续使用旧版 SDK。升级 SDK 时必须重新验证补丁与覆盖回归，详见[远山地形细节](docs/architecture/terrain-detail.md)和[空间投影](docs/architecture/terrain-perspective.md)。

桌面拖动分隔条调整大小；聚焦分隔条后可用方向键、Shift + 方向键、Home/End 操作。面板位置下拉框提供拖拽的键盘替代路径。

## 地图操作

- 默认浏览，点击地图空白不改变机位或朝向。“放置机位”按钮启用一次选点，放置后自动回到浏览；再次点按钮或在地图中按 Escape 取消。
- “定朝向”同样启用一次目标点选择；也可直接拖动绿色方向把手。拖动机位和方向把手时，参数及扇形在手势过程中连续更新。
- 平移、缩放和旋转只改变地图浏览状态。右键拖动或双指旋转地图，机位与扇形仍保持其地理方向；通过方向把手、预览拖动或方位角输入修改拍摄方向。
- 缩放过程逐帧重算扇形，定位与全球视图采用平滑过渡。预览可拖动调整方位和俯仰，也可聚焦取景框后使用方向键，按 Shift 加速；此操作不改变机位。
- “回到机位”定位当前拍摄位置；“全球视图”方便浏览其他地区。经纬度、方位角和俯仰角仍可在参数区输入。
- 地图扇形只表示水平视场角，示意长度随缩放变化，不表示实际拍摄距离或地形遮挡。
- 底图加载失败或图形环境无法启动时显示提示，可重试；参数编辑继续可用。

当前底图及平面投影的纬度范围约为 ±85.05°。更高纬度可在参数中输入并保留，地图会提示限制，不把机位移动到别的位置；极区完整选点能力仍待后续验证。

默认底图无需密钥，但需要网络访问 OpenFreeMap；保留地图内署名。可复制 `.env.example` 为 `.env.local` 并设置 `VITE_MAP_STYLE_URL` 替换样式，随后重启开发服务。`VITE_` 配置对浏览器公开，不可放保密凭据；自定义提供方需自行匹配许可、覆盖和署名。

## 时间与镜头

时间滑杆在当前日期和时区内按 00:00—23:59 调整，步长一分钟，与日期时间输入同步。遇到夏令时重复或跳过的钟点时保留原时刻并提示。

焦距数字输入与滑杆支持 8—1000 mm；横幅/竖幅与画幅比例独立设置。竖幅会交换有效成像宽高，同时更新预览宽高比和地图水平视场。

## 山体与水体预览

- 移动机位后先读取对应 DEM 高程，再建立摄影相机；等待时隐藏旧机位画面，避免位置错配。相机离地高度支持 0.1—100 米。
- 山体采用实际高程、地表参考色和地形阴影；地形不夸大。拖动预览、改变镜头或画幅会更新相机，保持机位不变。
- 湖泊、海洋和河流按水体边界显示静态颜色，水面贴附当前 DEM，高程仅为近似；尚未做独立水平水位校准、潮汐、波纹或倒影。
- 本轮使用基础级 DEM（瓦片上限 z12）；近景、岸线接缝、地形缺失区域及长焦细节需要进一步核对，不承诺建筑或植被遮挡。
- 长焦按实际视场和取景框细化地形网格，下载与绘制采用同一策略；最高网格 z14，不新增原生 DEM 分辨率。远山不再因默认浏览策略在长焦下反而使用过粗数据。
- 引擎近地避让可能抬高眼点并改变俯仰。预览使用实际相机姿态同步日月与读数，发生明显调整时显示实际高度和角度；参数、地图保留拍摄计划，机位高程与实际离地均为 DEM 近似。
- 高程、地形或水体请求失败时提供重试，不用零高程替代缺失数据。预览同样受约 ±85.05° 覆盖限制。
- 数据来源署名位于取景框外。`.env.example` 提供地形与水体 TileJSON 配置；替换来源需要匹配 Terrarium / OpenMapTiles 格式，并同步核对覆盖、许可与署名。

时间滑杆同时更新天空、地平线、远景雾、地表及水体明度；坡面阴影方向由太阳方位驱动。模型使用机位与 UTC 时刻计算太阳几何高度，区分白昼、低角度日照、三种暮光与夜间，切换显示时区不改变结果。无月深夜保留可辨的山脊与天空；月亮亮面越大、位置越高，夜间环境越亮，月亮落到几何地平线下后不再提亮。日月图层开关只控制圆盘，环境保持。晴空与月光属于构图近似，不模拟天气、真实曝光或地形投影阴影。

## 太阳与月亮

- 侧栏独立开关控制日月构图叠加，关闭太阳不关闭基础天空或地形光照；星空、银河与深空使用各自开关，空间站继续标为“规划中”。
- 日月在参考地平线上且完全位于视场外时，取景框边缘显示名称与方向箭头；相机后方标注“后方”。小预览在上缘并排显示，目标入画、落到地平线下或关闭图层后隐藏；箭头不代表画外目标一定可见。
- 日月圆盘按测站距离和摄影视场显示角尺寸，不设置最小像素大小；长焦会放大圆盘，横竖幅正确裁切。月亮亮区与方向由日月关系决定，轮廓与名称是构图辅助，不是月面照片。
- 日月在预览的三维图层中共享地形深度，圆盘与辅助轮廓按山体裁切。状态区分当前 DEM 未遮挡、部分或完全山体遮挡，以及关闭、地平线下、视场外、遮挡待测、像素不足和失败；未加载的数据不会被当成无遮挡。
- 参数区可切换默认的“标准折射 · 海平面近似”和“无折射 · 几何位置”。折射逐点作用于圆盘与月相轮廓，表达近地平线的竖向压扁；读数同时显示视高度与几何高度。“朝向”采用视高度，仅修改拍摄方向。
- 遮挡只依据当前已加载的 DEM，不包含建筑、植被或全部远地形；标准折射使用固定参考大气，不含实测天气或海拔密度修正。不能据此保证实际可见、日出日落、触山时刻或实拍亮度。不模拟月面纹理、地照与日月食；天文观测高度暂取参考椭球面 0 m，未混入基准未核定的 DEM 高程。
- Astronomy Engine 本地计算，不请求在线星历；完整许可随应用提供，见[第三方许可](THIRD_PARTY_NOTICES.md)。

## 星空与银河

勾选“星空”绘制 925 颗亮星和金星、木星，标注 90 个主要恒星名称及金木星，89 个恒星有中文名称。勾选“银河”绘制随地点和时间转动的亮云与暗尘细节，并用空心环标识银心方向。细节采用随应用提供的 ESO/S. Brunier 全天全景衍生纹理，首次开启按需加载；失败可关闭再开启重试，不影响地形和其他天体。“星空目标与朝向”可展开查看状态并主动朝向主要目标；参考折射、实际相机和 DEM 遮挡沿用现有约定，名称不会穿过山体。

星点与银河按暮光、月亮亮面比例和几何高度调整对比度，暗星比亮星更早淡出，白昼隐藏星点与银河轮廓。银心空心环仍保留为方向参考。主要目标的“天空较亮”与“山体遮挡”分别反馈，关闭月亮圆盘不关闭月光影响。

开启银河后，开关下可调节 25%—200% 的银河显示对比度，默认 100%，支持键盘和一键重置。关闭再开启保留数值；调节只影响银河外观，仍受暮光、月光和地形遮挡影响，不改变其他拍摄参数或重新加载纹理。

星点大小、颜色、显示阈值和银河明暗均为构图近似；全景未经精密天文/光度定标，不能将纹理细节视作精确目标位置，不保证肉眼/白昼可见性或实拍效果，不含曝光、光污染和天气。恒星目录采用 HYG v4.1 的本地子集，保留 CC BY-SA 4.0 许可、作者和下载。银河衍生图保留 CC BY 4.0 许可与 ESO/S. Brunier 署名。模型及验证见[星空架构](docs/architecture/starfield.md)、[初始验收](docs/plan/starfield.md)、[明暗验收](docs/plan/starfield-appearance.md)与[银河细节](docs/plan/milky-way-detail.md)。

## 深空天体与相机响应

勾选“深空天体”显示 M31、M42、M45、M8、北美、加州、心脏和灵魂星云，可搜索中文名或 M/NGC/IC 编号并主动朝向。轮廓跟随时间、机位、镜头与参考折射，接受 DEM 的部分或全部遮挡；名称的中心被山体挡住时隐藏。

相机参数中的“深空相机响应”区分未改机近似参考与天文改机（Hα 增强示意）。普通模式保留红色，改机额外增强红光结构，M31/M45 不统一染红。两模式沿用处理后的源图，非同机型实拍对比；核查与已修正的反向色偏见[色彩审计](docs/plan/deep-sky-colour-audit.md)。现有八个目标均接入影像结构：M31/M42/M45/M8/北美/加州使用 AVM 资料，心脏/灵魂使用有固定四角天球坐标的去星资料。按完整可用覆盖投影，右栏标明“影像结构参考”，署名保留各自许可。没有椭圆裁切和假外壳；原始覆盖、分辨率和处理仍有限，不是实测 Hα、具体机型或曝光预测。当前接入及验收见[剩余目标](docs/plan/deep-sky-remaining.md)，此前细节与边界修正见[长焦清晰度](docs/plan/deep-sky-sharpness.md)、[边界融合](docs/plan/deep-sky-boundary.md)与[模型说明](docs/architecture/deep-sky.md)。

## 星座与拍摄信息栏

“星座名称与连线”默认关闭，开启后显示 88 星座的参考连线与名称（巨蛇座分为两片），可独立于星点显示。连线端点使用同一 HYG 星历模型，接受参考折射、地平线与 DEM 遮挡；参考线在白昼也可显示，不是实际发光或星座边界。名称以图形端点的球面中心定位。

右侧“拍摄信息”集中展示原先预览下方的视场、实际姿态、光照、日月、星空与近似说明，保留主动朝向操作；版权署名仍在预览区。侧栏可收起，窄屏通过“拍摄信息”打开抽屉。面板交换与预览/参数默认 2:1 保留。数据来源、许可和执行证据见[本轮验收](docs/plan/constellations-and-info.md)。

## 目标搜索

右侧“搜索目标”支持中文名、图录原名、HIP 编号、星座缩写和英文名，例如“织女星”“Vega”“Ori”。查询不改变构图；未开启的目标提供明确的“开启并朝向”操作，地平线下只开启图层。清除恢复完整信息，收起/交换面板保留查询。

在线访问：[Tamatamatori](https://imanity.github.io/Tamatamatori/)。用户已授权公开仓库，Pages 使用 GitHub Actions 发布，`PAGES_ENABLED=true`；之后推送 `main` 会在测试与构建通过后自动更新。首次私有仓库的套餐限制与实际上线验收见[搜索与 Pages](docs/plan/search-and-pages.md)。

## 验证

```sh
npm test
npm run test:terrain
npm run build
```

[GitHub Actions CI](.github/workflows/ci.yml) 在推送到 `main`、创建或更新 PR 时运行，也可手动触发。使用 Node.js 22.18.0 和 24 分别执行 `npm ci`、`npm test` 和 `npm run build`；构建已包含类型检查。CI 不执行真实浏览器或 GPU 画面验收。

158 项自动检查覆盖既有交互、地形加载、日月位置、完整三维投影与昼夜配色，以及星空暮光/月光淡出、白昼隐藏与独立几何查询、逐点折射、异步遮挡查询、过期结果、超时和资源释放，并覆盖 32 组深空 ERFA 方向、扩展轮廓双深度查询、未改机/Hα 响应切换、缓存视野恢复，以及银河纹理按需加载、失败隔离、取消/迟到资源及 GL 状态恢复。亮星、银河与银心对照 54 组独立 ERFA 方向，金木星另对照 4 组 JPL Horizons；日月对照既有 JPL 样本与 USNO 月相时刻；真实 SDK 相机覆盖广角、长焦、竖幅和天顶投影，组件检查开关与朝向不改变其他计划参数。既有相机校准保留 132 组配置、276 个投影采样及 12 组瓦片覆盖回归，日月方向另有 72 组相机配置。组件测试使用 JSDOM 与地图 SDK 测试替身，数据加载测试使用合成像素，GL 查询测试使用替身；这些检查不代替真实 WebGL 画面。构建包含 TypeScript 检查，并独立打包地图 Worker。

Chrome 连接已恢复，三组固定场景完成基础 GPU 画面检查，覆盖镜头、画幅、布局、窄屏恢复和覆盖提示，并修复长焦及水平视角引发的瓦片越界。山峰投影精度、网格防碰撞后的相机高度、真实网络失败恢复及触屏设备仍有待验项；湖岸长焦存在岸线锯齿与接缝限制，详见验收记录。

时间天空已在 Chrome 对同一富士山机位的正午、暮光、夜间画面验收，并检查快速调时、时区切换、竖幅与窄屏恢复；截图与边界见[时间天空验收](docs/plan/time-sky-validation.md)。

日月已在 Chrome 检查太阳与山体广角构图、太阳与月亮长焦、月相、独立开关、时区、竖幅与窄屏；截图与待验边界见[日月验收](docs/plan/sun-moon-validation.md)。

当前三维日月图层另在 Chrome 验证太阳的完整露出、部分山体裁切与完全遮挡，并检查标准/无折射对照、长焦月相和横竖幅、窄屏恢复；截图与精度边界见[遮挡与折射验收](docs/plan/occlusion-refraction-validation.md)。

相机校准已保存 13 组真实 DEM 与公开绘制矩阵测量，覆盖 8—1000 mm 和 0.1/1.6/10 m；修复了引擎避让后地形与日月姿态不一致的问题。新增 24 组 SDK 数值配置，测量与仍未通过的实景精度边界见[相机校准](docs/plan/camera-calibration.md)。

[曲率对照](docs/plan/curvature-validation.md)建立独立 PROJ 基准后，[空间投影修正](docs/plan/terrain-perspective.md)已将实际网格的 WGS84/ENU 投影与对数深度接入默认预览，地形、水体和日月共用方向与深度；真实 GPU 固定点投影残差小于 0.001 CSS px。可继续接入其他天体，但不将该数值称为实景精度。

[高程基准核查](docs/plan/elevation-datum-audit.md)已确认现有上游声明与覆盖索引不足以启用统一自动转换，保存了有界联网审计与合成高度敏感度结果。当前默认曲面构图沿用明确的同源高度假设，正式实景精度能力仍需满足[高度基准准入条件](docs/architecture/elevation-datum.md)。
