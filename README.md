# Tamatamatori

天气支持按机位读取 Open-Meteo 七天逐小时预报，右栏“光照与环境”组提供光污染、天气与预测模型设置，并影响日月星空。选“自动匹配”时选项后标注拍摄时刻的云量来源模型（如日本气象厅 JMA，按逐小时云量与各候选模型比对识别）。天气先给晴朗、少云、多云或阴天与降水概率，分层云量与能见度在详细数值中，来源归入 About。云块位置与透光为显示近似，免费天气服务仅限非商业用途。范围与验证见[天气首步](docs/plan/weather.md)和[环境优化](docs/plan/environment-refinement.md)。

已接入巴纳德环 Sh2-276 和蛇夫座星云复合体的影像、搜索与朝向，两模式和地形遮挡共享当前预览流程。宽幅资料按公开四角拼接，并展示原生分辨率及亮度模型说明。[实施与验收](docs/plan/wide-clouds.md)

火树星云 NGC2024 已接入搜索与朝向，与马头共享一次影像绘制并单独判断地形遮挡。马头暗区对近似夜空的压暗已减弱，原始影像分辨率与器材色彩限制继续保留。[本轮记录](docs/plan/horsehead-flame.md)

摄影规划 Web App：通过地图选择机位和视角，设置时间与镜头参数，预览地面、天空和可选天文信息。

当前具备 P2 地形与时间天空，P3 已接入日月、亮星、金木星、银河及 15 个深空目标构图辅助，使用 React + TypeScript + Vite + MapLibre GL JS + Astronomy Engine。

页头“机位”按钮保存、切换、分享与导入机位：机位包含位置、方向、镜头、时间、时区、图层与环境设置，应用后画面与保存时相同（天气、空间站按当时数据）；分享使用 `tmt1:` 分享码，刷新页面恢复上次工作状态，数据只存于本浏览器。[机位保存与分享](docs/plan/shot-presets.md)

工作区为地图与预览左右两块，不再有独立的参数栏：机位坐标、方位与俯仰（经纬度下一行）和离地高度在地图下方，镜头、画幅与拍摄时间在预览下方。没有左栏：图层开关在右栏各分组的标题行，开启时就地展开该组（不滚动）、关闭时折叠，组内子设置放在缩进的浅色块里；首组“光照与环境”默认展开，含光污染、天气、预测模型与大气折射；深空相机响应在深空分组。右栏先写结论（状态、方向与高度），精确数值和模型口径在“显示详细数值”开启后出现，该开关只保存在本浏览器。分隔条可拖动调整宽度，面板标题的对调按钮交换左右位置。窄屏让预览与时间轴常驻上方，下方以“地图 / 相机 / 图层”标签切换，预览可双指捏合调焦。[工作区交互改版](docs/plan/workspace-redesign.md)

核心参数共用同一份拍摄计划：机位、方向、焦距、传感器与画幅共同更新地图水平视场和三维取景框；预览可拖动调整拍摄方向。时间按显式时区与 UTC 转换，切换时区或机位保留实际时刻。

地图使用 OpenFreeMap Liberty 底图；拍摄预览以 Mapterhorn DEM 渲染实际山体，以 OpenMapTiles 的水体边界显示静态水面。相机由机位高程加离地高度定位，匹配朝向、俯仰、焦距和横竖幅。天空、地表明暗和坡面光照随拍摄时刻变化；太阳、月亮按角尺寸叠加，月相随时刻与观察方向变化。星空、银河与深空轮廓提供构图参考；空间站提供 ISS 与天宫的位置和短轨迹参考。刷新后恢复上次的拍摄计划（含图层与环境设置），面板布局与地图浏览状态恢复默认值。

## 本地运行

需要 Node.js 22.18 或更新版本。首次安装及启动：

```sh
npm ci
npm run dev
```

打开终端输出的 Local 地址；默认端口为 5173，已占用时 Vite 会自动选择其他端口。

MapLibre 固定为 6.16.0，`npm ci` 自动应用地形 LOD、空间投影与深度补丁。Vite 启动和构建时会再次校验并同步补丁；开发期间修改补丁或共享着色器会自动重启服务、切换预构建缓存，避免继续使用旧版 SDK。升级 SDK 时必须重新验证补丁与覆盖回归，详见[远山地形细节](docs/architecture/terrain-detail.md)和[空间投影](docs/architecture/terrain-perspective.md)。

桌面拖动分隔条调整地图与预览的宽度；聚焦分隔条后可用方向键、Shift + 方向键、Home/End 操作。对调按钮只改变排列，地图与预览不会重新加载。

## 地图操作

- 默认浏览，点击地图空白不改变机位或朝向。“放置机位”按钮启用一次选点，放置后自动回到浏览；再次点按钮或在地图中按 Escape 取消。
- “定朝向”同样启用一次目标点选择；也可直接拖动绿色方向把手。拖动机位和方向把手时，参数及扇形在手势过程中连续更新。
- 平移、缩放和旋转只改变地图浏览状态。右键拖动或双指旋转地图，机位与扇形仍保持其地理方向；通过方向把手、预览拖动或方位角输入修改拍摄方向。
- 缩放过程逐帧重算扇形，定位与全球视图采用平滑过渡。预览可拖动调整方位和俯仰，也可聚焦取景框后使用方向键，按 Shift 加速；此操作不改变机位。
- “回到机位”定位当前拍摄位置；“全球视图”方便浏览其他地区。经纬度可在地图下方的机位条输入（粘贴“纬度, 经度”可一次填入），方位角和俯仰角可在预览上方输入。
- 地图扇形只表示水平视场角，示意长度随缩放变化，不表示实际拍摄距离或地形遮挡。
- 底图加载失败或图形环境无法启动时显示提示，可重试；参数编辑继续可用。

当前底图及平面投影的纬度范围约为 ±85.05°。更高纬度可在机位条中输入并保留，地图会提示限制，不把机位移动到别的位置；极区完整选点能力仍待后续验证。

默认底图无需密钥，但需要网络访问 OpenFreeMap；保留地图内署名。可复制 `.env.example` 为 `.env.local` 并设置 `VITE_MAP_STYLE_URL` 替换样式，随后重启开发服务。`VITE_` 配置对浏览器公开，不可放保密凭据；自定义提供方需自行匹配许可、覆盖和署名。

## 时间与镜头

显示时区默认为“当地时区”，按机位坐标查询并随机位变化（边境与海上可能不准，新疆返回 UTC+6 的乌鲁木齐时间）；也可固定为任意 IANA 时区，支持中文城市、英文、IANA 名称与 UTC 偏移搜索，偏移按拍摄时刻显示。时间滑杆步长一分钟，与日期时间输入同步：平时覆盖所选日期 00:00—24:00，开启星空、银河、深空、流星雨或彗星后改为中午到次日中午。滑杆背后色带为太阳高度，开启天气时其下有逐小时云量条；上方刻度只标注已开启图层的事件（日出日落、月出月落、暗夜起止、银心、流星辐射点、最亮彗星、空间站可见过境），点击跳转，也可用“上一事件 / 下一事件”。出没按海平面地平计算，不含地形遮挡。日期可前后一天，另有 ±1 分、±10 分、±1 时与“现在”微调；遇到夏令时重复或跳过的钟点时保留原时刻并提示。

焦距数字输入与对数滑杆支持 8—1000 mm，滑杆下方的常用焦距刻度可直接点选，预览中滚轮或双指捏合也可调焦；横幅/竖幅与画幅比例独立设置。竖幅会交换有效成像宽高，同时更新预览宽高比和地图水平视场。

## 山体与水体预览

- 移动机位后读取对应 DEM 高程，再建立摄影相机。等待期间保留上一有效画面，高程信息显示待更新，持续等待后提示暂留旧画面。相机离地高度支持 0.1—100 米，可输入或用对数滑条调整。
- 山体采用实际高程、地表参考色和地形阴影；地形不夸大。拖动预览、改变镜头或画幅会更新相机，保持机位不变。
- 湖泊、海洋和河流按水体边界显示静态颜色，水面贴附当前 DEM，高程仅为近似；尚未做独立水平水位校准、潮汐、波纹或倒影。
- 本轮使用基础级 DEM（瓦片上限 z12）；近景、岸线接缝、地形缺失区域及长焦细节需要进一步核对。建筑遮挡需单独开启有限建筑图层，不包含植被或未加载的建筑。
- 长焦按实际视场和取景框细化地形网格，下载与绘制采用同一策略；最高网格 z14，不新增原生 DEM 分辨率。远山不再因默认浏览策略在长焦下反而使用过粗数据。
- 引擎近地避让可能抬高眼点并改变俯仰。预览使用实际相机姿态同步日月与读数，发生明显调整时显示实际高度和角度；参数、地图保留拍摄计划，机位高程与实际离地均为 DEM 近似。
- 高程、地形或水体请求失败时提供重试，不用零高程替代缺失数据。预览同样受约 ±85.05° 覆盖限制。
- 完整数据来源署名集中在 header 的 About，地图保留紧凑署名控件。`.env.example` 提供地形与水体 TileJSON 配置；替换来源需要匹配 Terrarium / OpenMapTiles 格式，并同步核对覆盖、许可与署名。

时间滑杆同时更新天空、地平线、远景雾、地表及水体明度；坡面阴影方向由太阳方位驱动。模型使用机位与 UTC 时刻计算太阳几何高度，区分白昼、低角度日照、三种暮光与夜间，切换显示时区不改变结果。无月深夜保留可辨的山脊与天空；月亮亮面越大、位置越高，夜间环境越亮，月亮落到几何地平线下后不再提亮。日月图层开关只控制圆盘，环境保持。晴空与月光属于构图近似，不模拟天气、真实曝光或地形投影阴影。

## 太阳与月亮

- 侧栏独立开关控制日月构图叠加，关闭太阳不关闭基础天空或地形光照；星空、银河与深空使用各自开关，空间站使用独立开关并显示轨道更新状态。
- 日月在参考地平线上且完全位于视场外时，取景框边缘显示名称与方向箭头；相机后方标注“后方”。小预览在上缘并排显示，目标入画、落到地平线下或关闭图层后隐藏；箭头不代表画外目标一定可见。
- 右侧太阳、月亮分组可开启“运行轨迹”：预览画出一次出没的中心视位置连线和当地整点标记，山体或建筑后方为淡色虚线，地平线下不画；整点标注不判断遮挡。[日月运行轨迹](docs/plan/sun-moon-paths.md)
- 日月圆盘按测站距离和摄影视场显示角尺寸，不设置最小像素大小；长焦会放大圆盘，横竖幅正确裁切。月亮亮区与方向由日月关系决定，轮廓与名称是构图辅助，不是月面照片。
- 日月在预览的三维图层中共享地形深度，圆盘与辅助轮廓按山体裁切。状态区分当前 DEM 未遮挡、部分或完全山体遮挡，以及关闭、地平线下、视场外、遮挡待测、像素不足和失败；未加载的数据不会被当成无遮挡。
- 右栏“光照与环境”组可切换默认的“标准折射 · 海平面近似”和“无折射 · 几何位置”。折射逐点作用于圆盘与月相轮廓，表达近地平线的竖向压扁；详细数值同时显示视高度与几何高度。“朝向”采用视高度，仅修改拍摄方向。
- 遮挡依据当前已加载的 DEM 及已开启、加载成功的建筑图层，不包含植被、缺失建筑或全部远地形；标准折射使用固定参考大气，不含实测天气或海拔密度修正。不能据此保证实际可见、日出日落、触山时刻或实拍亮度。不模拟月面纹理、地照与日月食；天文观测高度暂取参考椭球面 0 m，未混入基准未核定的 DEM 高程。
- Astronomy Engine 本地计算，不请求在线星历；完整许可随应用提供，见[第三方许可](THIRD_PARTY_NOTICES.md)。

## 流星雨

“流星雨”图层显示拍摄日期处于 IMO 2026 工作表活动期的流星雨辐射点。右栏分组可开启“预估密度”，按拍摄时刻所在的整晚（天文暗夜）累计：预览按固定机位整晚拍摄、再把流星对齐到拍摄时刻星空叠加的成片画出示意流星（都从辐射点发散），并估算画面内约多少颗。估算计入辐射点高度、活动曲线、月光和光污染，假定相机能记录亮于约 +2 等的流星；结果是量级参考，示意流星不代表实际位置。IMO 数据未获明示许可，按署名摘录。[流星雨计划](docs/plan/meteor-showers.md)

## 彗星

“彗星”图层绘制拍摄时刻亮于 12 等的收录彗星：彗核、笔直的离子尾和弯曲的尘埃尾，并在右栏列出星等、彗尾长度和“朝向”。目录收录 1990 年起 COBS 目视星等夜间中位最亮不暗于 10 等的回归，作为站点静态文件 `comets/catalog.json` 在开启图层时读取。CI 每 3 小时增量更新一次：观测期未结束的回归重新拟合，新达到条件的彗星加入，周期彗星的新回归与旧回归并存；失败时沿用原目录并暂停，需在手动运行 CI 时勾选 `resume_comets` 恢复。手动全量处理用 `npm run update:comets -- --full`。轨道取 JPL Horizons 近日点密切根数，按二体推算；亮度按 COBS 目视观测拟合，彗尾物理长度用 Kammerer 经验公式，再按日、彗、地的实际位置投影，按暗夜长曝光口径显示，天空变亮时末端变淡、可见长度缩短。亮度常有 1 等以上出入，不预测爆发。COBS 衍生数据为 CC BY-NC-SA 4.0，仅限非商业使用。[彗星计划](docs/plan/comets.md)

## 星空与银河

勾选“星空”绘制 925 颗亮星和金星、木星，标注 90 个主要恒星名称及金木星，89 个恒星有中文名称。勾选“银河”绘制随地点和时间转动的亮云与暗尘细节，并用空心环标识银心方向。细节采用随应用提供的 ESO/S. Brunier 全天全景衍生纹理，首次开启按需加载；失败可关闭再开启重试，不影响地形和其他天体。“星空目标与朝向”可展开查看状态并主动朝向主要目标；参考折射、实际相机和 DEM 遮挡沿用现有约定，名称不会穿过山体。

星点与银河按暮光、月亮亮面比例和几何高度调整对比度，暗星比亮星更早淡出，白昼隐藏星点与银河轮廓。银心空心环仍保留为方向参考。主要目标的“天空较亮”与“山体遮挡”分别反馈，关闭月亮圆盘不关闭月光影响。

右侧银河分组提供 25%—200% 的显示对比度，默认 100%，支持键盘和一键重置。关闭图层时滑杆禁用并保留数值。调节只影响银河外观，仍受暮光、月光和地形遮挡影响。

星点大小、颜色、显示阈值和银河明暗均为构图近似。全景作为结构参考，天空明暗不含曝光与天气。恒星目录采用 HYG v4.1 的本地子集，保留 CC BY-SA 4.0 许可、作者和下载。银河衍生图保留 CC BY 4.0 许可与 ESO/S. Brunier 署名。模型及验证见[星空架构](docs/architecture/starfield.md)、[初始验收](docs/plan/starfield.md)、[明暗验收](docs/plan/starfield-appearance.md)与[银河细节](docs/plan/milky-way-detail.md)。

构图线右侧的“当地光污染”默认关闭，开启后按机位使用 World Atlas 2015 的天顶人工亮度，调整夜空、暗星、银河与深空云气的显示对比度。图集为约 2.8 km 的历史模型，覆盖约南纬 60° 至北纬 75°，失败及无覆盖时明确提示。数据与衍生分块采用 CC BY-NC 4.0，仅限非商业使用，来源和下载统一在 About。[光污染验收](docs/plan/light-pollution.md)

## 建筑体块

左侧“建筑”默认关闭，开启后读取机位周边约 5 km 的简化体块：2 km 内普通建筑候选，2–5 km 优先显示源高度至少 20 m 的建筑，并参与地形与天体遮挡。右侧建筑分组显示加载进度条、实际加载范围、附近地标精模（距离、状态与一键朝向），并提供独立重试；密集地区或高纬触及预算时明确提示覆盖不完整。高度可能由层数推算或缺省生成，屋顶、坡地基座和瓦片接缝为近似，远处未加载建筑不属于可见性保证。当前范围、缓存优化与验收状态见[建筑远景](docs/plan/building-distance.md)，首步历史见[建筑首步](docs/plan/buildings.md)。

晴空塔已接入首个无纹理精细地标：约 50 km 内随建筑加载，普通建筑仍限周边五公里。近处确认三处分部后替换粗体块，远处直接读取已注册模型；失败分别提示回退或无对应粗体块。模型约 1.18 MiB、88,581 面，与普通建筑共用 30 万面预算；有塔架与平台几何，定位/朝向近似，不含玻璃透光与夜景灯光。加载范围不代表一定可见。当前范围、覆盖与限制见[地标远景](docs/plan/landmark-distance.md)，来源处理见[晴空塔首步](docs/plan/skytree-landmark.md)，许可与下载集中于 About。

远距地标下方缺少地形造成的悬空间隙已修正：仅对需要的摄影预览扩展 DEM/网格覆盖，原相机、模型高度和普通地图保持原行为。固定 SDK 的兼容补丁随安装与构建校验；[地表校准记录](docs/plan/landmark-ground-calibration.md)区分覆盖、投影一致性与实际画面，仍不承诺测绘精度。

上海中心已作为第二处无纹理地标接入，约 0.93 MiB / 54,682 面，同样限约 50 km，与晴空塔及普通建筑共用 30 万面预算。逐项校验、近景替换、失败提示和 About 下载分别处理，缓存最多三份 / 8 MiB 几何字节。来源和朝向仍为近似；[扩展验收](docs/plan/landmark-expansion.md)包含 CPU 减面和真实 Chrome 画面。东京塔等待新的合格候选，尚未加入目录。

## 深空天体与相机响应

勾选“深空天体”显示 M31、M42、M45、M8、北美、加州、心脏、灵魂、M20、M33、玫瑰与马头区域。支持中文名、M/NGC/IC 编号和 B33 别名搜索，并可主动朝向。结构跟随时间、机位、镜头与参考折射，接受 DEM 的部分或全部遮挡。中心被山体挡住时隐藏名称。

相机参数中的“深空相机响应”区分未改机近似参考与天文改机 Hα 增强示意。普通模式保留基础红色，改机额外增强红光结构。M31/M33/M45 两模式保持一致。源图处理与分辨率决定参考外观的细节上限。玫瑰的源图已含 Hα 增强，信息栏明确标注。马头采用源图暗区的背景对比估计，星表恒星独立绘制。四个新目标的范围、资料与验收详见四目标记录。[四目标验收](docs/plan/deep-sky-next-four.md)，[色彩核查](docs/plan/deep-sky-colour-audit.md)

15 个目标均提供影像结构参考，使用 AVM 或固定四角坐标注册。运行时按实际视场加载 14 幅影像，深空 RGBA/mip 驻留预算为 64 MiB；故障按影像资源反馈，马头与火树继承共享状态，关闭再开启图层可重试。预览署名区提供来源、原许可及派生 PNG 下载。宽幅、长焦、相机响应与地形遮挡采用独立验收。[模型说明](docs/architecture/deep-sky.md)，[既有清晰度验收](docs/plan/deep-sky-sharpness.md)，[既有边界融合](docs/plan/deep-sky-boundary.md)

## 星座与拍摄信息栏

“星座名称与连线”默认关闭，位于右侧星空子设置，开启后显示 88 星座的参考连线与名称（巨蛇座分为两片）。关闭星空时同时关闭星座，搜索并开启星座时同时开启星空。连线端点使用同一 HYG 星历模型，接受参考折射、地平线与 DEM 遮挡。参考线在白昼也可显示，名称以图形端点的球面中心定位。

右侧“拍摄信息”集中展示原先预览下方的视场、实际姿态、光照、日月、星空与近似说明，保留主动朝向操作。版权署名集中在 header 的 About。侧栏可收起，窄屏通过“拍摄信息”打开抽屉。支持面板交换，预览与参数默认高度比为 1:1。数据来源、许可和执行证据见[本轮验收](docs/plan/constellations-and-info.md)。

## 空间站与轨道更新

开启“空间站”后显示 ISS 与天宫的拍摄时刻位置及前后各三分钟轨迹点。支持搜索、主动朝向、±1 秒与 ±10 秒调整，标记和轨迹接受实际地形深度遮挡。右侧列出日照参考、轨道历元、上游成功检查与网页检查时间。

上游 GP 数据由 GitHub Actions 计划每三小时获取，最短请求间隔两小时。网页开启相关图层或搜索后，每五分钟检查已发布快照。距轨道历元超过 24 小时提示低可信，超过 72 小时停止绘制。变轨后的可靠性取决于新轨道解发布，拍摄前应核对实际历元与检查状态。

本地可运行 `npm run update:orbits` 更新 `public/orbits/stations.json`。异常时保留有效快照并暂停自动上游请求，排查后通过手动 CI 的 `resume_orbits` 恢复，本地对应 `npm run update:orbits -- --resume`。缓存位于 `.cache/`。定时更新在本次工作流部署后启用，执行记录和边界见[空间站验收](docs/plan/space-stations.md)。

```sh
npm test

npm run build
```

[GitHub Actions CI](.github/workflows/ci.yml) 在推送到 `main`、创建或更新 PR 时运行，也可手动触发。使用 Node.js 22.18.0 和 24 分别执行 `npm ci`、`npm test` 和 `npm run build`；构建已包含类型检查。CI 不执行真实浏览器或 GPU 画面验收。

182 项自动检查覆盖既有交互、地形加载、日月位置、完整三维投影与昼夜配色，以及星空暮光/月光淡出、白昼隐藏与独立几何查询、逐点折射、异步遮挡查询、过期结果、超时和资源释放，并覆盖 60 组深空 ERFA 方向、扩展轮廓双深度查询、未改机/Hα 响应切换、缓存视野恢复，以及银河纹理按需加载、失败隔离、取消/迟到资源及 GL 状态恢复。亮星、银河与银心对照 54 组独立 ERFA 方向，金木星另对照 4 组 JPL Horizons；日月对照既有 JPL 样本与 USNO 月相时刻；真实 SDK 相机覆盖广角、长焦、竖幅和天顶投影，组件检查开关与朝向不改变其他计划参数。既有相机校准保留 132 组配置、276 个投影采样及 12 组瓦片覆盖回归，日月方向另有 72 组相机配置。组件测试使用 JSDOM 与地图 SDK 测试替身，数据加载测试使用合成像素，GL 查询测试使用替身；这些检查不代替真实 WebGL 画面。构建包含 TypeScript 检查，并独立打包地图 Worker。

Chrome 连接已恢复，三组固定场景完成基础 GPU 画面检查，覆盖镜头、画幅、布局、窄屏恢复和覆盖提示，并修复长焦及水平视角引发的瓦片越界。山峰投影精度、网格防碰撞后的相机高度、真实网络失败恢复及触屏设备仍有待验项；湖岸长焦存在岸线锯齿与接缝限制，详见验收记录。

时间天空已在 Chrome 对同一富士山机位的正午、暮光、夜间画面验收，并检查快速调时、时区切换、竖幅与窄屏恢复；截图与边界见[时间天空验收](docs/plan/time-sky-validation.md)。

日月已在 Chrome 检查太阳与山体广角构图、太阳与月亮长焦、月相、独立开关、时区、竖幅与窄屏；截图与待验边界见[日月验收](docs/plan/sun-moon-validation.md)。

当前三维日月图层另在 Chrome 验证太阳的完整露出、部分山体裁切与完全遮挡，并检查标准/无折射对照、长焦月相和横竖幅、窄屏恢复；截图与精度边界见[遮挡与折射验收](docs/plan/occlusion-refraction-validation.md)。

相机校准已保存 13 组真实 DEM 与公开绘制矩阵测量，覆盖 8—1000 mm 和 0.1/1.6/10 m；修复了引擎避让后地形与日月姿态不一致的问题。新增 24 组 SDK 数值配置，测量与仍未通过的实景精度边界见[相机校准](docs/plan/camera-calibration.md)。

[曲率对照](docs/plan/curvature-validation.md)建立独立 PROJ 基准后，[空间投影修正](docs/plan/terrain-perspective.md)已将实际网格的 WGS84/ENU 投影与对数深度接入默认预览，地形、水体和日月共用方向与深度；真实 GPU 固定点投影残差小于 0.001 CSS px。可继续接入其他天体，但不将该数值称为实景精度。

[高程基准核查](docs/plan/elevation-datum-audit.md)已确认现有上游声明与覆盖索引不足以启用统一自动转换，保存了有界联网审计与合成高度敏感度结果。当前默认曲面构图沿用明确的同源高度假设，正式实景精度能力仍需满足[高度基准准入条件](docs/architecture/elevation-datum.md)。

npm run landmarks -- inspect --input-dir C:/Users/TangRJ/Downloads
