# P1 地图接入设计

更新：2026-11-04。范围仅为真实底图、机位、方向与水平视场，不实现地形或天文预览。

## 选型与数据

- 地图引擎采用 MapLibre GL JS 6.16；BSD-3-Clause 许可，具体依赖以锁文件为准。使用 ESM，Vite 将独立 Worker 打包为本地资源；地图模块按需加载。
- 使用 OpenFreeMap 公共实例的 Liberty 样式；底层数据来自 OpenStreetMap / OpenMapTiles。无需账户或密钥，保留地图中的 OpenFreeMap、OpenMapTiles 与 OpenStreetMap 署名。
- 样式 URL 可由 `VITE_MAP_STYLE_URL` 替换。此项为浏览器公开配置，不能放保密凭据；替换提供方时需要重新检查数据许可、署名和覆盖。
- 公共服务依赖网络，不作为生产容量与可用性保证。本轮只请求用户当前浏览所需的数据，不做批量下载、离线缓存或服务代理。
- 当前采用平面 Mercator 地图，初始北向上，支持地图浏览旋转。提供方 TileJSON 报告纬度范围约为 ±85.05113°，最大原生瓦片级别为 14；更近视图属于放大显示，不保证增加地理细节。
- 计划本身保留 ±90° 纬度范围。覆盖外不修改原始机位，也不将机位标记夹到覆盖边界；隐藏不可靠的地图叠加并提示使用参数输入。极区地图与地球投影留待独立验证。

以上依据：[MapLibre 文档](https://maplibre.org/maplibre-gl-js/docs/)、[引擎许可](https://github.com/maplibre/maplibre-gl-js/blob/main/LICENSE.txt)、[OpenFreeMap 接入说明](https://openfreemap.org/quick_start/)、[服务条款](https://openfreemap.org/tos/)与[实时数据源说明](https://tiles.openfreemap.org/planet)（查阅：2026-11-04）。

## 状态与交互边界

拍摄计划仍由工作区管理。地图只提交位置或方位角的局部修改，不重建整份计划，也不修改 UTC、时区、传感器或焦距。

地图浏览中心、缩放级别与地图旋转角使用独立的会话状态。平移、缩放和旋转只更新此状态；地图旋转时，机位、扇形与方向把手保持其地理方向。面板交换位置、重试或窄屏切换保留浏览状态，不把浏览中心写成拍摄机位。

默认处于浏览模式，空白点击不修改计划。“放置机位”和“定朝向”均为明确启用的一次性操作，成功点击后回到浏览；再次点击按钮或在地图中按 Escape 可取消。点击位置归一化经度；朝向使用机位到目标点的球面初始方位角，按真北顺时针定义。重合点、对跖点及精确极点不产生可靠的朝向修改。用户仍可在参数区精确输入。

水平视场使用传感器、画幅与焦距的现有计算结果。扇形与朝向线使用球面目的点计算，半径仅用于显示，随地图缩放变化，并在底图纬度边界附近收缩。跨日期变更线时展开邻近经度，避免扇形横跨整张地图。球面近似不是测绘距离或地形遮挡判断，计算依据见[球面方位与目的点公式](https://www.movable-type.co.uk/scripts/latlong.html)。

机位与方向把手在 `drag` 期间更新计划，而非只处理 `dragend`。活动把手由引擎控制位置，重画扇形时不强行改写它，避免拖动抖动。地图 `move`、`zoom`、`rotate` 事件及计划变化通过 requestAnimationFrame 合并；几何输入未变化时不重复发送 GeoJSON。定位、全球视图采用 easeTo，并遵守引擎对减少动态效果偏好的处理。事件和动画接口见 [MapLibre Map 文档](https://maplibre.org/maplibre-gl-js/docs/API/classes/Map/)。

预览通过 Pointer Capture 保持完整拖动，使用拖动起始视场换算水平、竖直角度；只修改方位角和俯仰角，后者限制在 ±90°。松开、取消或丢失捕获时结束手势。键盘方向键提供替代操作；地图、预览与参数共享同一份拍摄计划。

## 生命周期与失败处理

- React 管理计划与面板；MapLibre 管理地图实例、底图和标记。计划变化更新标记与 GeoJSON，不重新创建地图。
- 异步加载读取最新计划，组件已卸载时不创建实例或回写状态。卸载取消待执行动画帧，并释放标记、监听、观察器和渲染资源。
- 使用 ResizeObserver 响应分隔条、面板换位及窄屏显示变化；隐藏面板尺寸为零时不重算。
- 样式与瓦片加载过程中提示状态；超时、样式或瓦片请求失败显示可重试信息，不用空白冒充已经加载。
- 图形环境无法启动时显示独立提示；参数编辑与示意预览继续可用。重试保留拍摄计划和浏览位置。
- 地图使用 SDK 紧凑署名控件，完整来源同时列入 About；状态提示、参数摘要和窄屏布局应避让署名与缩放控件。

## 验收方向

自动检查球面方位、目的点、视场宽度、日期变更线、同点/对跖点以及高纬覆盖边界。组件交互测试在 JSDOM 中挂载真实 React 工作区，用地图 SDK 测试替身检查默认点击、单次放置、连续拖动、逐帧缩放、地图旋转状态保存以及预览与参数联动；不将此环境描述为 WebGL 渲染验证。

浏览器中应验证：选点与拖动同步到参数；方向模式不改变机位；浏览操作不改变计划；焦距只改变扇形角度；换位与尺寸变化后地图正常；网络失败可提示和重试；超出底图范围不截断计划；署名可见。本轮浏览器连接不可用，实际浏览器交互与视觉验收需另行复核，不以计算测试或构建代替。
