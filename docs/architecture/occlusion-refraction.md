# 日月山体遮挡与标准折射

更新：2026-11-04。本轮让日月圆盘按当前 MapLibre 地形深度裁切，并提供标准折射与无折射比较；不增加天气、日月食、建筑植被或其他天体。

## 绘制与遮挡

日月从 SVG 圆盘升级为现有预览实例的末尾 `CustomLayerInterface` 三维图层。继续沿用三维针孔投影与月相轮廓，将屏幕多边形三角化，在远裁剪面绘制；通过共享深度缓冲，地形像素挡住日月，天空像素允许通过。写入颜色但不改地形深度，绘制后恢复 GL 状态。辅助标签和读数仍由 React 管理，不绘制穿山圆盘作为失败回退。

用 WebGL 2 异步遮挡查询分别检查圆盘轮廓的天空与地形样本，区分“当前 DEM 未遮挡”“部分山体遮挡”“山体遮挡”。无样本、查询未完成、地形加载或出错均不能标成无遮挡。查询结果携带包含机位、方向、镜头、时间、折射、尺寸与地形更新序号的键，过期结果丢弃；重建、隐藏和上下文中断时使状态失效并释放 GPU 资源。

判定只描述当前已加载的 DEM 网格画面，和实际可见性分开。模型保留原有地形覆盖、LOD、近裁剪、平面地球、水位及缺失数据限制，不宣称查验了所有远处地形。小到没有覆盖像素的圆盘显示“像素不足”，不为获取状态而放大真实圆盘。

## 标准折射

参数区提供“标准折射（海平面近似） / 无折射（几何位置）”，保存在拍摄计划中，默认标准折射。采用 Astronomy Engine 的 `Refraction("normal", geometricAltitude)` 经验公式；不引入实测气压、温度或海拔密度修正。近地平线误差可能显著，不能以此保证日出、日落、触山时刻或可见性。

保留原始测站几何坐标、距离与月相，基础昼夜仍按几何太阳高度计算。对圆盘与月相轮廓的每条方向分别施加折射后再投影和裁切，表达近地平线的竖向压扁；不只整体抬高圆心。视地平线状态按折射后的圆盘上缘判断，朝向操作采用视高度。界面同时展示视高度与几何高度，并说明固定参考大气。地形本身不施加天体折射，也不模拟地面视线的折射或海市蜃楼。

参考：[MapLibre 自定义图层](https://maplibre.org/maplibre-gl-js/docs/API/interfaces/CustomLayerInterface/)、[Astronomy Engine 折射](https://github.com/cosinekitty/astronomy/blob/master/source/js/README.md#Refraction)。接口与深度规则在当前安装 SDK 验证；不访问内部纹理或私有变换字段。

## 验收

数值覆盖折射零点、天顶、地平线下与圆盘压扁；既有 JPL 无折射基准继续保留。GL 查询替身检查部分/全部遮挡、未知状态、过期结果、状态恢复与释放，不模拟实际光栅化。真实浏览器使用固定日落机位，保存露出、部分遮挡和完全遮挡三组画面；折射开关必须改变圆盘位置而保留计划的其他参数。执行结果见[遮挡与折射验收](../plan/occlusion-refraction-validation.md)。
