# 时间驱动的天空与地表配色

更新：2026-11-04。本轮将已有 UTC 拍摄时刻接入预览，以晴空近似表达白昼、暮光和夜间，不提供天气、太阳圆盘、月光、星空、曝光或地形投影阴影。

## 计算与误差边界

领域计算仅使用机位经纬度和 UTC 时刻，不读取浏览器时区或系统当前时间。太阳几何高度角相对理想水平面，方位角真北起顺时针；不加大气折射、地形遮挡、地平线下沉或测站视差，不能据此给出精确日出日落或目标可见性。

采用 NOAA 公开的 Meeus 简化太阳位置公式：UTC 转儒略日与儒略世纪，计算太阳赤纬、时间方程和本地时角，再得到地平坐标。保持现有 1900—2100 年输入范围，不引入服务或新运行时依赖。独立公开样例用于检查角度约定与量级，测试容差不等于整个日期范围的精度承诺。

参考：[NOAA 计算说明](https://gml.noaa.gov/grad/solcalc/calcdetails.html)、[公开计算源码](https://gml.noaa.gov/grad/solcalc/main.js)、[NREL SPA 参考样例](https://www.nlr.gov/docs/fy08osti/34302.pdf)。NOAA 在线工具已不再维护，本项目本地计算，不将在线服务作为运行依赖；本轮不实现完整 SPA。

## 近似渲染

- 用太阳高度角驱动连续插值，而非按固定当地钟点切换。以 −18°、−12°、−6°、0°、+6°、+25° 为配色节点；文字区分夜间、天文暮光、航海暮光、民用暮光、低角度日照与白昼。几何太阳中心低于 0° 不施加直射日照。
- 独立的显示配色函数产生天空、地平线、雾、地面、土地覆盖、水体与地形阴影颜色；属于美术近似，不计算大气散射、照度、白平衡或真实曝光。夜间保留少量地面明度便于构图。
- MapLibre `setSky` 更新天空与雾，`setPaintProperty` 更新现有地表图层；山体坡面明暗以地图真北为锚点，方向使用太阳方位，光源高度采用 SDK 支持的有效范围。夜间关闭直射阴影强度。
- 太阳方位只影响坡面阴影，不绘制太阳或判断山体对太阳的遮挡。天空配色在各朝向相同，暂不模拟朝日与背日的色差；旋转预览不应旋转真实光源。
- 用现有动画帧合并计划修改；仅地点或 UTC 时刻改变时更新环境，不重建实例、不改相机、不重新请求机位 DEM。画面属性关闭额外的默认渐变延迟，连续时间滑杆本身提供连续变化，避免显示旧时刻。

## 界面与验证

预览显示当前光照阶段与太阳几何高度，并持续说明“晴空近似 · 不含天气与曝光”。时间和时区控件沿用现有交互；仅改变显示时区不得改变环境。加载失败仍显示现有具体错误，不用渐变天空掩盖地形缺失。

固定数值验证包括公开参考样例、同一 UTC 的时区不变性、日期变更线、南北半球季节差异、极昼极夜及配色节点连续性。组件验证检查时间更新调用环境接口、保留实例与相机、避免额外 DEM 请求，以及重建/隐藏恢复时应用最新时间。真实浏览器对同一机位的白昼、暮光、夜间截图，并检查快速滑动后的最终状态、布局与相机参数保留。执行结果另记在[时间天空验收](../plan/time-sky-validation.md)。
