# P2 山体与水体预览

更新：2026-11-04。当前范围是实际地形形状与静态水体边界的摄影机位预览，不承诺照片级地表、精确水位、倒影或天气。

## 数据与渲染

- 地图区保持现有平面地图；预览使用第二个 MapLibre 实例，共享拍摄计划与引擎依赖，独立管理绘制资源。
- 地形使用 Mapterhorn Terrarium DEM（512 像素 WebP）。本轮将地形与机位采样上限设为 z12，优先验证稳定的全球基础级地形，不将瓦片放大当作新增精度。
- 远山网格采用随实际取景尺寸和视场变化的屏幕细节策略，网格上限 z14、DEM 上限仍为 z12；地形源的最小视觉 tileSize 为 128，图像解码仍为 512。固定 SDK 的最小兼容修正和资源边界见[远山地形细节](terrain-detail.md)。
- 地表以简化的土地覆盖色和地形阴影表现；水体来自 OpenFreeMap / OpenMapTiles 的 `water` 面与 `waterway` 线。预览不绘制道路、地名和建筑标签。
- 水体按真实边界着色、贴附当前 DEM 表面，水面高度为 DEM 近似，尚未校准独立水平水位。河流细线只是地理参考，不承诺实际宽度。界面始终显示这项限制。
- 使用 1 倍真实地形，不夸大山体。天空、雾、地表明暗和坡面阴影随机位及 UTC 时刻变化；为晴空近似，详见[时间天空设计](time-sky.md)，不扩展天文图层。
- 地形与水体服务均为公开网络服务，配置可替换；不引入账户、服务端或密钥。完整署名集中在 header 的 About，避免版权长列表挤压取景框；地图另保留 SDK 紧凑署名控件。

资料：[Mapterhorn 数据访问](https://mapterhorn.com/data-access/)、[数据来源与署名](https://mapterhorn.com/attribution/)、[MapLibre 地形](https://maplibre.org/maplibre-gl-js/docs/examples/3d-terrain/)、[第一人称相机示例](https://maplibre.org/maplibre-gl-js/docs/examples/walk-around-a-map-in-first-person/)、[水体结构](https://github.com/openmaptiles/openmaptiles/blob/master/layers/water/water.yaml)（查阅：2026-11-04）。

## 高程与相机

引擎在 DEM 缺失时可能以 0 返回高程。本轮单独请求机位所在的 DEM 瓦片，解码 Terrarium 后双线性采样；无效、透明或缺失数据均报告失败，不能当成海平面。瓦片像素关闭颜色转换，保留编码数值。

机位变化时取消过期请求并短暂合并连续拖动；仅使用与当前经纬度匹配的结果。缓存少量已解码瓦片以减少附近移动的重复下载。采样失败允许重试，不显示伪造地形。

高程内部沿用同源 DEM 的数值体系。提供方 TileJSON 未声明统一垂直基准，本轮尚未独立验证或转换到椭球高、其他海拔基准；正式精度验收需要核对源数据的垂直基准。

后续实际地形与贴附水体已使用[摄影 ENU 投影](terrain-perspective.md)，消除同一高度假设下的平面/曲面方向差；DEM 数值作为条件参考曲面，不自动施加 geoid 常数。SDK 平面相机仍用于加载和实际眼点测量，最后绘制使用独立的摄影相机矩阵。

相机绝对高程为 DEM 高程加离地高度；离地高度需大于 0。渲染地形细化后，使用有效的引擎表面采样校正相机贴地位置；无法证明为有效数据的零值不覆盖独立采样结果。地形采样与显示均属于 DEM 模型近似。

相机使用现有水平、垂直视场计算。设置垂直 FOV 后，用 Mercator 坐标中的眼点与前方 20 米的观察点建立相机，保持机位固定，匹配方位角、俯仰角、横竖幅与焦距。支持向上观察，关闭引擎的交互和自动贴地中心，保留现有 React 取景框拖动。

相机保留 `maxZoom: 32`，满足固定眼点与长焦视场所需的虚拟缩放；同时设置 `zoomLevelsToOverscale: 32`，使矢量瓦片覆盖沿用来源原生上限，而不随高相机缩放细分到 SDK canonical 瓦片上限 z25 之外。不能单纯降低相机缩放上限来掩盖错误，否则会改变眼点。瓦片层级与相机缩放不是新增地表精度。

SDK 的地形细节层级计算在精确水平视角、眼点所在瓦片上可能遇到 0/0，造成覆盖遍历越界。相机渲染将绝对值小于 `1e-7` 度的俯仰保留为同符号微小角度；拍摄计划和界面数值不变，偏移小于 `1e-6` 度的数值校准容差。此兼容处理与瓦片覆盖选项一同接受当前 SDK 源码回归检查。

引擎仍有防穿地和近裁剪校正，近地场景可能明显改变标称高度或俯仰。本轮已在真实 GPU 读到广角低机位的调整；预览显示实际读数与避让提示，日月跟随实际姿态，参数保留计划。读取方法、阈值及基准边界见[相机校准设计](camera-calibration.md)，固定测量见[校准记录](../plan/camera-calibration.md)。

## 生命周期与反馈

- 机位高程、地形/水体加载、图形环境失败分别显示状态。机位改变后，旧位置画面隐藏，避免误以为旧画面已经对应新参数。
- 角度、焦距、画幅和离地高度改变只更新相机，不重建地图、不重复下载机位高程；时间修改通过样式接口更新环境，不改变相机。环境更新同样合并到动画帧，以地点和 UTC 为键避免逐帧重复写入。
- ResizeObserver 和动画帧合并适配分区尺寸、横竖幅及窄屏切换。卸载时释放地图、观察器、动画帧和请求；异步结果不得更新已卸载实例。
- 预览地图容器使用高于 SDK 默认 `.maplibregl-map` 的选择器优先级，并显式占满取景框宽高，避免样式加载顺序将绝对定位覆盖为相对定位、导致高度为 0。隐藏面板时暂停加载超时计时，恢复有效尺寸后重新同步；样式、相机与瓦片超时分别提示。
- 预览可重试；错误不影响地图操作和参数编辑。超出约 ±85.05° 的区域明确提示覆盖限制。

## 验证

计算测试覆盖瓦片坐标、Terrarium 解码、双线性采样、相机位置与视场、水平/垂直观察和横竖幅。SDK 相机 CPU 验证进一步检查实际变换后的眼点、角度、针孔投影和瓦片覆盖遍历，包括连续尺寸变化与水平长焦组合；使用合成地面高程，尚不验证真实网格的防碰撞与近裁剪校正。组件测试验证加载、失败重试、过期结果、相机联动及资源清理。三组场景已完成基础 GPU 检查，湖岸长焦可见粗 DEM 与贴地水体交接的限制；固定场景、数值判据、截图及待验项记录在[地形预览验收](../plan/terrain-validation.md)。公开端点做小规模连通性检查，不下载区域数据。

浏览器连接不可用时应如实报告：自动检查不能证明 GPU 上的真实山脊、水岸接缝和长焦精度。正式精度验收需要选取已知山峰、湖岸和近地机位进行视觉与坐标核对。
