# 亮星、行星与银河构图参考

## 数据与精度

- 恒星：固定 [HYG v4.1](https://github.com/astronexus/HYG-Database/tree/3bf37f4b2d5460e1278286320d1d62fab9b493c1/hyg)，按 V 星等 ≤4.5 提取，925 颗，排除太阳。原目录与导出子集均为 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)。生成入口 `scripts/build-star-catalog.mjs` 保留来源提交、SHA-256、列定义与修改声明；实际子集及下载地址随应用分发，不能省略署名。
- 使用 J2000 赤经/赤纬、距离及空间速度推进恒星位置，加入地球位置与一阶周年光行差；通过既有 Astronomy Engine 旋转到测站地平坐标。HYG 数据字段与 epoch 见[原目录说明](https://github.com/astronexus/HYG-Database/blob/3bf37f4b2d5460e1278286320d1d62fab9b493c1/hyg/README.md)。不模拟双星轨道、变星、星盘或严格的长期光度变化。
- 金星、木星使用既有库的测站视赤道坐标与几何高度；点大小按星等作有上下限的显示符号，不表达真实角直径或现场可见性。
- 银河使用库的 IAU 1958 银河坐标旋转；亮度、宽度和暗带为解析美术示意，不使用随机位置或宣称复原真实尘埃云。银心采用 Gordon 等的 [Sgr A* ICRF3 坐标](https://arxiv.org/abs/2212.00632)，J2000 坐标轴、2015.0 位置历元；本轮固定该方向，忽略其亚角秒级历元变化。银心与银河坐标原点不混同。

## 渲染与状态

沿用机位局部 ENU、实际摄影相机、传感器视场、所选标准/无折射及参考地平线。独立的当前目标 WebGL 图层在地形之后、日月之前绘制：银河带为有界网格，恒星与行星为点，天空深度为 1、不写深度，接受地形的 ENU 对数深度遮挡。不增加引擎、后台或通用插件系统。

仅少量主要参考点与银心显示名称。名称根据实际 GPU 深度查询结果显示，不能穿过山体；星空的方向/状态与日月保留独立读数。切换图层、机位、时间、姿态或地形细化时旧查询作废；加载失败不伪造空白星空。星点大小、颜色、银河轮廓属于定位示意，白天勾选仍不代表实际能看到。日月开关与月光环境含义不变。

恒星方向和银河顶点按位置、UTC 与折射缓存；旋转、焦距和画幅仅更新相机矩阵。资源随预览实例释放，星空关闭不新增外部请求。验证见[执行计划](../plan/starfield.md)。

## 固定参考

测试使用独立 [ERFA `atco13`](https://github.com/liberfa/erfa/blob/master/src/atco13.c) 计算恒星/银心方向，`g2icrs` 检查银河坐标轴；参考与应用使用相同 HYG 输入，但不使用同一位置变换实现。ERFA 与 JPL 数值基准、模拟 GL 生命周期检查及 Chrome 真实画面分别记录，不将少量固定样本误差解释为全年、全球或实景精度保证。
