# 深空天体首步

## 数据与坐标

使用固定 OpenNGC 的 8 个目标及原项目 Aladin/DSS2 描绘的多级轮廓，衍生 JSON/组合分量图按 CC BY-SA 4.0 保留来源和修改声明。`scripts/build-deep-sky.mjs` 提取目录并计算 gnomonic 边界，`build-deep-sky-atlas.py` 将轮廓变成连续谱/Hα/其他发射的独立权重图；M31/M42 另加入下述公开影像局部结构。未引入在线星图、后台或新的运行时依赖。缺失位置角不补造，带轮廓目标按原天球顶点绘制；M31 外层椭圆使用目录角径和位置角，M45 辅助星来自已有 HYG。

`deep-sky.ts` 将 J2000 中心及切平面 east/north 网格转成单位天球方向，通过既有 skyReference（含岁差、章动和一阶周年光行差）到测站 ENU，再逐顶点参考折射。网格按 ≤0.25° 分段、每边至多 32 段，按 UTC/机位/折射缓存。摄影姿态、焦距和画幅仅更新相机矩阵。星云外轮廓可大于目录角径，不将描绘边界当作实测等光度线。

## 绘制、遮挡和资源

沿用 StarfieldLayer 与地形主深度，新增扩散目标的球面三角网格程序。源 atlas 三通道作为独立发光分量，输出预乘透明度；背景权重沿用当前暮光/月光近似，白昼淡出。`cameraResponse` 保存在共享拍摄计划（默认 `stock`，另一值 `ha-modified`），只经独立 setter 修改 Hα uniform，不纳入星历/相机/遮挡键。改机只作用于深空 atlas 的 Hα 通道，星系/星团的连续谱、HYG 点源、日月、地形与银河全景不作全局染色。显示权重不是通量、相机 QE 或曝光计算；相机模式按保留 UV/IR 截止的 Hα 改机近似，不模拟全光谱系统。

深空 atlas 与银河纹理复用仅服务于当前两份资产的 SkyTexture 生命周期：按需请求、12 秒超时、独立失败、关闭重开重试；卸载/取消不接收迟到资源。atlas 使用 clamp、限制 mip 级数并留零边缘以避免相邻目标串色，上传/绘制恢复宿主纹理单元、采样器和解包状态。失败只提示深空轮廓不可用，保留地形和其他天体。

可见绘制显式开启颜色写入，查询阶段关闭颜色写入，退出恢复宿主掩码。失效后的相同 frame key 仍须恢复 ready；加载事件主动更新源版本并调度检查，缓存或纯天空视野不依赖后续 sourcedata 才恢复。

扩展目标的视场状态按整个边界投影判断，中心在框外时仍可部分入画。每个画面内目标用相同发光掩码分别在 LEQUAL / GREATER 深度下查询，区分无遮挡、部分、全部及像素不足；查询忽略显示亮度和相机响应。名称另查中心点，中心被山体挡住时不把名称画在山体上。查询针对当前画面内、地平线以上的掩码，不能推断框外整片星云的遮挡。

## 交互与验证

左侧独立开关、右侧目标读数与搜索共享计划。搜索独立于开关；显式“开启并朝向”才修改图层/方向。相机参数提供响应选择；时刻、机位、镜头、银河对比度均保持原值。来源和衍生数据下载留在预览署名区。

位置使用独立 ERFA atco13 固定输入对照，形状/角尺寸、图像资源及数据哈希另验；GL 生命周期替身验证清晰/被挡双查询和响应更新不重传资源；真实 Chrome 检查定性改机差异、连续谱目标保持不变、部分入画、地形遮挡及失败恢复。结果见[深空执行计划](../plan/deep-sky.md)，不将数值方向回归解释成照片或实景光度精度。

## M31/M42 局部结构细化

输入记录固定在 `scripts/deep-sky-image-sources.json`，复制至衍生 JSON 的 imageSources 保留下载/署名。`deep_sky_image.py` 校验原图 SHA256、尺寸和嵌入 AVM，按其 ICRS/J2000 TAN、负 RA 像素比例、旋转和左下角 1-based 参考像素把影像重投影到原有目标切平面。AVM 参考尺寸与下载图像尺寸可不同，必须按轴缩放；不能用显示角度旋转原图猜测天球姿态。

离线预处理采用中值/形态滤波、黑位和显示层次调整，抑制部分前景星点；大光晕和未解析邻近目标仍可能残留。有限影像以椭圆羽化覆盖叠加在 16% 原目录轮廓上，覆盖之外只有较淡的目录近似，不扩充影像或拉伸填满目标。M31 的结构仅写入连续谱；M42 从发布用色彩划分定性显示分量，不能反演其 U/B/V/R/Hα 实测通量。

atlas 改为 4096×2048、每格 1024；运行时按设备 MAX_TEXTURE_SIZE 向下缩放，仍只使用一张静态图和原有三通道 shader。8 个边框均为零、保留 mip 上限和间距；上传失败与回收沿用既有路径。无新增 npm 依赖。PyAVM/Astropy/WCSLIB 仅用于离线独立核对，50 个点的转换差小于 1e-7 参考像素；该结果验证转换实现，不能推出发布方原始影像配准精度。范围和真实画面见[细化验收](../plan/deep-sky-detail.md)。
