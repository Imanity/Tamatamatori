# 深空天体首步

## 数据与坐标

使用固定 OpenNGC 的 8 个目标及原项目 Aladin/DSS2 描绘的多级轮廓，衍生 JSON/组合分量图按 CC BY-SA 4.0 保留来源和修改声明。`scripts/build-deep-sky.mjs` 提取目录并计算 gnomonic 边界，`build-deep-sky-atlas.py` 将显示结果打包成基础 RGB 与独立红色增量。八个目标均接入影像结构：M31、M42、M45、M8、NGC7000、NGC1499 保留原 AVM，IC1805/IC1848 使用固定 Stellarium 四角注册；不使用目录轮廓合成细节。未引入在线星图、后台或新的运行时依赖。缺失位置角不补造，带轮廓目标按原天球顶点绘制，M45 辅助星来自已有 HYG。

`deep-sky.ts` 将 J2000 中心及切平面 east/north 网格转成单位天球方向，通过既有 skyReference（含岁差、章动和一阶周年光行差）到测站 ENU，再逐顶点参考折射。网格按 ≤0.25° 分段、每边至多 32 段，按 UTC/机位/折射缓存。摄影姿态、焦距和画幅仅更新相机矩阵。星云外轮廓可大于目录角径，不将描绘边界当作实测等光度线。

## 绘制、遮挡和资源

沿用 StarfieldLayer 与地形主深度，新增扩散目标的球面三角网格程序。源 atlas 的 RGB 保留基础色彩，A 存储 1−额外红色增量（避免 PNG 解码器丢弃 alpha=0 处的 RGB）；A 是数据，最终透明度由光信号计算，输出预乘透明度；背景权重沿用当前暮光/月光近似，白昼淡出。`cameraResponse` 保存在共享拍摄计划（默认 `stock`，另一值 `ha-modified`），只经独立 setter 修改 Hα uniform，不纳入星历/相机/遮挡键。未改机 uniform 为 0，保留全部基础 RGB；改机 uniform 为 1，只加入独立红色增量，星系/星团的基础色彩、HYG 点源、日月、地形与银河全景不作全局染色。显示权重不是通量、相机 QE 或曝光计算；相机模式按保留 UV/IR 截止的 Hα 改机近似，不模拟全光谱系统。

深空 atlas 与银河纹理复用仅服务于当前两份资产的 SkyTexture 生命周期：按需请求、12 秒超时、独立失败、关闭重开重试；卸载/取消不接收迟到资源。atlas 使用 clamp、限制 mip 级数并留零边缘以避免相邻目标串色，上传/绘制恢复宿主纹理单元、采样器和解包状态。失败只提示深空轮廓不可用，保留地形和其他天体。

可见绘制显式开启颜色写入，查询阶段关闭颜色写入，退出恢复宿主掩码。失效后的相同 frame key 仍须恢复 ready；加载事件主动更新源版本并调度检查，缓存或纯天空视野不依赖后续 sourcedata 才恢复。

扩展目标的视场状态按整个边界投影判断，中心在框外时仍可部分入画。每个画面内目标用相同发光掩码分别在 LEQUAL / GREATER 深度下查询，区分无遮挡、部分、全部及像素不足；查询忽略显示亮度和相机响应。名称另查中心点，中心被山体挡住时不把名称画在山体上。查询针对当前画面内、地平线以上的掩码，不能推断框外整片星云的遮挡。

## 交互与验证

左侧独立开关、右侧目标读数与搜索共享计划。搜索独立于开关；显式“开启并朝向”才修改图层/方向。相机参数提供响应选择；时刻、机位、镜头、银河对比度均保持原值。来源和衍生数据下载留在预览署名区。

位置使用独立 ERFA atco13 固定输入对照，形状/角尺寸、图像资源及数据哈希另验；GL 生命周期替身验证清晰/被挡双查询和响应更新不重传资源；真实 Chrome 检查定性改机差异、连续谱目标保持不变、部分入画、地形遮挡及失败恢复。结果见[深空执行计划](../plan/deep-sky.md)，不将数值方向回归解释成照片或实景光度精度。

## M31/M42 完整覆盖与色彩修正

此前局部图的椭圆羽化及 16% 目录外壳因可见裁切痕迹已撤除，旧视觉验收不再作为修复依据。当前输入固定在 `scripts/deep-sky-image-sources.json`：M31 为 ESA/Hubble 的 heic1112f（6°×3.9°），M42 为 NOIRLab 的 noao-m42steinberg（2.2°×1.2°、可见光 LRGB）；两者均带 AVM，使用发布方 CC BY 4.0。完整来源与修改说明随 JSON 和图层署名提供。

`deep_sky_image.py` 核对原图 SHA256、尺寸和 AVM，以完整原图四角重投影后的边界加 3% 空间作为目标网格；不用内接椭圆或原目录角径裁掉影像。AVM Rotation 按 FITS CROTA2 完整 CD 矩阵处理，支持非等比 X/Y 像素尺度、左下角 1-based 参考像素和不同尺寸缩放。已与 PyAVM/Astropy/WCSLIB 独立对照；数值差只验证转换实现，不代表原始照片有相同的天球精度。

离线进行中值/形态滤波抑制部分星点，将发布用 sRGB 线性化，再减去边缘低分位背景。采用线性强度，色彩恢复为发布用 RGB 的显示比例，避免把线性 RGB 直接显示造成过饱和；采样边缘只做 3 个工作像素的过渡，不叠加目录轮廓或合成外壳。M42 的额外红色结构为 `max(R−(G+B)/2,0)×0.6` 的显示近似；普通模式不删除红色，改机在基础 RGB 上额外增加它。M31 增量为零。不能从 LRGB/合成图反推出特定相机或实测 Hα 通量。

M31/M42 修正时，加州、心脏、灵魂曾沿用目录显示模型；它们现已由影像替代，见末节。可见绘制从连续 RGB 亮度计算透明度，不再用 0.012 的分量阈值截出可见边沿；遮挡查询独立使用 0.008 的数据存在阈值且不随响应变化。影像资料还可能包含残余星点和邻近目标，不作为额外可搜索星历。

M31/M42 的 1024×1024 图格及其像素在后续布局调整中保持不变；沿用单张图、GL 生命周期和地形深度，没有新增 npm/运行时依赖。原始修正记录见[遮罩及颜色修正](../plan/deep-sky-render-fix.md)，当前图集布局见下节。

## M45/M8/NGC7000 扩展

新增 NOIRLab/AstroPix 的 noao-m45denton（可见光 RGB、约 2.2°×1.5°）、noao-m8wideblock（LRGB、约 1.6°×1.1°）和 noao-n7000mosblock（LRGB、约 4.2°×2.9°）。均使用明示 CC BY 4.0、输入哈希和完整 AVM，不把窄带假色或红外图代入普通相机色彩参考。配准沿用完整 CROTA2/CD 矩阵，支持这三图不等 X/Y 像素尺度。

三图现使用同一发布图的原尺寸 TIFF（1438×968、2179×1469、2758×1890），SHA256、尺寸及内嵌 AVM 均核对，WCS 与旧 JPEG 一致。`detailMode=source-rgb` 保留最终 RGB 的高频信息；中值/形态滤波作用于背景估计副本，扩散光支持另见下节，不能再次把 31/15 像素开运算与高斯模糊施加到最终影像。没有锐化、AI 或生成新结构。云气内部仍可能保留照片星点及衍射光刺，HYG 星历与标签不受其驱动。

平滑背景仍由过滤副本的边界 RGB 经一维平滑、64×64 调和解和双线性放大获得，在线性域扣除；它可能减弱部分大尺度弥漫分量，不是实测天空背景。三图只在原图边缘过渡 40 个工作像素（约宽度的 1.5%–2.8%），不使用椭圆裁切或目录外壳；M31/M42 保持 3 像素。来源以外不生成云气或星场。M45 的额外红色增量为零；M8/北美按 RGB 的红色结构近似增量，非实测 Hα。

单张 atlas 为 4096×4096，8 个对象各带像素坐标 `atlasRect=[x,y,width,height]`：M45/M8 为 2048×1024，北美/加州为 2048×2048，其余四图为 1024×1024。UV 使用每个区域的像素中心，角范围仍由 AVM/TAN 决定，不能用纹理长宽代替天球角尺寸。固定区域留中性边框、互不重叠；独立 WCS 按各自宽高对照。`tile` 只保留旧目录序号，不再用于计算 UV。

这比统一扩大至 8192 像素纹理节约显存；完整 RGBA 与 mip 链约 85 MiB。运行时按 atlas 最长边与 MAX_TEXTURE_SIZE 等比缩小，小设备的细节仍受上限约束，原有五图不会比旧版同上限条件下更差。无损 PNG 在补齐三目标后约 8.31 MiB，预算上限 14 MiB；按需请求、12 秒超时、失败隔离和资源释放继续有效。未新增 npm/运行时依赖。

旧结构接入记录见[扩展历史](../plan/deep-sky-expansion.md)；当前长焦修正、固定裁区模糊回归检查和真实画面见[清晰度验收](../plan/deep-sky-sharpness.md)。

## 扩散光支持与照片星场边界

完整原图的星点密度在照片边缘突然停止，低频背景扣除与窄边缘过渡不足以隐藏这个矩形。M31/M42 沿用星点抑制且来源外沿较暗，未出现同等明显的问题；不因此给三张新图恢复全图强模糊。

三图设置 `opacityModel=diffuse-colour-reconstruction`：在线性 RGB 背景扣除后，反射云取 `max(B−R,0)`，发射云取 `max(R−(G+B)/2,0)`，作为定性的扩散光支持。9 像素腐蚀后在原信号约束下逐步重建，去掉孤立紧凑信号，同时保留与云气连通的窄丝。41 像素闭运算填补白色星核造成的支持孔洞，再作 sigma=2 的支持平滑。最终 RGB 不滤波、不填补，真实暗带仍取原图颜色。

支持的边界噪声门槛取外沿 95 分位且至少 0.002，完整支持门槛为前者四倍且至少高 0.008；两者之间 smoothstep。共同乘入基础 RGB 与额外红色增量，继续沿用原 shader 和独立模式 uniform；支持以外的照片星点淡出，HYG 星点与名称独立。此颜色分离不是谱线提取或精确去星，白色弥漫分量可能减弱，云气内部仍可有照片星点；来源边缘的真实云气仍受有限覆盖约束。

合成检查区分紧凑点源、连通细丝与白色星核；实际 atlas 检查外围信号下降、主体保留、既有清晰度与其他五图逐像素不变。真实 Chrome 的宽幅、长焦、响应和遮挡另验，见[边界融合](../plan/deep-sky-boundary.md)。

## 加州、心脏与灵魂

加州采用 NOIRLab/AstroPix `noao-n1499block` 原尺寸 1172×1743 光学 LRGB，CC BY 4.0，沿用完整 AVM、原 RGB、边界背景扣除及扩散光支持。它是有限范围的摄影资料，不保证覆盖云气的全部远端。

心脏、灵魂采用 Stellarium 固定提交 `230f2bd84b7827fb16be2a54c2ebdae07edf17a6` 的 1024×1024 去星纹理，Giuseppe Donatiello / Sun Shuwei，原作者和上游 CREDITS 明示 CC0。来自 DSLR 拼接，原始滤镜响应和去星细节没有完整定标。只复用影像及四角坐标事实，没有引入 Stellarium 代码。`registrationModel=stellarium-sky-corners` 与 AVM 明确分开，来源 URL、版本、SHA256、四角与派生矩阵写入清单。

四角按纹理左下、右下、右上、左上对应像素边界 0.5 至 width/height+0.5，在球面均值方向的 TAN 平面拟合完整 CD 矩阵；保留旋转、非等尺度与剪切。通过 WCSLIB 核对四角最大源像素残差小于 0.5，并独立核对网格转换；这不是新的 plate solve 或天球精度承诺。生成时重算矩阵并核对已固定数值，超限则失败，不能偷偷退回只按目录中心放图。

心脏、灵魂 `backgroundModel=none`，不重复去星、背景扣除或整体模糊；保留原始 RGB 的色彩比例及强度，红色增量沿用统一显示近似。三目标都使用 40 源像素边缘过渡，不生成原图之外的资料。加州占 `[2048,2048,2048,2048]`，心脏占 `[0,3072,1024,1024]`，灵魂占 `[1024,3072,1024,1024]`；其余五份影像的图格、RGBA 与角范围保持不变。图集仍为 4096 方图，约 8.31 MiB、GPU/mip 约 85 MiB，原有按需加载、设备回退与失败隔离继续有效。

来源核查、200 点注册检查与真实宽幅/长焦、模式和遮挡验收见[本轮记录](../plan/deep-sky-remaining.md)。

## 两模式色彩核查与边界

两模式现明确命名为“未改机 · 近似参考”和“天文改机 · Hα 增强示意”。前者沿用处理后出版图，不是按指定未改机相机反演的底图；后者从 RGB 红色优势估计额外显示结构，不能区分真实 Hα、其他红色谱线、红色连续谱和源图调色。M31 的 DSS2 B/R 成品、其他 RGB/LRGB 和滤镜响应未知的 DSLR 拼接不能混称成对器材实拍。

`deepSkyRedEnhancementColor` 是域层与 GLSL 共用的显示增量常量，现为 `[1,0,0]`。旧 `[1,.1,.18]` 会在一些本来很红的像素额外加入绿蓝，反而降低红色占比，实际图集已证实此问题。保留基础 RGB、打包增量、强度压缩、天空权重和遮挡查询；只修正额外显示增量方向。归一化与背景合成会影响最终屏幕通道，不能将“信号不加 G/B”解释为屏幕 G/B 像素绝对不变。

真实的器材对比还需要原始波段/谱线通量、滤镜/传感器响应、白平衡和曝光基准。此次通过的是定性显示检查，不是实景或光度校准；证据见[色彩核查](../plan/deep-sky-colour-audit.md)。候选扩展与当前图集已占满的资源约束见[后续目标](../plan/deep-sky-candidates.md)，不预建未验证的纹理框架。
