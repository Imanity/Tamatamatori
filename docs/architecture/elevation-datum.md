# DEM 高度基准的使用决策

更新：2026-11-04。核查证据与复现见[高程基准核查](../plan/elevation-datum-audit.md)，几何坐标定义见[曲率参考](curvature-reference.md)。

## 当前决策

现用 Mapterhorn 高程值作为同一数据源内部的地形与相机高度使用，不自动宣称为正高、EGM2008 高或 WGS84 椭球高。TileJSON 编码说明、来源名字与覆盖多边形不足以建立这样的契约；不能从“接近公布山峰高度”反推基准。

全球统一转换未获证据支持。保留未知状态，不添加通用 geoid 常数、按国家套用模型的启发式规则或未经匹配的垂直偏移。核查本身不改变高程数值和星历观测高度；后续按用户要求已启用[参考曲面的默认空间投影](terrain-perspective.md)，几何修正与实景高度转换仍分开。

## 正式转换的准入条件

1. 瓦片/数据集有可追溯版本，明确来源和重采样、混合规则；若同一像素混合不同基准，应在已知的统一基准中处理。
2. 高程种类、垂直参考、水平参考框架及相关成果版本明确。`H + N = h` 只在 H 与 N 的基准相匹配时使用，不能把地理范围相同当作基准相同。
3. 转换格网的版本、覆盖、缺失值、许可和署名明确；分别计算眼点与目标，不将两端 geoid 差默认为零。
4. 以独立数值、已知控制点和实际画面验证转换；模型精度、DEM 精度与实际可见性分别判断。

上述条件针对正式精度能力。已有公开数据可作为候选调研，不在条件未满足时自动接入或预建通用数据源框架。

## 条件几何与默认构图

曲率与绘制路径可以使用明确假设的统一高度输入验证，不需要等待所有全球数据完成基准统一。后续默认预览已启用参考曲面构图，数据仍沿用同源高度体系；实际精度能力与新增来源仍受上述准入条件约束。

- 默认取景框明确标注“曲面构图 · 高程基准未核定”，开发校准进一步显示同源高程假设。保留输入值及假设，不把结果写回拍摄计划。
- 用实际网格的 ECEF/ENU 坐标验证曲率，独立固定点只作为检查工具。地形与相机采用相同高度假设和局部方向约定。
- 实际网格、贴附水体与日月共享主深度已经验收；后续无限远天体可复用该基础，未核实的高度和实景误差继续独立保留。
- 新增资源范围必须有瓦片、顶点、请求、超时、取消和释放边界；不对未知来源开启区域批量下载。

几何渲染通过不解除正式高度转换的准入条件，也不等于触山时刻或实景精度已获验证。
