# 日月构图渲染

更新：2026-11-04。本轮接入太阳、月亮的方向、角直径、月相近似与侧栏开关；沿用现有摄影相机、地形与晴空环境，不实现其他天体、天气、月面纹理、日月食、月光照明或真实曝光。

## 计算选择

采用 MIT 许可的 Astronomy Engine 2.1.19，本地计算日月测站坐标与距离；无网络星历请求、账户、密钥或新增服务。依赖和许可分别保存在锁文件与第三方许可说明。日月图层与基础天空统一使用同一个太阳位置算法，替代此前 NOAA 简化太阳位置函数；旧验收记录保留历史结果。

使用 `Equator` 的日期赤道坐标及测站视差修正，再通过 `Horizon` 转为真北顺时针方位与几何高度；关闭大气折射。观测高度采用参考椭球面 0 m，本轮不把垂直基准未核定的 DEM 高程直接输入天文算法；相机离地高度仍只驱动地形相机。这是天文机位高度的近似，后续核对垂直基准再统一。太阳、月亮半径分别取 695700 km、1737.4 km，按测站距离计算角直径。

月面亮区以日月测站方向及距离推导的光照方向构造，给出亮面比例与盈亏阶段；亮侧随观察姿态旋转，不能固定成右亮或左亮的图标。月相外观采用球面近似，不模拟纹理、天平动、地照或日月食。

参考：[Astronomy Engine 文档](https://github.com/cosinekitty/astronomy/blob/master/source/js/README.md)、[许可](https://github.com/cosinekitty/astronomy/blob/master/LICENSE)、[JPL Horizons 接口](https://ssd-api.jpl.nasa.gov/doc/horizons.html)、[USNO 月相接口](https://aa.usno.navy.mil/api/moon/phases/date?date=2026-11-01&nump=4)。库作者的精度说明不自动成为本应用的误差承诺，固定基准需独立验证。

## 投影与状态

- 图层开关存入同一份拍摄计划，分别控制日月叠加；关闭太阳图层不关闭晴空环境与地形光照。机位、时间、镜头和布局不被开关改变。
- 在局部东、北、天坐标中构造目标方向，以现有方位角、俯仰角、传感器及画幅确定的针孔模型投影。采用完整三维方向变换，不把方位差、高度差分别当平面坐标；长焦、竖幅、天顶和跨真北均需验证。
- 圆盘边缘按角半径采样，并由摄影视锥与理想几何地平面裁切；圆盘中心刚离开视场、或刚落到地平线下时，上缘仍可能在画面内。视觉圆盘不设置最小像素尺寸；辅助名称和轮廓与真实角尺寸分开表达。
- 预览逐项区分“已关闭”“地平线下”“视场外”“画面内（地形遮挡未校验）”及计算失败。地平线判据考虑圆盘半径，不能仅看中心高度。
- 图层为构图辅助叠加，不参与 MapLibre 深度测试；可能覆盖山体。界面持续提示“日月为构图辅助 · 地形遮挡未校验”，不宣称目标实际可见。地形失败仍保留具体错误，不用天体掩盖缺失。
- 提供明确的“朝向太阳 / 朝向月亮”操作以调整方位和俯仰，只有用户主动点击才转向；地平线下目标不提供自动居中。

## 验证

固定数值基准使用 JPL Horizons 的无折射日月坐标、距离与角直径；用公开月相时刻检查盈亏。几何测试覆盖完整相机姿态、长焦与横竖幅、圆盘跨画面边界、部分地平线、背后目标和月相亮侧。组件测试检查开关、居中、调时、时区与布局保留参数。实际浏览器保存太阳、月相、长焦和窄屏截图，结果见[日月验收](../plan/sun-moon-validation.md)。
