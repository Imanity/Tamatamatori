# 日月构图渲染

更新：2026-11-05。已接入太阳、月亮的方向、角直径、月相近似与侧栏开关，并增加当前 DEM 遮挡、标准参考折射和画外方向提示；沿用现有摄影相机、地形与环境。月光构图近似见[环境架构](time-sky.md)；不实现其他天体、天气、月面纹理、日月食或真实曝光。

## 计算选择

采用 MIT 许可的 Astronomy Engine 2.1.19，本地计算日月测站坐标与距离；无网络星历请求、账户、密钥或新增服务。依赖和许可分别保存在锁文件与第三方许可说明。日月图层与基础天空统一使用同一个太阳位置算法，替代此前 NOAA 简化太阳位置函数；旧验收记录保留历史结果。

使用 `Equator` 的日期赤道坐标及测站视差修正，再通过 `Horizon` 转为真北顺时针方位与几何高度；星历层保留无折射坐标。渲染层按计划选择标准参考折射或无折射，基础天空继续使用几何高度。观测高度采用参考椭球面 0 m，本轮不把垂直基准未核定的 DEM 高程直接输入天文算法；相机离地高度仍只驱动地形相机。这是天文机位高度的近似，后续核对垂直基准再统一。太阳、月亮半径分别取 695700 km、1737.4 km，按测站距离计算角直径。

月面亮区以日月测站方向及距离推导的光照方向构造，给出亮面比例与盈亏阶段；亮侧随观察姿态旋转，不能固定成右亮或左亮的图标。月相外观采用球面近似，不模拟纹理、天平动、地照或日月食。

参考：[Astronomy Engine 文档](https://github.com/cosinekitty/astronomy/blob/master/source/js/README.md)、[许可](https://github.com/cosinekitty/astronomy/blob/master/LICENSE)、[JPL Horizons 接口](https://ssd-api.jpl.nasa.gov/doc/horizons.html)、[USNO 月相接口](https://aa.usno.navy.mil/api/moon/phases/date?date=2026-11-01&nump=4)。库作者的精度说明不自动成为本应用的误差承诺，固定基准需独立验证。

## 投影与状态

- 图层开关存入同一份拍摄计划，分别控制日月叠加；关闭太阳图层不关闭晴空环境与地形光照。机位、时间、镜头和布局不被开关改变。
- 在局部东、北、天坐标中构造目标方向，以现有方位角、俯仰角、传感器及画幅确定的针孔模型投影。采用完整三维方向变换，不把方位差、高度差分别当平面坐标；长焦、竖幅、天顶和跨真北均需验证。
- 圆盘边缘按角半径采样，对各方向施加所选折射后，由摄影视锥与水平面裁切；圆盘中心刚离开视场、或刚落到地平线下时，上缘仍可能在画面内。视觉圆盘不设置最小像素尺寸；辅助名称和轮廓与真实角尺寸分开表达。
- 预览逐项区分“已关闭”“地平线下”“视场外”、当前 DEM 未遮挡、部分山体遮挡、山体遮挡及等待、像素不足和失败。地平线判据考虑折射后的圆盘上缘，不能仅看中心高度。
- 圆盘与轮廓由 MapLibre 自定义三维图层共享地形深度，异步查询只报告当前已加载 DEM 的遮挡。辅助名称由 React 管理，完全遮挡或等待期间隐藏；失败不回退到穿山圆盘。实现与固定参考大气限制见[遮挡与折射设计](occlusion-refraction.md)。
- 提供明确的“朝向太阳 / 朝向月亮”操作，以方位和视高度调整拍摄方向，只有用户主动点击才转向；地平线下目标不提供自动居中。

## 画外方向提示

沿用圆盘上缘及所选折射的地平线判据；只有图层开启且 `bodyPolygons` 状态为“视场外”时显示。箭头不查询画外 DEM 遮挡，也不代表真实可见。圆盘部分入画时保留既有圆盘绘制，不同时显示箭头。

将折射后的目标射线点乘实际相机的右、上、前向基底，按真实水平/垂直视场比例求与取景矩形的边界交点。方向提示不除以前向深度，因此目标经过相机侧面进入后方时不会因负深度反向；前向点积为负时标注“后方”。精确反向没有唯一屏幕方向，统一放右侧并标“后方”。箭头图形角度采用相机平面中的方向，避免竖幅将角度拉伸。

React 只叠加方向与名称，不添加相机操作。接近的双目标组成一组并排展示，CSS 留出边距及现有提示空间；小预览采用容器查询，统一在上缘并排显示，避免窄竖幅中因边距夹取而互相覆盖。目标移动、焦距或画幅改变后重新定位。相机沿用已有实际姿态回传，地形尚未就绪时隐藏提示。

## 运行轨迹

轨迹开关是拍摄计划的 `layers.sunPath` / `layers.moonPath`，从属于对应天体图层。`src/domain/body-paths.ts` 复用圆面的 `topocentric` 测站坐标和所选折射：

- **取样**：按 UTC 对齐每 5 分钟取一点并缓存方向。在拍摄时刻前后 36 小时内选一次出没（本次，或前后最近的一次），超过 24 小时的只保留一圈。拍摄时刻本身作为顶点，保证轨迹穿过圆面中心。
- **整点**：用 Temporal 取所选时区的整点。
- **投影**：轨迹先在三维中按海平面地平与外扩画框裁切，再按与圆面相同的实际相机投影。
- **绘制**：`CelestialLayer` 在圆面之前绘制，在设备像素中扩成带斜接的三角带。第一遍以 GREATER 深度画淡色虚线（被已加载 DEM 或建筑遮挡），第二遍以 LEQUAL 画晕边、实线和整点标记；不写深度，不影响圆面遮挡查询。
- **标注**：整点文字由 React 叠加，只标方向，不做逐点遮挡查询；会盖住日月名称的标注不显示。

范围与验收见[日月运行轨迹](../plan/sun-moon-paths.md)。

## 验证

固定数值基准使用 JPL Horizons 的无折射日月坐标、距离与角直径；用公开月相时刻检查盈亏。几何测试覆盖完整相机姿态、长焦与横竖幅、圆盘跨画面边界、部分地平线、背后目标和月相亮侧。组件测试检查开关、居中、调时、时区与布局保留参数。首版画面结果见[日月验收](../plan/sun-moon-validation.md)，新增逐点折射、深度查询与真实 GPU 遮挡检查见[遮挡与折射验收](../plan/occlusion-refraction-validation.md)。
