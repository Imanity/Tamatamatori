# 建筑预算与地标保留修复

2026-11-07，按[缺块核查](building-data-audit.md)修复当前加载器。预算修复、自动检查、真实瓦片回放与城市 Chrome 画面已完成本地验收。未提交推送。

本轮保持约 2 km、最多 16 瓦片、80,000 个入选轮廓点和 120,000 个三角面的上限。先读取全部候选瓦片并收集轻量几何索引，再跨瓦片统一分配绘制预算，不再由前几个瓦片耗尽后停止读取。下载/解码安全限制和绘制预算分别表达。

高层分部按角尺度优先保留；普通建筑先按机位局部空间格网分配基础份额，再按角尺度补充。使用源轮廓，不以长方盒替换被省略的房屋，也不放大总绘制预算。选择不依赖镜头朝向，转向和调焦保持同一批网格及稳定遮挡标注；更细的视场驱动 LOD 留待性能证据支持后再评估。

使用用户机位 `35.70698835542723, 139.79386910980952`、离地 100 m，验证八个瓦片均读取，晴空塔 634 m 构件保留；以塔址、上海、密集合成瓦片、超限和取消/迟到响应作对照。CPU 合成基座、真实 DEM 与实际 GPU 分别验收。浏览器还需检查宽幅/长焦、拖动调焦、关闭恢复、地形/天空遮挡与手机。

区域静态包、建筑搜索、精细地标和新增纹理不属于本轮。不默认提交推送。

后续范围扩展与当前选择份额见[建筑远景](building-distance.md)。本页保留 2 km 预算修复时的历史参数与证据。

## 修复结果

下载/扫描与绘制分别限额，先为全部候选瓦片建立轻量索引，再筛选分部、采样 DEM 和生成网格。高层预留 40%，500 m 空间格网轮流分配至总预算 60%，余量按角尺度补充；未使用的份额可继续分配。源轮廓、孔洞、架空底面、隐藏标记与高度含义不变。具体限额与组织见[建筑架构](../architecture/buildings.md)。

右栏分别显示实际读取瓦片、入选/候选分部与预算省略数。仍可缺少普通房屋，不能将“全部候选瓦片已读取”解释为“周边建筑全部绘制”或源资料完整。现阶段不简化轮廓，也不按视场频繁替换网格。

## 保留边界与下一步

密集东京仍省略约 84% 的候选分部，当前修复解决前几个瓦片独占预算和高层被舍弃，不保证每栋房屋出现。塔架、渐变外形、纹理、近景基座与坡地接缝仍是原型限制。后续若改善覆盖，可独立评估有误差约束的轮廓简化与 LOD，先测量真实 GPU / 手机帧耗时。

本轮没有新增固定天体恰与楼体相交的 GPU 遮挡专项、坡地接缝、夜间天气合成、浏览器网络故障注入或帧耗时测试；这些仍按[首步待验](buildings.md)单列，不能用本次截图或 GL 替身替代。区域包本地化也尚未接入。
