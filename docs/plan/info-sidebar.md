# 信息栏改进

2026-11-08 按用户要求分两轮调整右侧“拍摄信息”栏，精模扩充暂不处理。

- **第一轮**：左栏开启图层时联动右栏；建筑分组改为用户关心的进度、范围、地标精模与缓存；其他分组删去调试说明。
- **第二轮**：
  - 全局信息默认展开并删去调试说明；
  - 建筑分组不再显示缓存；
  - 关闭图层时折叠对应分组；
  - 左栏删去“设置与信息”跳转按钮。

本文记录两轮之后的现状。

## 范围

1. **左右联动**
   - 左栏只保留图层开关。
   - 右栏图层分组的初始展开状态与开关一致：默认开启的太阳、月亮展开，其他收起。
   - 开启图层时：展开对应分组并滚动到信息栏顶部；桌面收起的右栏重新展开，搜索词清空；焦点留在开关上。
   - 关闭图层时：折叠对应分组，不滚动，也不改变搜索词和右栏收起状态。
   - 分组标题仍可手动展开或折叠，不改变图层。
   - 移动端开启图层时保留图层抽屉，下次打开信息抽屉时再定位。
2. **全局信息**：默认展开，只保留以下读数：
   - 方位、俯仰、视场；
   - 光照阶段与太阳高度，夜间附月亮亮面与高度；
   - 天空明暗；
   - 光污染天顶人工亮度；
   - 天气状态、云量、降水与能见度，以及 Open-Meteo 来源链接。

   删去的内容：
   - 曲面构图与高程基准说明；
   - 光污染格网与模型说明；
   - 天气模型名、分层云示意说明、采样时刻、预报范围、获取时间与近似说明。

   “地形按曲面构图绘制、垂直基准未核定、水面高程按 DEM 近似”移入 About 的“地图与高程”。
3. **建筑分组**显示：
   - 加载阶段、百分比和进度条；
   - 实际加载范围（瓦片数量上限截断时给出实际半径）和省略的建筑数量；
   - 50 km 内地标精模的距离、状态，以及“朝向”按钮。

   不显示缓存、来源版本、瓦片数、体块入选/候选、三角面、网格字节、清理点数和载入时间。
4. **其他分组**：
   - 日月删去遮挡与折射说明行。
   - 星空、银河和深空删去目录规模、全景衍生、源图色彩、定标与遮挡口径等说明。
   - 空间站删去网页检查时间、历元、日照判断附注和长段更新说明，保留更新时间、过期与失败提示。
5. 不改变计算、渲染、遮挡、数据源或拍摄计划结构，不增加持久缓存。

## 实现

- **定位请求**：
  - 左栏开关发出带“展开/折叠”标记的请求，不移动焦点。
  - 展开时，滚动作用于信息栏自身，等展开内容提交后再执行，否则信息栏高度不足、滚不到目标位置。
  - 信息栏隐藏时登记待定位分组，获得尺寸后补做；在此之前关闭该图层会撤销待定位。
  - 动画遵循“减少动态效果”设置。
- **分组初始状态**：预览面板挂载时，从当时的图层开关取得分组初始状态。交换面板位置后重新挂载，手动展开的状态会回到与开关一致。
- **建筑进度**：
  - 加载器按“瓦片读取 → 地标 → 体块生成”报告进度，总步数为两倍瓦片数加附近地标数。
  - 图层每 80 ms 最多发布一次进度。
  - 进度更新只刷新读数，不让日月星空的遮挡结果失效。
- **建筑结果新增字段**：
  - 普通建筑的实际覆盖半径；
  - 地标基座高程；
  - 地标回退原因，分为预算不足、读取失败、对应未确认三类。
- **朝向**：用 WGS84 椭球计算机位到地标中部高度的方位与俯仰，眼高优先取实际渲染相机的高度。
- **缓存**：
  - 第一轮曾把建筑瓦片与地标模型缓存合并为可订阅的分地区存储，并把瓦片条目上限由 48 放宽到 192。
  - 第二轮删去缓存显示后，该存储已撤回，恢复加载器内原缓存：瓦片 48 块 / 16 MiB，地标 16 项 / 8 MiB。

## 验证边界与限制

- **定位到底的情况**：分组位于信息栏末尾附近时，信息栏已无法继续下滚，分组只保证完整可见，不一定到顶。
- **关闭后的滚动位置**：关闭图层使内容变短时，浏览器会收回超出范围的滚动位置。
- **手动展开不保留**：交换预览面板位置后，手动展开的分组回到与开关一致。
- **地标与朝向**：
  - “朝向”对准地标中部高度，不调整焦距；地形、近处建筑和雾仍可遮挡。
  - 地标基座未知时，按机位地面高程近似。
- **已删说明的去处**：近似口径、来源与定标边界由预览信息条与 About 承载。
- **未改动**：搜索结果的文字未调整。
- **未测量**：实体手机与帧耗时。
