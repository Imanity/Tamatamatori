## 第 1 轮：布局

### 范围

- 桌面工作区只保留地图与预览两块，左右排列。默认地图约 36%、预览约 64%，分隔条可调；面板标题的“对调”按钮交换左右位置，不重建地图或预览。删除三栏位置下拉和拖拽换位。
- 地图下方为机位条：纬度、经度、地面高程与相机离地高度（数值与对数滑条）。在纬度框粘贴“纬度, 经度”可一次填入两项。地图左下角原有的方向、视场与焦距浮层移除，这些信息由预览承载。
- 预览上方信息条：方位角、俯仰角可直接编辑；流星估算和引擎避让反馈保留。
- 预览下方相机条：焦距数值与对数滑杆，常用焦距作为滑杆下方可点的刻度；传感器、画幅比例与横竖幅为同排的紧凑选择框。
- 预览下方时间轴：日期、时间与时区一行，太阳高度色带滑杆，微调按钮与日月时刻按钮。第 2 轮再改为事件刻度。
- 少用设置迁移：大气折射移入左栏“环境”组；深空相机响应移入右栏“深空天体”分组，预览信息条只在深空图层开启时注明相机响应。
- 晨光定义、改机说明、方位约定等常驻说明改为控件提示，第 3 轮统一精简。
- 窄屏（宽度小于 1100 px）：预览与时间轴常驻上方，下方用“地图 / 相机 / 图层 / 信息”标签切换，相机条移入“相机”标签；预览支持双指捏合调焦。横屏时预览在左、标签区在右。原图层与信息抽屉改为标签页；开启图层后切到“信息”时定位对应分组。

### 暂不处理

- 事件刻度、夜间时间轴与当地时区（第 2 轮）；结论化文案、图层并入右栏与详细数值开关（第 3 轮）。
- 拍摄计划、机位格式与会话格式不变；面板顺序和宽度仍只在当前页面保留。

### 验收

## 第 2 轮：时间轴

### 范围

- 时间轴范围：未开启夜空类图层（星空、银河、深空天体、流星雨、彗星）时为所选当地日期 00:00—24:00；开启任一后改为中午到次日中午，凌晨属前一晚，零点刻度标出次日日期。切换范围不改变拍摄时刻。
- 事件刻度只来自已开启的图层，可点击跳转：

| 开启的图层 | 刻度 |
| --- | --- |
| 太阳 | 日出、日落 |
| 月亮 | 月出、月落 |
| 夜空类任一 | 天文昏影、天文晨光（暗夜起止） |
| 银河 | 银心升起、落下 |
| 流星雨 | 时段中点 ZHR 最高的活动流星雨，辐射点升起、落下 |
| 彗星 | 时段中点最亮的列表彗星升起、落下，按中点位置近似 |
| 空间站 | 可见过境：高度 10° 以上、空间站受照且太阳低于 −6° 的时段，标在起点 |

- 天气效果开启且有数据时，滑杆下方加一条逐小时总云量条；它是读数，不是事件。
- 标签互相重叠时只保留标记，名称与时刻在提示中。开启图层但本时段没有对应事件时，刻度行下方以“本时段无：……”说明。
- 原日月时刻按钮行改为“上一事件 / 下一事件”，与微调按钮同排。
- 出没沿用原日月时刻口径：海平面地平与所选折射，不含地形遮挡。
- 时区列表首项为“当地时区（城市 · UTC±N）”，选中后跟随机位，新会话默认跟随。移动机位时保持 UTC 拍摄时刻，时区随之变化时在时间轴下方提示一次。
- 按坐标查时区采用 `@photostructure/tz-lookup` 11.7.0（CC0），其数据源自 timezone-boundary-builder（ODbL，源自 OpenStreetMap），署名进入 About。边境附近与海上可能不准，可改选固定时区；新疆返回 `Asia/Urumqi`（UTC+6）而非北京时间。
- 机位格式在 v1 内新增可选字段 `time.followLocalZone`（缺省为 false）：旧机位与旧会话保持固定时区；为 true 且未给 `timeZone` 时按坐标求时区。
