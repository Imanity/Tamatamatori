## 第 1 轮：布局

### 范围

- 桌面工作区只保留地图与预览两块，左右排列。默认地图约 36%、预览约 64%，分隔条可调；面板标题的“对调”按钮交换左右位置，不重建地图或预览。删除三栏位置下拉和拖拽换位。
- 地图下方为机位条：纬度、经度、地面高程与相机离地高度（数值与对数滑条）。在纬度框粘贴“纬度, 经度”可一次填入两项。地图左下角原有的方向、视场与焦距浮层移除，这些信息由预览承载。
- 预览上方信息条：方位角、俯仰角可直接编辑；流星估算和引擎避让反馈保留。
- 预览下方相机条：焦距数值与对数滑杆，常用焦距作为滑杆下方可点的刻度；传感器、画幅比例与横竖幅为同排的紧凑选择框。
- 预览下方时间轴：日期、时间与时区一行，太阳高度色带滑杆，微调按钮与日月时刻按钮。第 2 轮再改为事件刻度。
- 少用设置迁移：大气折射移入左栏“环境”组；深空相机响应移入右栏“深空天体”分组，预览信息条只在深空图层开启时注明相机响应。
- 晨光定义、改机说明、方位约定等常驻说明改为控件提示，第 3 轮统一精简。
- 窄屏（宽度小于 1100 px）：预览与时间轴常驻上方，下方用“地图 / 相机 / 图层 / 信息”标签切换，相机条移入“相机”标签；预览支持双指捏合调焦。横屏时预览在左、标签区在右。原图层与信息抽屉改为标签页；开启图层后切到“信息”时定位对应分组。

### 暂不处理

- 事件刻度、夜间时间轴与当地时区（第 2 轮）；结论化文案、图层并入右栏与详细数值开关（第 3 轮）。
- 拍摄计划、机位格式与会话格式不变；面板顺序和宽度仍只在当前页面保留。

### 验收

- 自动检查：全量测试（更新换位、参数位置与窄屏相关用例）、类型检查与 GitHub Pages 子路径构建。
- Chrome：桌面 1440×900 与 1120×700，手机 390×844 竖屏、844×390 横屏与 360×640。核对预览尺寸、各参数可达、对调与标签切换不重建地图或预览、地图在标签切换后尺寸正确、时区列表不被裁切。

## 第 1 轮执行记录

2026-11-10 完成本地验收。

### 实现

- 删除 `Parameters.tsx`，拆为地图下方的 `PositionBar`、预览下方的 `CameraBar` 与 `Timeline`，数值输入共用 `NumberField`。窄屏由 `(max-width: 1099px)` 判断，相机条只渲染在一处：桌面在预览下方，窄屏在“相机”标签。
- 对调只切换工作区的 `data-order` 与 CSS 顺序，地图与预览不重新挂载；默认地图占 36%，分隔条按左侧一栏换算宽度。
- 焦距滑杆改为对数刻度（`focalSlider`，位置 0—1000），常用焦距对应的位置精确回到该焦距，刻度可直接点选。机位条解析粘贴的“纬度, 经度”（`parseCoordinatePair`），地面高程由预览回传；“相机离地高度”标签缩短为“离地高度”。
- 方位角与俯仰角在预览信息条直接编辑，显示计划原值。曾尝试只显示一位小数，但与地图方向的精确同步冲突，已撤回，数值显示留到第 3 轮处理。
- 大气折射移入左栏环境组；深空相机响应移入右栏深空分组，搜索结果显示期间不出现该设置；预览信息条只在深空图层开启时注明相机响应。晨光定义、改机说明与方位约定改为控件提示。
- 窄屏网格依次为预览、标签、内容三行，横屏为预览一列、标签与内容一列。竖屏取景框高度上限为 34dvh，高度不超过 700 px 时降为 26dvh；横屏低矮屏幕压缩页头。预览按两指间距比例调焦，松开一指后不继续转向。
