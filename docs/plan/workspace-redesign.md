## 第 2 轮：时间轴

### 范围

- 时间轴范围：未开启夜空类图层（星空、银河、深空天体、流星雨、彗星）时为所选当地日期 00:00—24:00；开启任一后改为中午到次日中午，凌晨属前一晚，零点刻度标出次日日期。切换范围不改变拍摄时刻。
- 事件刻度只来自已开启的图层，可点击跳转：

| 开启的图层 | 刻度 |
| --- | --- |
| 太阳 | 日出、日落 |
| 月亮 | 月出、月落 |
| 夜空类任一 | 天文昏影、天文晨光（暗夜起止） |
| 银河 | 银心升起、落下 |
| 流星雨 | 时段中点 ZHR 最高的活动流星雨，辐射点升起、落下 |
| 彗星 | 时段中点最亮的列表彗星升起、落下，按中点位置近似 |
| 空间站 | 可见过境：高度 10° 以上、空间站受照且太阳低于 −6° 的时段，标在起点 |

- 天气效果开启且有数据时，滑杆下方加一条逐小时总云量条；它是读数，不是事件。
- 标签互相重叠时只保留标记，名称与时刻在提示中。开启图层但本时段没有对应事件时，刻度行下方以“本时段无：……”说明。
- 原日月时刻按钮行改为“上一事件 / 下一事件”，与微调按钮同排。
- 出没沿用原日月时刻口径：海平面地平与所选折射，不含地形遮挡。
- 时区列表首项为“当地时区（城市 · UTC±N）”，选中后跟随机位，新会话默认跟随。移动机位时保持 UTC 拍摄时刻，时区随之变化时在时间轴下方提示一次。
- 按坐标查时区采用 `@photostructure/tz-lookup` 11.7.0（CC0），其数据源自 timezone-boundary-builder（ODbL，源自 OpenStreetMap），署名进入 About。边境附近与海上可能不准，可改选固定时区；新疆返回 `Asia/Urumqi`（UTC+6）而非北京时间。
- 机位格式在 v1 内新增可选字段 `time.followLocalZone`（缺省为 false）：旧机位与旧会话保持固定时区；为 true 且未给 `timeZone` 时按坐标求时区。

## 自动匹配的数据源标注（2026-11-10）

- Open-Meteo 的返回不说明 `best_match` 用了哪个模型，且会随地点和预报时效切换。开启天气且选“自动匹配”时，另发一次只含总云量的请求，带上 `best_match` 与 15 个候选模型（JMA、KMA、UKMO、Météo-France、MeteoSwiss、ItaliaMeteo、DWD ICON、NOAA GFS、GEM、CMA、BOM、ECMWF IFS、MET Norway、KNMI、DMI），费用约 1.6 次调用，30 分钟缓存、最多四个机位。
- `src/domain/weather-source.ts` 取拍摄时刻最近的整点，找与 `best_match` 连续一致小时数最长的候选（至少 3 小时，排除晴空或全阴的巧合）；同长时比较整段一致小时数，再按列表顺序。北欧与荷兰的模型在其范围外回落到 ECMWF，因此 ECMWF 排在它们之前。找不到时标“来源未能确定”，请求失败时标“来源未知”，识别中标“识别来源中”。
- 选项显示如“自动匹配（日本气象厅 JMA）”，天气读数的来源行补充“自动匹配此刻的云量来自……”。只比较云量：它驱动预览中的云层；能见度等其他变量可能来自别的模型。
- 实测（2026-11-10）：东京约前 76 小时为 JMA、之后为 ECMWF，首尔前段同为 JMA，伦敦全程 UKMO，纽约、温哥华全程 NOAA GFS，巴黎与柏林前段为 DWD ICON，上海、北京、悉尼、内罗毕、里约全程 ECMWF。浏览器中默认机位当前时刻显示 JMA，5 天后显示 ECMWF。
- 检查：`npm test` 359 项通过（新增识别算法单元检查与选项、来源行的交互检查），子路径构建通过。
- 按用户要求，可选模型加入 ECMWF IFS 9 km（`ecmwf_ifs`，即“自动匹配”在多数地区回落的高分辨率版本，含能见度）。2026-11-11 按用户要求删去 ECMWF IFS 0.25°（不含能见度）：可选模型为自动匹配、NOAA GFS、DWD ICON 与 ECMWF IFS 9 km；已保存机位中的 `ecmwf_ifs025` 读取时改为 `ecmwf_ifs`，这是机位格式中唯一会改写取值的退役项。

## 预览尺寸稳定（2026-11-11）

用户发现更换天气模型时预览会先放大再缩回。原因是取景框占用预览面板的剩余高度，而时间轴的逐小时云量条只在有预报时渲染：换模型时预报清空，云量条消失，时间轴变矮、取景框变大，数据回来后再缩回。

- 原则：取景框周围的行无论有无内容都保持固定高度；数据提示浮在画面上，不占布局。
- 云量条、黄金/蓝调行始终占位，无数据时为空。
- 时间轴底部改为一条固定高度的状态行，按优先级显示输入错误、时区随机位改变的提示、“本时段无”，过长时省略并在提示中给出全文。手动改选时区时清掉已过时的随机位提示。
- 预览信息条固定为一行（桌面 34 px、窄屏 30 px），流星估算、相机响应与引擎避让过长时省略。
- 光污染与天气的失败、过期提示改为浮在取景框顶部。
- 浏览器逐帧量测：1440×900 下开启天气、四次换模型、开关太阳/空间站/深空/光污染、跨时区移动机位、时区提示消失与时间输入错误，取景框始终为 655×436；390×844 下取景框 348×232 与下方标签位置不变。
- 仍会改变尺寸的只有用户主动的布局操作：拖动分隔条、对调面板、切换画幅或横竖幅、选择自定义传感器时相机条多出一行。
- `npm test` 371 项通过，新增一项检查：上述行始终存在、换模型时云量条清空但占位保留、提示位于取景框之上。
