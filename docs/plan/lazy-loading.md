## 2. 原则

1. **行为与结果不变**。同一操作得到同样的结果；命令行、MCP 与 Node 测试直接引用领域模块，不受影响。
2. **读取中与失败分别表达**，不与“图层关闭”“没有结果”混同；失败可重试。
3. **不重建地图与预览**。拆出的部分在读到之前，原位置显示占位。
4. **不加依赖**，不改部署方式。
