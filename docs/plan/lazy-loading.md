- 已经按需读取的：
  - 地图 SDK；

## 2. 原则

1. **行为与结果不变**。同一操作得到同样的结果；命令行、MCP 与 Node 测试直接引用领域模块，不受影响。
2. **读取中与失败分别表达**，不与“图层关闭”“没有结果”混同；失败可重试。
3. **不重建地图与预览**。拆出的部分在读到之前，原位置显示占位。
4. **不加依赖**，不改部署方式。

## 3. 分步

1. **第十八轮：推算模式与 About**（本轮，见第 4 节）。
2. **第十九轮：目录数据按图层读取**：深空、亮星、星座、流星雨、地标、光污染索引与空间站 SGP4，在对应图层开启或推算用到时读取。
3. **之后：真机与跨浏览器检查**：前几轮都写着“实体手机、Firefox、Safari 未测”。需要用户的手机与浏览器；若改用自动化测试浏览器，须经用户同意再下载。

## 4. 第十八轮：推算模式与 About

### 范围

- **推算模块**：
  - 计算、模板、请求转换、地图几何与界面组件合为一个模块（`src/ui/solve/solve-module.ts`）。首次进入推算模式或打开 `#solve=` 链接时读取。
  - `useComposition` 仍在 App 中，只持有状态：条件、选中、编辑、放置、搜索结果与试看前的计划。模块读到前返回空，地图、预览与时间轴不画推算内容。
  - 读取中，推算面板写“推算模块读取中…”；失败写明原因，可“重试”。退出推算模式后模块保留，条件与结果照旧保留。
  - 条件的初始日期改为首次进入推算时的拍摄日期。原为页面打开时的日期，打开后改过日期再进入推算会对不上。
- **`#solve=` 链接**：先读模块，再解析并显示预览对话框；对话框不变。模块读取失败时提示“无法打开推算链接”，并清除链接。
- **地图**：推算结果线的颜色改由推算模块给出天体种类，地图叠加层不再引用天体目录。
- **About**：按钮与对话框框架不变，来源列表在首次打开时读取。读取中写“读取中…”，失败写原因并可重试。
