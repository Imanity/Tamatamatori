# 环境配置与天气显示优化

## 第一阶段

按用户顺序先完成标注连续性、左栏环境配置与预报模型选择，验证后提交推送。

- 同一机位、拍摄时刻和折射配置下，转动相机时延续已经确认的目标方向遮挡结果，文字位置按当前相机更新。新机位、时刻、图层与失败使保留结果失效。右栏的最新遮挡测量状态单独表达。
- 左侧栏在图层组下增加环境组，包含光污染、天气开关与天气的预报模型子设置，手机沿用同一配置入口。
- Open-Meteo 提供自动匹配、GFS、ICON、ECMWF IFS。模型进入缓存键，切换时取消旧请求，数据来源按所选模型显示。可选能见度缺测单独反馈，核心云雨字段缺测继续暂停效果。

验证包含标注在连续转向中的保留、遮挡与故障恢复，模型请求与缓存隔离、迟到响应、缺测，以及桌面和手机的真实 Chrome 画面。

## 第二阶段

随后评估分层云并实现可行的显示近似，再加入雨雪动画。

Open-Meteo 已提供低、中、高云量，分别覆盖约 0—3 km、3—8 km、8 km 以上。当前模型仅区分云量与图案比例，未使用真实云底和空间场。可在现有射线合成中按不同示意高度、形态、颜色与透光区分三层，并让 CPU 透过率与 GPU 共享参数。高度与风场需按显示近似表达。[官方变量说明](https://open-meteo.com/en/docs)

雨雪动画采用独立于拍摄时刻的单调播放时间，雨下落快、雪下落慢并轻微横向漂移。页面隐藏、预览隐藏、关闭效果或无降水时停止连续重绘，恢复后平滑继续。动画不触发天气请求、天体计算或地形加载，尊重减少动态效果的系统偏好。

分层、地平线、高处机位、地形遮挡和雨雪逐帧变化分别验收。真实空间云场和实际云底仍需另行资料支持。

## 第一阶段执行记录

2026-11-07 完成本地验收。环境采用图层组下方的可折叠分组，天气预测模型为子设置，关闭天气时仍保留选择。预览工具栏仅保留构图线。

`npm test` 共 213 项通过，子路径构建通过。模型进入请求参数、取消和缓存身份，最多缓存四个机位与模型组合。ICON、IFS 的能见度缺测独立显示，沿用基础雾混合；核心云雨缺测仍暂停天气。浏览器分别获取四种选择的真实数据，未混用模型补值。供应商接口的模型、字段与插值边界见[官方说明](https://open-meteo.com/en/docs)。

恒星、深空、星座、日月与空间站的标注延续同一观测条件下的已确认遮挡。转向时按当前实际相机投影，新的测量结果更新标注，右栏仍按本轮查询状态显示。保留结果只作显示连续性使用，机位、时刻、离地高度、折射、图层、轨道或渲染失败使相关保留状态失效，尚未测到的目标继续等待。

Chrome 使用 `index-BWP9toXS.js`、`index-db_hJWpU.css`。保存[7 组场景](environment-evidence/browser-results.json)，包含[星空与深空](environment-evidence/01-night-labels.jpg)、[拖拽后](environment-evidence/02-after-drag.jpg)、四个模型与[手机环境入口](environment-evidence/07-mobile-environment.jpg)。真实往返拖拽期间[60 次公开 DOM 采样](environment-evidence/drag-samples.json)中，参宿七及猎户座大星云的标注均存在，位置随视角变化。此为连续采样，采样间隔由工具连接决定。

首次完整自动检查出现组件进程内存退出，并发现新检查的固定云量期望值写错。核对投影视角反馈优先级并修正期望后，完整重跑 213 项通过。浏览器初次预览服务漏设子路径，修正启动参数后重新加载。直接在受限读取环境中调用逐帧 API 失败，连接恢复后改用公开 DOM 轮询，失败采集未记作通过。最终[浏览器错误日志](environment-evidence/browser-console.json)为空。
