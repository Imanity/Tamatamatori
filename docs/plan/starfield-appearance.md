# 星空的暮光与月光明暗

更新：2026-11-05。上一轮星空/银河首步已提交推送为 `5a6dc4b`。本轮只增加星空明暗的构图近似，不修改天体方向、地形、日月圆盘或既有环境配色。

## 本轮范围

- 太阳几何高度驱动星点与银河淡入淡出；明亮恒星与金木星比暗星保留更久，白昼隐藏星点和银河轮廓。
- 月光按月亮亮面比例和几何高度降低星点与银河对比度。月亮图层关闭、月亮在视场外仍参与；地平线下不参与。
- 主要目标保留方向与主动朝向；银心空心环和名称属于定位参考，银河轮廓淡出时仍可按 DEM 遮挡显示。
- 明暗隐藏不作为山体遮挡证据。GPU 遮挡查询独立于可见度透明度；“天空较亮”与“山体遮挡”分别显示。

暂不处理：曝光、光污染、天气、观测波段、消光/空气质量、月亮附近眩光、真实极限星等、真实银河表面亮度或新天体类型。显示阈值是本产品的视觉选择，不作为天文预报值。

## 验收

- 固定输入检查暮光分界连续性、白昼/暗夜端点、不同星等排序，以及新月/满月、月出/月落与非法输入。
- 同一 UTC 的显示时区、朝向、镜头、画幅与图层开关不改变明暗模型；不重复请求 DEM，不重建地形。
- GL 替身验证透明星点仍执行独立几何查询；明暗变化不误报山体遮挡，失败/过期及卸载资源检查继续通过。
- Chrome 检查无月深夜、强月光夜间、暮光与白昼，主要星点/银河变化及银心参考、默认布局与既有遮挡。

## 边界与下一小步

这里的透明度与显示阈值是构图显示参数，不是测光值、实际极限星等或拍摄成功率。仍不包含光污染、天气、曝光、波段、视线消光和月亮附近眩光；银河依旧是解析轮廓。下一小步建议补充星座连线与主要名称，帮助理解星空朝向，另行核实连线数据来源与许可。
