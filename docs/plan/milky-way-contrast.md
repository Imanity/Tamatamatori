# 银河显示对比度

更新：2026-11-05。用户要求先提交推送银河细节，再继续上一轮建议的对比度调节。

## 范围

在左侧银河开关下提供 25%—200%、步长 5% 的对比度滑杆，默认 100%，提供一键重置。开启银河时显示，关闭时保留数值；与其他面板共享同一拍摄计划，收起侧栏、交换面板不重置。只调节银河纹理的显示强度，不改变星点、银心环、地形/天空、方向、时刻或镜头，不模拟真实曝光。

显示系数与现有暮光/月光权重相乘；白昼仍淡出，强月光仍减弱。只更新 uniform，不重新上传纹理、重建顶点、加载 DEM 或作废目标遮挡查询。显示系数不参与位置/摄影相机的缓存键。

## 验收

- 25%、100%、200% 的显示强度按预期变化，非法值不得传给 GL；白昼最大值仍为零银河亮度。
- 组件检查滑杆/键盘、重置、关闭重开与布局切换保留值，其他拍摄参数和遮挡状态不变，无新增 DEM/纹理请求或天体重新计算。
- Chrome 固定同一暗夜构图对比低/默认/高值，检查夜间、月光、白昼与山体遮挡，保存截图和记录。类型检查与全量自动检查通过。
- 本次指令先发布既有银河细节；继续开发的对比度改动先在本地验收，不自动提交推送。
