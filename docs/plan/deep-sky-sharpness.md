# 深空长焦清晰度修正

2026-11-05。用户指出 M45、M8、NGC7000 长焦过于模糊。本轮只修复这三图的细节保留与纹理分辨率，不新增目标、曝光或天文模型。

本地验收完成：2026-11-06。此轮恢复高频时保留了照片星场，后来用户指出矩形边界明显；它不是边界融合通过的依据。后续修正见[边界融合](deep-sky-boundary.md)，本页保留 5f9bebb 的历史记录。

## 原因与方案

上一版对 M45 作 31 像素开运算和 8 像素高斯平滑，北美作 15/2 像素处理，M8 也经过中值/形态滤波；实际星云细丝、暗带及小尺度结构被一起去掉。完整来源压在每格 1024 像素中，长焦进一步放大损失。旧版广角结构验收不能作为长焦清晰度通过依据。

保留原始 RGB 的高频信息，低频去星副本仅用于背景估计，不再对最终图像整体去星和模糊，不做后期锐化或生成细节。允许照片中的残余恒星作为参考影像的一部分，但不能把它们当成新增精确星历。

在单张 4096×4096 atlas 中给 M45/M8 各分配 2048×1024、北美 2048×2048 的矩形区域；其余五图保留 1024×1024 与原有像素。UV、配准检查和设备上限回退按区域实际宽高处理。相比统一增至 8192 像素纹理，控制 GPU 开销；此布局是当前八图的固定布局，不引入打包框架。

优先下载同一发布图的原始分辨率版本，并核对许可、图像范围、AVM 与哈希。不得只放大低分辨率 JPEG 并宣称获取了新细节。范围、角尺寸、色彩模式、地形遮挡和资料署名继续保留。

## 验收

- 独立 WCS 对照支持矩形图格，完整来源足迹、不重叠布局、边界不串色、设备 MAX_TEXTURE_SIZE 回退和 RGBA 数据语义均核对。
- 保存当前图集作为本地对照，检查三个目标在固定 600/1000 mm 构图中的细丝、暗带、星点清晰度；宽幅不能恢复明显矩形背景、局部圆洞或椭圆截断。
- 复核 M45 两种响应不变、M8/北美的额外红色增强，以及白昼隐藏和 DEM 遮挡。保留真实 Chrome 画面，不用数值指标代替视觉判断。
- 对其余五图逐像素比较；匹配的自动测试、类型检查与子路径构建通过后再记录完成。先本地完成，不默认提交或部署。

## 执行结果

- 三份资料切换至同一发布图的原尺寸 TIFF：M45 1438×968、M8 2179×1469、北美 2758×1890。内嵌 AVM 与原 JPEG 完全相同，原图缩小后与旧 JPEG 的像素相关系数均超过 0.992；没有换成其他视场或假色资料。输入文件哈希保留在来源清单中。
- 取消最终影像的整体中值/形态/高斯滤波，过滤副本只用于背景估计。来源边缘过渡为 40 个工作像素，约原宽度的 1.5%–2.8%；原始细节和星点保留，不补造来源之外的资料。
- `npm test`：155/155 通过，增加固定天球裁区的模糊回归检查及五个旧图格的 RGBA 哈希检查；矩形区域不重叠、像素边界、UV 像素中心、设备上限回退和响应独立性均覆盖。指标只防止重新套用强模糊，不把高频能量增加等同于实景精度或视觉质量倍数。见[固定参考](../../tests/fixtures/deep-sky-sharpness.json)。
- PyAVM/Astropy/WCSLIB 独立核对 125 点和完整足迹，最大转换差约 5.30e−11 个参考像素；支持非方形区域，不代表来源本身的天球测量精度。见[配准记录](deep-sky-sharpness-evidence/image-registration.json)。
- `npm run build -- --base /Tamatamatori/` 通过，包含类型检查；未新增 npm 或运行时依赖。保留既有大分块提示。
- 最终 PNG 为 4096×4096、11824096 bytes（约 11.28 MiB），SHA256 `5f9bebb65cf54325b6b5b33118099875a4baf2fcc1954d239ffb7eeb8f4fa31f`。M31、M42、加州、心脏、灵魂的 1024 方格只搬位置，像素完全不变。GPU RGBA/mip 约 85 MiB，无损文件预算上限为 14 MiB；首次加载体积增加，仍按需请求和按设备上限缩放。
