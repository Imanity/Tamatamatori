# 拍摄参数交互优化

2026-11-09 按用户四项界面意见实施，本地验收完成，未提交推送。

## 范围

1. 分享对话框：展开的 JSON 栏与分享码栏同宽。
2. 时区列表：删去“全部时区 · 按拍摄时刻的 UTC 偏移排列”标题，改用分隔线；“常用”分组和按偏移的排序不变。
3. About：地标模型改为卡片列表，排版与深空影像一致。
4. 拍摄参数：重做拍摄时间的操作；相机离地高度增加滑条。

暂不处理：

- 焦距滑杆仍为线性。
- 时区仍由用户选择，不按机位推断。
- 不提供地形遮挡下的实际见日时刻，也不加银河核心、月相等其他事件。
- 拍摄计划字段与机位格式不变。

## 拍摄时间

```text
当地日期          周三   当地时间
[‹] 2026/11/04 [›]     [16:47:30]
━━━━━━━━━━━━━━●━━━━━━  ← 色带：当日太阳高度
00:00  06:00  12:00  18:00  23:59
[−1时][−10分][−1分][现在][+1分][+10分][+1时]
[晨光][日出][日落][昏影] [月出][月落]
```

- **日期**：两侧加“前一天 / 后一天”，保留当地钟点；标签旁显示星期。目标日期上该钟点因夏令时不存在或重复时，保留原时刻并提示。
- **时间输入**：与日期同排，字号加大，仍可编辑到秒。
- **滑杆**：独占整行，桌面有效宽度约 263 px，约 5.5 分钟/像素（原先与日期同排，宽度约为现在的一半）；仍只覆盖所选当地日期。
- **色带**：滑杆背后按当地钟点每 10 分钟取一次太阳几何高度，分为夜间、天文/航海/民用暮光、低角度日照、白昼六段。滑杆朗读文本同时报出当前所处阶段。
- **微调**：±1 分、±10 分、±1 时按绝对时刻移动，可以跨过午夜和夏令时切换。“现在”取设备时钟，向下取整到分钟。
- **日月时刻**：列出所选当地日期的晨光、日出、日落、昏影、月出、月落，点击后拍摄时刻设为该时刻（精确到秒），与当前时刻一致的按钮高亮。
  - 晨光、昏影：太阳中心位于地平下 18°。
  - 日月出没：上缘位于海平面地平。折射按参数区的“大气折射”设置，采用与预览相同的折射模型，并用事件时刻的实际视半径，因此跳转后预览中的日月上缘正好落在海平面地平上。
  - 当地日期内没有某事件（极夜、极昼、白夜无天文晨昏，或月亮当天不出/不落）时，按钮显示“—”并禁用，悬停与朗读说明原因。
  - 时间区下方注明：日月出没按海平面地平计算，不含地形遮挡。

计算位于 `src/domain/time/day-events.ts`。观察者与渲染天空相同，位于参考椭球面 0 m。当地日按时区取 00:00 至次日 00:00，夏令时切换日为 23 或 25 小时。搜索使用 astronomy-engine 的 `SearchAltitude`，日月出没先用平均视半径求一次，再按该时刻的视半径重求。只在日期、位置、时区或折射变化时重算；Node 下每次约 1.9 ms（六个事件）加 4.3 ms（色带）。

## 相机离地高度

- 数字输入不变，下方增加滑条，对数刻度覆盖 0.1—100 m，刻度标 0.1、1、10、100 m。
- 10 m 以下取 0.1 m，10 m 及以上取整米。
- 方向键每次改变一个单位，避免滑条一格小于取整单位时按键无效。

## 其他三项

- **分享 JSON 宽度**：Chrome 把 `<details>` 内容包在独立的盒子中，原先对 `details` 设的网格拉伸到不了文本框，文本框只按默认列数约 231 px 宽。现改为块布局。
- **时区列表**：“常用”标题改为不吸顶，否则没有第二个标题时它会一直停在顶部。
- **About 地标**：每处地标一张卡片，包括：
  - 名称作标题；
  - 模型与作者链接；
  - 许可、非商业限制（强调色）与处理说明；
  - 折叠的“定位、朝向与参考资料”；
  - 两个下载入口，文字不再重复地标名称。

  署名内容仍全部来自生成目录，未逐模型手改。

## 已知限制

- 日月出没按海平面天文地平计算，不含山体与建筑遮挡，也不含相机高度带来的地平俯角；山区或高处实际见到日月的时刻会不同，需要结合预览判断。
- 色带按太阳几何高度分段，不反映天气、月光或光污染。
- “现在”依赖设备时钟。
- 滑杆仍只覆盖所选当地日期，跨日要用微调或前后一天。
- 未测实体手机。
