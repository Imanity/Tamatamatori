# 银河细节

更新：2026-11-05。

本轮只细化已接入银河的视觉结构：以随包分发的全天全景衍生纹理替换规则亮带，展示银心亮云、非对称盘面与暗尘裂隙。维持现有银河开关、银心方向、日月明暗、参考折射和 DEM 遮挡；不扩展星表、深空天体或真实曝光模型。初始本地验收后，用户已授权提交推送本步并继续。

## 数据与边界

候选已核实：[ESO eso0932a](https://www.eso.org/public/images/eso0932a/)，6000 × 3000，署名 **ESO/S. Brunier**，按 [CC BY 4.0](https://www.eso.org/public/outreach/copyright/) 使用和修改。采用银河平面水平、银心居中的全景；银经增加方向与银纬上下方向必须用独立恒星/银心参照检查。素材是摄影拼接全景，存在投影/拼接和摄影色调误差，不继承星历的角度精度。

只提取银河平面附近的低频外观，抑制照片里的亮星/行星，避免把历史天体位置当作当前目录目标；不保证完全去星。记录输入 SHA-256、转换步骤及输出哈希，附生成脚本。运行时只请求本站静态纹理，不依赖 ESO 在线服务；署名保留在预览底部和第三方许可。

## 验收

- 网格与纹理方向：闭合无镜像/接缝，银心与天鹅座/南十字等方向交叉检查；保留独立 ERFA 方向回归。
- GL：按需加载、失败提示、图层关闭与卸载不迟到上传；不污染宿主纹理绑定与像素解包状态，纹理/查询正确释放。
- 实际 Chrome：固定暗夜银心与天鹅座，旋转/缩放无屏幕粘连，南北半球方向正确；晨光/月光减弱，地形遮挡与关闭恢复正常。图片失败与重试状态单独检查。
- 完成匹配的自动检查和子路径构建，保存真实截图与执行记录；未执行项不能标为通过。

- `npm test` **139/139** 通过；`npm run build -- --base /Tamatamatori/` 通过，含类型检查。新增检查覆盖按需加载、关闭/卸载取消、迟到图片释放、下载与上传失败隔离、12 秒超时、关闭重开恢复、复用纹理和 GL 纹理/采样器/解包状态恢复，以及搜索开启时的错误反馈。54 个独立 ERFA 方向的最大差仍为约 0.002473°，只验证坐标方向，不代表摄影纹理精度。
- **Chrome 真实 GPU**：山中湖 35.4172°N / 138.8729°E、35 mm、东京时间 2026-07-16 00:00、方位 200° / 俯仰 20°，保存[原效果](milky-way-evidence/before.jpg)与[细节效果](milky-way-evidence/after.jpg)。银心附近明亮云团与暗尘结构替换规则亮带；天空、地形和目标共享原有相机和遮挡。
- 检查[天鹅座](milky-way-evidence/cygnus.jpg)、[8 mm 广角](milky-way-evidence/wide.jpg)、[悉尼南半球](milky-way-evidence/southern.jpg)及 1000 mm 竖幅，纹理随朝向/视场转动，未见明显裂缝、屏幕粘连或图形错误。南北半球只作整体方向与结构的粗核对，未进行逐点照片定标或全年/全球覆盖验收。

- **子路径与失败恢复**：独立临时静态服务使用实际 `/Tamatamatori/` 构建，首次纹理请求主动返回 HTTP 503。[失败截图](milky-way-evidence/load-failure.jpg)显示搜索状态下仍有明确提示，地形就绪、亮星和银心继续可用；关闭重开后第二次请求成功并恢复细节。临时服务不进入应用或生产构建。各场景的 DOM、实际遮挡读数及控制台记录见[浏览器记录](milky-way-evidence/browser-results.json)。

## 限制与下一小步

摄影全景并非精密星图，仍可能残留未解析星点、行星光晕或星云；本轮压低这些点源但不保证全部去除，不将纹理中的亮斑作为新的可定位天体。未量化照片拼接角误差、现场颜色或曝光；纹理约 0.088°/像素，长焦只放大现有纹理，不能生成新细节。银心和亮星的精确参考仍只来自既有坐标计算；高程、折射、月光和晴空模型的原有限制不变。
