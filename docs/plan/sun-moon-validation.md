# 日月渲染验收

本记录保留日月首版 SVG 的验收结果。后续已改为共享地形深度的三维图层并接入标准折射，当前执行结果见[山体遮挡与折射验收](occlusion-refraction-validation.md)；下文的未实现项仅描述当时版本。

更新：2026-11-04。状态：本轮日月构图辅助已完成数值、组件及 Chrome 基础画面检查；地形遮挡与实拍精度不在通过项中。

本轮检查日月圆盘的角位置、角尺寸、月相外观与图层交互，不验收真实曝光、大气折射、天气、山体遮挡或日月食。

- 数值：固定日期与观测点，对照 JPL Horizons 无折射的太阳、月亮方位、高度、角直径与距离；检查 UTC 与时区不变性。
- 投影：完整三维方向变换与现有 SDK 相机一致，包含 8—1000 mm、横竖幅、真北与天顶；部分圆盘在画面内和跨几何地平线时有正确裁切。
- 月相：新月、上下弦、满月的亮面与比例、盈亏和亮侧朝向；不将地平线以上等同于可见。
- 交互：日月独立开关，明确区分关闭、视场外、地平线下与计算失败；主动居中只改方向；调时、换位与窄屏恢复保留开关和计划。
- 浏览器：固定山中湖机位 35.4172 / 138.8729，使用同一天的白昼太阳、夜间月亮和至少一组长焦/月相画面，留存参数与截图。

## 执行结果

全项目 69 项测试通过，构建通过；保留既有 MapLibre 大包体提示。本轮新增 8 项日月领域检查、1 项真实 SDK 投影检查、1 项图层交互检查；交互检查也使用真实全局样式验证开关不继承文本输入框尺寸。

### 数值与 SDK

独立样本从 JPL Horizons API 一次性取得并固化到 [sun-moon-reference.json](../../tests/fixtures/sun-moon-reference.json)，CI 不请求远端。两组地点为山中湖 35.4172 / 138.8729 与悉尼 −33.86 / 151.21；各取日月的两个相邻分钟，共 8 条记录。均采用参考椭球面高度 0 km、AIRLESS、UTC，保留完整查询 URL。

| 指标 | 本轮比较容差 | 8 条样本内最大差值 |
| --- | --- | --- |
| 方位 | 0.05° | 约 0.00144° |
| 几何高度 | 0.05° | 约 0.00028° |
| 角直径 | 0.002° | 约 0.1251 角秒 |
| 相对距离 | 0.001 | 约 0.00006592 |
| 月面亮区比例 | 0.003 | 约 0.00001279 |

上述差值只覆盖固定样本，不代表整个 1900—2100 年或全球精度上限。另以 [USNO 月相记录](../../tests/fixtures/moon-phases-reference.json) 的 2026 年 11 月新月、满月、上下弦 UTC 时刻核对盈亏阶段，月相角在 0.1° 容差内；测站亮面比例与理想新、满、半月比较容差为 0.015。相机在 8/35/200/1000 mm、横竖幅、0/35/90° 俯仰和 0/247/359.8° 方位的 72 组配置下，与真实 SDK CPU 投影比较至少 144 个方向，偏差不超过 0.1 CSS px。此项不创建 WebGL，也不验证真实 DEM 的防碰撞校正。

圆盘边界与月相另用合成方向检查：中心离开画面后仍保留可见圆盘部分；跨几何地平线只绘制上方部分；背向与天顶不产生无穷坐标；亮区面积与比例相符，亮侧朝光源，未设置视觉最小角尺寸。

## 边界与下一步

月相仅检查了本轮残月的真实画面；新、满、上下弦通过数值与合成亮区几何验证，未分别执行 GPU 截图。当前圆盘是构图辅助 SVG，不参与地形深度测试，可能覆盖山体；观测高度、折射、真实曝光、地照、月面纹理及日月食均未验证。不能将“画面内”表述为实际可见。

下一小步优先实现并验证日月与地形遮挡的联动；原有地形与网络恢复待验项继续见[地形验收](terrain-validation.md)。本轮不将 P2 或 P3 整体标记完成。
