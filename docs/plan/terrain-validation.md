## 本轮范围

检查现有山体与静态水体预览能否稳定表达机位、朝向和镜头构图；本轮不接入天空、天文图层或水面特效。发现能复现的产品问题再修复，不凭数值测试结果推定实景精度。

固定输入保存在 [terrain-scenes.mjs](../../tests/fixtures/terrain-scenes.mjs)，相机验证保存在 [camera-calibration.test.mjs](../../tests/core/camera-calibration.test.mjs)。运行全部检查使用 `npm test`；只运行地形与相机数值检查使用 `npm run test:terrain`。Windows PowerShell 如禁止运行 npm.ps1，可使用 `npm.cmd`。

## 本轮发现与修复

1. 长焦参数更新后，画面可能停留在原构图。实际控制台出现 canonical 瓦片 z26 越界：高虚拟缩放配合 SDK 默认矢量过缩放策略，可能超出其 z25 上限。预览明确设置过缩放参数，使矢量覆盖沿用来源原生层级，同时保留固定眼点所需的相机缩放范围。
2. 俯仰恰为 0° 时仍可能越界。SDK 地形细节层级计算在眼点所在瓦片遇到 0/0，导致覆盖遍历继续细分。渲染角在零点附近保留 0.0000001° 的微小偏移，小于现有校准容差；拍摄计划与界面仍表示请求的 0°。

修复后重新加载并复测上述场景，长焦及水平视角均能更新，无相同控制台错误。两类问题加入真实 SDK CPU 瓦片覆盖回归，不用 SDK 测试替身证明修复。

本轮仅修复用户反馈的地形消失，不增加图层或改变投影算法。以下结果补充历史验收，不替代后续空间投影及高程基准记录。

在实际运行的 `127.0.0.1:5173` 上复现：高程读取成功、画布尺寸有效，但预览只剩背景；控制台反复报告 `u_photo_enabled` 在顶点与片元着色器中的精度不一致。服务仍供应 `.vite-terrain-4f394a08f424` 旧预构建，其中两阶段均未显式指定 highp；当前源码及已安装 SDK 均已显式指定 highp，当前输入签名则为 `b056831f7ff4`。这是旧开发服务没有随共享 GLSL 更新重新计算缓存造成的，不是 DEM 覆盖缺失。

- 真实 Chrome：当前 5173 默认富士山场景恢复；预览换到主栏后取景框 1068×712 CSS px、地形就绪，[恢复画面](terrain-cache-evidence/fuji-restored.jpg)可见山体与前景地表。

## 2026-11-05：低视角近处白色面片回归

本轮只修复近处三角面片的颜色异常。在山中湖固定机位 35.4172 / 138.8729、朝向 247°、8 mm、全画幅横幅 3:2、计划俯仰 −8°、离地 1.6 m、东京时间 12:00 复现大片白色三角形，[修复前画面](terrain-near-evidence/before-8mm.jpg)可见前景明显断裂；地形已就绪，控制台无 error。

问题来自雾效：顶点在相机前后分别执行雾坐标的透视除法，随后插值；跨裁剪面的面片可能得到远超 1 的雾深度，使颜色混合越界。现改为传递齐次雾坐标、逐片元相除并限制混合范围，见[架构说明](../architecture/terrain-perspective.md)。主地形投影、近裁剪与对数遮挡深度保持原定义。

验证结果：

- 同一计划与时间下，[8 mm 修复画面](terrain-near-evidence/after-8mm.jpg)中不再出现白块。SDK 避让后的实际眼点可能随初始化状态不同，不把前后截图当成相同实际相机的像素精度测量。
- 计划离地 0.1 m、俯仰 −20° 时，实际离地约 2.23 m、俯仰 −25.51°，[低机位画面](terrain-near-evidence/after-low-height.jpg)无同类白块；8 mm 竖幅、计划俯仰 −60° 时，实际离地约 3.93 m、俯仰 −64.69°，[竖幅俯拍](terrain-near-evidence/after-portrait-down.jpg)仍正常。
- 真实鼠标拖拽使计划变为约 237.659° / −19.258°，实际离地约 2.13 m、俯仰 −20.67°；1068×712 CSS px 取景框内未再出现白块，[拖拽画面](terrain-near-evidence/after-drag.jpg)及[浏览器记录](terrain-near-evidence/browser-check.json)已保存，验证标签页 error 日志为空。
- 200 mm、离地 1.6 m，15:45 朝向太阳后固定相机，15:48 仍为“部分山体遮挡”，[遮挡回归画面](terrain-near-evidence/sun-regression.jpg)可见山脊正确裁切太阳。
- `npm test` 共 97 项通过；新增跨近裁剪面齐次插值反例，检查旧雾深度越界、近景无雾及远处混合范围，并检查实际安装的原始 GLSL、生成模块与 ESM 使用同一新内核。CPU 反例不代替以上真实 GPU 画面验证。
- `npm run build` 通过，仍有既有 MapLibre 大分块提示。使用 npm 原始 6.16.0 包进行隔离补丁验证，7 个相关文件在首次安装、已有安装升级与重复执行后内容一致，[安装记录](terrain-near-evidence/patch-install.json)保存哈希与幂等结果。

本轮没有校准近景地表精度或真实水位，低机位仍保留 SDK 避让反馈。白色面片问题的固定复现已通过，可以回到银河位置与轮廓的后续小目标。
