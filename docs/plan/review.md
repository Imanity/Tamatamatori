# 整体评估与后续方向

状态：2026-11-15 按用户要求通读项目，评估交互上可优化的地方和还能实现的功能。第 1—5 节为评估；用户随后选定的第一批优化见第 6 节，已完成本地验收并按用户授权提交推送。更新：2026-11-15。

## 1. 现状

- **功能**：
  - 地图选点与朝向、三维地形与水体预览、镜头与画幅、时间轴；
  - 日月、星空、银河、星座、深空、空间站、流星雨、彗星、极光、潮汐、日月食、建筑与 21 处地标、天气与光污染；
  - 机位保存与分享；
  - 推算：构图约束搜索，支持命令行与 MCP。
- **质量**：
  - 自动检查 504 项，本地约 34 秒，CI 每次 2—3 分钟；
  - 首屏 JS 827 KiB（gzip 284 KiB），另有地图 SDK 约 1 MiB；
  - 计划文档 67 份，其中“暂不处理 / 限制”共 189 条。
- **没有验证过的**：
  - 实体手机、Firefox、Safari（用户决定不做）；
  - MCP 服务器在桌面客户端中的实际接入。

## 2. 交互与体验

按“影响大、改动小”排序。

| # | 现象 | 建议 | 改动 |
| --- | --- | --- | --- |

| 9 | 没有网站图标和 PWA 清单，手机“添加到主屏幕”后只是普通网页 | 加图标与清单（名称、主题色、竖屏启动） | 小 |

## 3. 可以实现的功能

### 3.1 改动小、价值明确

| 功能 | 说明 | 依赖 |
| --- | --- | --- |
| 时间播放与轨迹动画 | 按设定步长自动推进时间：看日落过程、星空转动、空间站过境 | 无，复用现有绘制 |
| 夜间红光模式 | 野外夜拍时屏幕整体变暗、偏红，保护暗适应 | 无，主要是配色 |
| 推算结果结合天气 | 7 天内的结果标注云量与降水，可只看“可能晴”的结果 | 已有 Open-Meteo 接入；注意每个结果一次请求的用量 |
| 预览导出图片 | 导出当前预览，附时间、机位与镜头参数，便于分享与留档 | 需要从 WebGL 画面取图 |
| 实拍照片叠加 | 上传实拍照片半透明叠加到预览，用于核对构图、复盘与校准 | 照片只在本机处理，不上传 |
| 曝光与景深估算 | 按 NPF 规则给出不拖线的最长曝光，并给出超焦距 | 原计划“精确曝光”暂缓，需用户确认是否纳入；须标明是估算 |

## 4. 工程与质量

- **AGENTS.md 过长**：325 行、约 70 KB，大部分是逐轮执行记录，每个会话都要读入。建议只保留规则与当前状态，历史记录留在各计划文档。
- **没有代码检查工具**：没有 ESLint 与 Prettier，部分文件的写法压在一行。可先只加 react-hooks 规则，它能查出依赖遗漏，不批量改格式。
- **布局没有自动检查**：jsdom 不计算布局，两轮手机布局调整只能靠内置浏览器人工测量。如需自动化，可以用 Playwright 截图比较，但要先经同意下载测试浏览器。
- **Temporal 补全约 160 KiB**：Chrome 与 Firefox 已有原生 Temporal，可按需加载补全；但各引擎的时区数据可能不同，要先验证一致性。
- **两项未验证**：实体手机与跨浏览器；MCP 桌面接入。

## 5. 建议顺序

1. **一轮小改**：默认时间改为“现在”（第 2 节第 1 项）、文字可读性（第 3 项）、图标与 PWA 清单（第 9 项）。
2. 时间播放与快捷键（第 2 节第 4 项，与第 3.1 节合并做）。
3. 场景预设与推算结果的排序、筛选（第 2 节第 5、6 项）。
4. 推算结果结合天气。
5. 行星，以及空间站凌日、凌月。

第 3.3 节各项与“曝光估算”、AGENTS.md 精简，先由用户决定是否纳入。

银拱的计算：

- 银道（银纬 0°）是天球上的大圆，与地平线交于相对的两点，所以银拱两端的方位总是相差 180°。
- 最高点在银极与天顶所在的竖直面上，高度为 90° 减去银极高度的绝对值。
- 方位与高度按所选折射修正；最高点低于 10° 时说明“银河贴近地平线”，不提供朝向。
- 银道正好经过天顶时，两侧方位等价，取计算所得的一侧。

验收：

- 银拱最高点与按 0.01° 逐点采样银道（与银河网格同一坐标变换与折射）所得的最高点，方位与高度差都不超过 0.05°。
- “朝向”后的方位与俯仰与上述定义一致。
- 新会话的拍摄时刻为打开页面的那一分钟；刷新恢复的会话保持原时刻。
- 保存、改名、删除机位后，地图标记随之更新（同页多处机位库实例同步）；单击标记打开卡片，“应用”后计划与机位菜单一致，可撤销。
- 自动检查与子路径构建通过；内置浏览器核对页头、银拱朝向后的预览与地图上的机位。
