# 实际地形空间投影修正

更新：2026-11-05。状态：默认预览已启用实际网格投影修正；本地数值、真实 Chrome、生产构建与隔离安装验收通过，可继续接入其他天体。

## 目标

按用户要求，直接推进到可继续接入其他天体的渲染基础。修正实际山体和贴附水体的 Mercator 平面方向误差，使地形、实际相机与日月共享局部东、北、天方向及主绘制深度。本轮不新增其他天体、真实水位、天气或部署。

保留固定 MapLibre、既有 DEM LOD、颜色和加载机制，通过明确的本地 SDK 桥接修正地形顶点，而非二维移动图像或参考标记。高度沿用同源数值作为条件参考曲面；不解决未知基准与实际地面大气导致的误差，不启用未经证实的垂直转换。

## 验收判据

- 独立 ECEF/ENU 参考对照 CPU 计算和 GPU 同一顶点程序；固定场景 8—1000 mm、横竖幅的 GPU 投影残差以小于 0.1 CSS px 为本轮目标，不能等同于实景误差。
- 显示真实曲面山体和静态水体，验证镜头、方向、机位、布局及昼夜更新；默认地图不启用修正。
- 日月物理圆盘继续共享主地形深度，真实 Chrome 验证露出、部分和完全遮挡，以及月亮与画幅切换。
- 补丁可重复安装，源码/ESM 一致，失败明确；保留既有加载、失败重试、取消及资源释放检查。
- 达标后更新文档，明确后续天体可以沿用的方向/投影边界及仍未知的数据精度。

## 实现结果

实际地形顶点采用 WGS84 → 实际眼点 ENU → 摄影机位投影。保留 Mapterhorn DEM、既有屏幕 LOD、土地覆盖色、阴影和水体边界；水体与地形在同一网格上变换，日月仍绘制到相同主深度缓冲。主地形使用对数深度，避免低近裁剪下远山表面深度量化。具体数学和本地 SDK 桥接见[实现设计](../architecture/terrain-perspective.md)。

正常页面默认启用，不需要校准 URL。取景框标注“曲面构图 · 高程基准未核定”，不将高程自动转换为真实椭球高；原计划参数、地图浏览与实际渲染姿态继续分离。普通地图没有安装坐标桥接，仍使用原地图投影。

地图“定朝向”已同步改为参考椭球点的 ENU 水平方位，并移除 0.1° 量化；扇形与方向把手保持该方位。独立 PROJ 零高度固定样本见 `tests/fixtures/geodetic-reference.json` 的 `mapSurfaceBearing`，不把球面近似或输入截断重新引入长焦构图。地图点没有独立高程，仍不自动设置俯仰或识别可见山脊。

这些结果确认实际使用的投影核和方向约定一致，不测量实际照片误差，也不包含 DEM 三角网插值相对真实地表的误差。

## 可以继续的工作与限制

下一小步可以接入银河位置与轮廓：使用同一 ENU 方向、实际相机、传感器视场、天空深度及地形遮挡，无需再次建立一套地形投影。深空天体可以随后沿用该基础。尚未接入的新图层仍显示规划中。

已知限制包括源 DEM 分辨率及高程基准、三角网插值、缺失的远地形、建筑植被、地面大气折射、参考点坐标精度和独立水位。现有天文图层仍采用 0° 参考天文地平线，未加入海平线俯角或地平线下可见性校准。正式现场触山时刻、真实水面和米级实景精度仍未验收；这些问题不阻止后续天体的构图辅助接入，也不能被本轮亚像素数值结果掩盖。
