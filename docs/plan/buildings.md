# 建筑体块首步

2026-11-07，按[可行性评估](buildings-feasibility.md)推进普通建筑原型。后续已完成[跨瓦片预算修复与城市画面验收](building-budget.md)：229 项检查、真实 DEM 下的东京/上海、宽幅长焦、拖动开关与手机视口已核对。固定天体相交遮挡、坡地接缝、夜间天气合成与运行帧耗时仍待专项验收。下文保留首版执行历史，不以旧加载策略作为当前行为。

建筑默认关闭。首版按机位加载约 2 km，现已按[远景优化](building-distance.md)扩大至约 5 km，远景采用高度筛选与独立预算份额。复用既有 DEM 高程、WGS84 / ENU 摄影投影与对数主深度，支持体块、孔洞、分部底高、地形与天空遮挡。时间只改变材质明暗，拖视角、调焦不重新获取建筑。来源与限制收束至右栏和 About。

首步采用公开 custom layer，自行解码有限瓦片及三角化，不改动 SDK 建筑着色器。缓存、请求和网格有界；高纬或密集地区触发范围/网格上限时显示不完整，失败、空数据与关闭分别反馈。建筑更新使旧遮挡标注失效，新机位不沿用旧几何。暂不接入精细地标、真实屋顶、纹理、夜景灯光、全球建筑搜索、后端或第二套渲染器。

设计见[交互与反馈](../design/buildings.md)，技术边界见[建筑架构](../architecture/buildings.md)。验收包括独立几何固定输入、解析/预算/取消与迟到响应、GL 状态和生命周期、东京/上海实际 Chrome 城市画面、24/85/200/1000 mm、建筑挡天体/山体挡建筑、关闭恢复、手机布局与性能。CPU、GL 替身和真实 GPU 分别记录，不将源高度视为实测精度。

## 首版本地执行结果（历史）

- `npm test`：226 项通过。新增固定输入检查覆盖含内院的屋顶面积、架空底高、坡地下裙、MVT 解析、`hide_3d`、非法高度、日期线、高纬范围上限、真实源码 WGS84/ENU 对照、缓存、取消与迟到响应、GL 状态和资源回收。React 检查覆盖左右栏入口、调焦复用、独立错误/重试与 DEM 实例不重建。
- `npm run build -- --base /Tamatamatori/`：通过。保留既有 MapLibre 大包和 satellite.js WASM 引入 Node 模块的兼容提示；未增加引擎或 SDK 补丁。
- 标注保留缓存增加显式失效入口。建筑开始载入、替换、失败和关闭时清空旧结果；同一批建筑的纯转向继续保留名称位置所需的已确认方向遮挡。建筑失败时天体读数为遮挡未知，地形保留，不把纯 DEM 结果当作建筑无遮挡。
- 机位高程尚未就绪或宿主隐藏时停绘建筑；关闭立即取消请求并释放当前 GPU 网格，不依赖隐藏宿主再产生绘制帧。程序在关闭期间可保留，卸载时释放。

原型边界为周边约 2 km、最多 16 个 z14 瓦片、80,000 个接受的轮廓点、120,000 个三角面。单瓦片读取上限 3 MiB，原始瓦片缓存最多 16 块且合计 16 MiB，TileJSON 缓存一小时。三角面满额时顶点缓冲约 8.24 MiB；该数不包括解码临时对象、DEM、其他图层或驱动开销，不是浏览器峰值内存。独立重试清理建筑缓存并重新读取来源；版本化 URL 隔离不同数据版本。

## 首版 GPU 阻塞与剩余限制

四次 Chrome 发现尝试（包括用户告知已恢复后的一次会话重置）均返回 `The browser access host is unavailable`，原生通道也不可用。没有保存或宣称任何新建筑截图通过。[验证元数据](building-evidence/verification.json)记录当前资源版本及各层验证边界。

当时待验项目包括真实 DEM 接地与坡地接缝、24/85/200/1000 mm、建筑/山体/天体深度、夜间天气合成、拖动缩放与开关、手机恢复和帧耗时；其中城市平地画面、镜头、拖动开关及手机视口恢复已在后续验收补齐，其他专项仍未完成。现有 GL 替身只检查 API 状态与资源，不证明着色器在真实驱动编译、光栅化或最终画面正确。

当前只提供简化平屋顶和近似基座，不包含屋顶细节、纹理、夜景灯光或精细地标。跨瓦片坡地建筑可能出现分片高度差；沿瓦片边界的墙体省略和有限资料覆盖也限制近景精度。先完成上述城市 GPU 验收，再决定调整预算、改善分片基座或接入单个精细地标，不将未验能力视为已完成。

后续恢复 Chrome 后，先进行了缺块 CPU 核查（当时尚未新增 GPU 验收）。用户反馈整块缺失与晴空塔不可见后，加载器的真实 MVT / 合成基座复现已确认：跨瓦片预算造成覆盖截断，用户机位的晴空塔高层被绘制预算舍弃。原因、两机位对照与本地区域包体积实测见[数据与缺块核查](building-data-audit.md)。本地化评估尚未改变应用加载策略。

当前加载策略与新增真实 GPU 记录以[预算修复验收](building-budget.md)为准。首版源码/产物签名仍保留，不覆盖历史失败记录。
