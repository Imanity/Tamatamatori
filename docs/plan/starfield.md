# 星空与银河首步

更新：2026-11-05。目标：新增“星空”开关，接入北极星、牛郎星、织女星等亮星与金星、木星；启用现有“银河”开关，绘制银河轮廓并标识银心方向。默认均关闭，保留已有日月、月光、地形和布局。

本轮使用固定 HYG v4.1 目录的 V 星等 ≤4.5 子集（925 颗恒星、18 个中文名称参考），排除太阳；金星/木星沿用 Astronomy Engine。银河按 IAU 银河坐标生成柔和带状示意，银心采用公开 Sgr A* 方向。仅作构图定位，不是完整星表、实拍银河、曝光、光污染或天气模拟，不新增深空和空间站能力。

## 验收

- 固定位置/UTC 的恒星、行星和银心方向；对照独立参考，检查 J2000、自行、岁差/章动、坐标轴、日期变更线、地平线与折射。
- 星空与银河独立开关；时间、镜头、方向、画幅和实际相机更新；不重建地形、不重复请求 DEM。
- 星点、银河和银心接受同一真实地形深度；名称不穿山；等待、关闭、视场外、地平线下及失败有说明。
- Chrome 检查夏季三角、北极星、金木星、银河/银心、广角与长焦、地平线裁切和遮挡；保留实际画面，不以数值测试代替 GPU 验收。
- 目录保留 CC BY-SA 4.0 许可、来源、提取方式与可下载子集；运行时不依赖外部星表或星历接口。

- **独立数值**：54 组 PyERFA 2.0.1.5 / ERFA `atco13`、`g2icrs` 参考覆盖北极星、牛郎星、织女星、大角星、天狼星、银心及银河赤道方向；两个南北半球测站，2000 / 2026 / 2099 三个历元。最大空间方向差 **0.002473°**，小于本轮 0.02° 容差。金星、木星另对照 4 组 JPL Horizons 无折射、椭球高 0 m 的测站方向，方位和高度误差均小于 0.05°。保留[离线样本](../../tests/fixtures/starfield-reference.json)及[重建脚本](../../scripts/generate-starfield-fixtures.py)；脚本仅生成参考，需要临时安装 `pyerfa==2.0.1.5`，不作为应用或 CI 依赖。ERFA 参考的 DUT1、极移和气压设为零，未来闰秒不预测。
- **自动检查**：`npm test` **116/116**、`npm run build` 通过（含类型检查）。新增检查覆盖星表许可/数值、独立方向基准、UTC/日期变更线/极点/日期边界、折射和摄影矩阵、银河网格闭合与缓存、独立开关/朝向、真实相机反馈、过期/失败状态、异步查询、宿主 GL 状态恢复与资源释放。GL/组件替身检查不代表 GPU 画面验收。构建仍有既有 MapLibre 大包提示。

## 限制与下一小步

银河宽度、亮度和暗带为解析示意，星点大小/颜色是有上下限的符号；白天开启仍可用于定位，不表示现场能看到。未模拟光污染、云层、曝光、完整星等消光、月光对银河可见度的影响、双星/变星或星座连线。银心标识的是固定 Sgr A* 方向，不是光学可见的黑洞。近地遮挡继续受 DEM 分辨率、覆盖与未核定高程基准影响。

后续已按用户要求推进暮光、月光对星空明暗的近似反馈，见[独立验收](starfield-appearance.md)。本页保留首步的原始效果与边界；后续仍不同时扩展深空或空间站。
