# 山体遮挡与大气折射验收

更新：2026-11-04。状态：数值、组件及 Chrome 基础 GPU 画面检查通过；真实大气与地理精度不属于通过项。

本轮验收当前 DEM 的日月深度遮挡与标准参考折射，不验收真实天气、完整远地形覆盖或精确日出日落。技术边界见[遮挡与折射设计](../architecture/occlusion-refraction.md)，既有[日月验收](sun-moon-validation.md)与[地形验收](terrain-validation.md)继续保留各自的精度限制。

Windows、Node.js 24.17.0：`npm.cmd test` 的 77 项检查通过，`npm.cmd run build` 通过；保留既有 MapLibre 包体大小提示。本记录报告本地结果，远端 CI 在提交推送后另行核对。

新增 7 项领域与 GL 查询检查，另加 1 项组件检查；既有失败重试检查补充日月状态断言：

- 标准折射：几何 0° 得到视高度约 0.483032°，几何 10° 得到约 10.090128°；无折射保留原方向，天顶和地平线下结果有限，非法输入被拒绝。这是固定库模型的回归，未对照实测气象。
- 对圆盘每条轮廓方向施加折射：几何中心 0.3° 的竖向尺寸缩小，横向尺寸基本保持；几何地平线下的上缘可因参考折射进入画面。凹月相轮廓三角化保持面积。
- GL 查询替身覆盖无遮挡、部分遮挡、全部遮挡、无覆盖像素、异步等待、查询超时、编译失败、过期结果丢弃、宿主 GL 状态恢复及卸载释放。**这些检查不模拟 WebGL 光栅化或真实 DEM 深度。**
- 组件检查折射切换不移动相机、不重新请求机位高程、不改变其余计划；地形更新使遮挡失效，重建释放旧图层。高程或地形失败显示遮挡未知，修改计划后继续保留未知状态；重试恢复测量。组件使用 JSDOM 与 SDK 替身。

既有离线 JPL 几何星历、USNO 月相、真实 SDK 相机投影及昼夜回归仍通过；本轮未修改其精度承诺。

## 保留限制与下一步

- 三种真实遮挡状态在太阳场景验证；月亮检查长焦凹亮面与无遮挡，未另做月亮触山序列。近水平圆盘压扁、像素不足、查询超时和故障恢复的本轮检查为自动回归，未分别做真实 GPU 故障注入。
- 遮挡只针对当前 DEM 网格与已加载的视野。LOD、远裁剪、近景相机、防碰撞、缺失地形和水位误差沿用原有限制；未对照实测山峰轮廓或实拍触山时刻，不包含建筑、树木和天气。
- 标准折射为固定海平面参考大气，不使用机位气压、温度或密度；几何高度低于经验公式适用区时仅保留库的数学延拓，不作为实际可见预测。天文测站参考高度仍取椭球面 0 m。
- 真实网络失败恢复、触屏设备及既有地形精度待验项继续保留。下一小步建议补充山峰投影基准及真实网络中断恢复，随后再推进其他天文图层。
