# 时间天空验收

更新：2026-11-04。状态：本轮基础环境实现已完成自动检查与 Chrome 画面验收；不代表天气、曝光或地理精度已验证。

本轮只交付按机位与 UTC 时刻变化的晴空配色、地表明度与太阳方向坡面阴影；沿用当前地形、水体和摄影相机。天气、曝光、天体图层和地形投影阴影不在本轮范围。

## 固定输入与检查

- 数值：NREL SPA 样例（纬度 39.742476°、经度 −105.1786°，UTC 2003-10-17T19:30:30Z），检查太阳角度量级；与含大气折射的样例比较容差为 0.1°，不宣称达到完整 SPA 精度。
- 边界：同一 UTC 切时区、经度 ±180°、南北半球夏冬、极昼极夜、非法输入、跨日和配色节点连续性。
- 组件：时间改变仅更新环境；相机位置、镜头、方向、实例与机位高程请求数保持；地点变化和布局重建使用最新环境。
- 浏览器：山中湖固定机位 35.4172° / 138.8729°，方位 247°、俯仰 +4°、全画幅 35 mm、横幅 3:2、离地 1.6 m；日期 2026-11-04，时区 Asia/Tokyo。分别检查当地 12:00、17:00、00:00，再用时间滑杆快速切换，保留截图和实际结果。
