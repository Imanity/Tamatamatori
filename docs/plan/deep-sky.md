# 深空天体与改机对比首步

更新：2026-11-05。保留尚未提交的银河对比度改动；本轮只接入 8 个常见深空目标与两种相机响应，先本地验收；用户随后明确要求提交推送。

> 本文保留首步模型与验收历史。M31/M42 后续已改为完整宽幅 RGB 参考及独立红色增量，当前模型和视觉结果以[遮罩与色彩修正](deep-sky-render-fix.md)为准。

## 范围与数据

仙女座 M31、猎户座 M42、昴星团 M45、礁湖 M8、北美 NGC7000、加州 NGC1499、心脏 IC1805、灵魂 IC1848。左侧独立开关、右侧状态/名称与搜索、主动朝向；按真实角尺寸和摄影相机投影，接受参考折射和实际 DEM 遮挡。扩展目标按其发光轮廓查询部分/全部遮挡，不能用中心点代替整片星云。

采用 Mattia Verga 的 [OpenNGC](https://github.com/mattiaverga/OpenNGC/tree/be3cd6c5498806a2fbb2f7e0452ef802dbb02be0)，CC BY-SA 4.0，固定提交、输入哈希、J2000 位置、角尺寸、可用位置角和 Aladin/DSS2 描绘的多级轮廓。缺少的位置角保留为空；有轮廓时按实际天球坐标绘制，不编造方向。M45 关联星使用现有 HYG 数据。导出子集和衍生图保留相同数据许可及署名；不引入在线天文服务或新的运行时依赖。

## 显示边界

相机参数新增“深空相机响应”：未改机 / 天文改机（Hα 增强），默认未改机。按常见保留 UV/IR 截止的 Hα 改机近似，不涵盖全光谱改机。参考 [Canon EOS Ra](https://global.canon/en/c-museum/product/dslr890.html) 所示 Hα 656.3 nm 增透原理，以不同的 Hα 显示权重作定性对比；不声称所有改机具有固定的实际增益。

衍生图将连续谱、Hα 与其他发射分量分开，改机仅增强 Hα；星系/星团的连续谱、星点和银河全景保持现有表现。各分量来自目录轮廓与人工分类的结构示意，不是实测窄带通量或照片。星云层次、颜色和亮度不作为现场曝光预测，不加入 ISO、光圈、快门、滤镜或堆栈模型。切换响应只更新 uniform，不改变位置/角尺寸、地形、其他天体或遮挡结果。

## 验收

- 目录可复现，固定天球位置与位置角/角尺寸检查；与独立 ERFA 方向对照，广角/长焦、横竖幅、参考折射和部分入画覆盖。
- 同一目标/时间/构图下，改机增强发射星云红色，M31/M45 不统一泛红；暮光/月光仍减弱扩散光，白昼淡出。
- GL 资源、按需图像请求、独立失败/超时/重试、响应切换不重建几何；扩展发光轮廓分别查询清晰与被遮挡像素，区分无遮挡/部分/全部/像素不足。
- React 开关、搜索和朝向联动，切换响应不改变计划其他值，不重载 DEM；Chrome 保存未改机/改机及山体遮挡等真实画面。自动检查、子路径构建与 GPU 验收分开记录。
