## 1. 产品目标

帮助摄影者回答：在某个地点、某个时刻，朝某个方向、使用某个镜头，能够怎样构图？

主流程：选择机位 → 设置拍摄方向 → 调整时间与镜头 → 查看预览 → 按需显示天文信息 → 反复调整。

预览以可解释的地理与天文模拟为基础，优先保证位置、方向和视场的一致性，再逐步增加信息。初期不以照片级效果作为目标。

## 2. 全局需求

| 领域 | 目标 | 范围边界 |
| --- | --- | --- |
| 工作区 | React 界面，包含地图区、预览区、图层侧栏与信息栏，参数归入地图与预览 | 先面向桌面浏览器，窄屏预览与时间轴常驻、其余分区切换 |
| 地图 | 使用开源地图引擎浏览全球，选择机位与拍摄方向 | 全球选点与数据覆盖分开验收；不承诺各地均有相同精度 |
| 参数 | 设置拍摄时间、时区、焦距，以及解释视场所需的传感器与画幅信息 | 初期不模拟完整曝光、镜头畸变或景深 |
| 基础预览 | 从拍摄机位生成地面与天空，天空随地点和时间变化 | 地面来自地形及地图信息；缺数据时明确降级，不冒充实景 |
| 图层 | 按需显示太阳、月亮、银河、深空天体、空间站等信息 | 分批接入，区分构图标记、预测位置与肉眼或相机实际可见性 |

基础版的地面信息至少包括有来源的地形起伏与地表参考信息；只有平面或占位网格的预览属于早期原型。建筑、树木等精细遮挡不纳入基础版承诺。

## 3. 逐步交付

每个阶段仍要拆成若干小目标，一轮只做一个。阶段编号表示依赖顺序，不表示一次性交付范围，也不承诺日程。

| 阶段 | 主要结果 | 验收方向 |
| --- | --- | --- |
| P0：全局文档（已完成） | 规划、设计、架构与协作规则 | 需求有去向，阶段边界清楚，未混入功能实现 |
| P1：操作闭环原型 | 工作区、地图选点、拍摄方向与核心参数联动 | 能从地图选点走到示意预览；修改参数有一致反馈；示意内容清楚标注 |
| P2：基础预览 MVP | 接入有来源的地形与地表参考，按拍摄视场显示地面，天空依据地点和时间变化 | 同一拍摄计划可重复得到一致构图；移动机位、改变焦距和切换昼夜均可观察；缺失数据有反馈 |
| P3：天文构图辅助 | 依次接入太阳、月亮、银河、深空天体 | 每类单独交付；位置与时间对应、开关有效；地平线、视场和显示状态有区分 |
| P4：空间站信息 | 轨道数据与观测位置结合，显示空间站位置或轨迹 | 展示数据来源、轨道历元与更新时间；过期或缺数据时说明预测限制 |

P2 才是基础最小可用版本；P1 用于验证操作和技术路线，不能作为地形与天空能力已经完成的依据。P3 按用户要求先交付日月构图辅助，再逐项推进银河与深空天体；P4 同样先位置、后轨迹等附加能力。

P1 已建立工作区、可调布局、地图手势和统一参数。P2 沿用独立 MapLibre 实例，接入 Mapterhorn DEM、OpenFreeMap 水体边界与固定机位相机；离地高度、焦距和横竖幅参与实际渲染。水面高度暂按 DEM 近似，尚未校准独立水位。既有 Chrome 地形与昼夜检查见[地形验收](terrain-validation.md)与[时间天空验收](time-sky-validation.md)。

日月圆盘、月相近似、独立开关和主动朝向已接入，基础星历见[日月验收](sun-moon-validation.md)，遮挡与折射见[相关验收](occlusion-refraction-validation.md)。[相机校准](camera-calibration.md)修复近地避让后的日月及读数联动；[远山 DEM 验收](terrain-detail.md)统一下载和网格细节策略，在固定长焦场景中恢复原生 z12 采样一致性。后续[曲率对照](curvature-validation.md)建立独立椭球方向基准并完成 Chrome 模型差异检查；既有自动检查及构建通过，本轮隔离全新安装与补丁幂等检查通过，尚未完成实景山脊精度验收。[高程基准核查](elevation-datum-audit.md)已结束，现有证据不足以启用正式转换；[空间投影修正](terrain-perspective.md)已将实际网格修正和水体/日月共享深度接入默认预览；本轮继续接入亮星及银河，真实网络恢复仍保留待办；不将 P2 或 P3 整体标记完成。

## 4. 基础版验收场景

星座名称/连线、更多主要亮星名称与右侧拍摄信息栏已按独立小目标接入，范围和执行结果见[星座与信息栏验收](constellations-and-info.md)。

星空与银河的暮光/月光显示近似作为独立小目标推进；不将显示阈值当作实际可见度，执行结果见[明暗验收](starfield-appearance.md)。

夜间构图明度与月相/高度驱动的环境效果已验证，见[时间天空验收](time-sky-validation.md#2026-11-05夜间构图明度与月光)。日月画外方向提示已验收，见[日月验收](sun-moon-validation.md#2026-11-05日月画外方向提示)。按本轮要求接入亮星、金木星及银河轮廓与银心方向，范围和执行结果见[星空验收](starfield.md)。

这些是完整基础版的验收方向，当前已接入基础地形、静态水体及随时间变化的晴空近似：

- 在两个不同地点选择机位，预览中的地理场景及方向随计划更新；浏览地图本身不意外移动机位。
- 保持机位、朝向和传感器不变，增加焦距后视场缩小；地图上的水平视场提示与预览一致。
- 保持机位不变，修改时间后天空发生合理变化；显示时区明确，跨日期操作不丢失实际时刻。
- 在全球选点时能处理日期变更线与高纬度地区；地图投影或数据覆盖存在限制时有替代输入或明确提示。
- 地形请求失败时，用户仍能编辑计划；预览说明缺失部分及其影响。
- 已接入图层可独立开关，未接入图层清楚标注；天体未出现在画面中时可以理解原因。
