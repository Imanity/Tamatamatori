# 星座辅助与拍摄信息侧栏

更新：2026-11-05。本轮按用户要求补齐三个相互关联的操作：星座名称/连线开关、主要亮星名称，以及固定在工作区右侧的拍摄信息栏。保留此前暮光/月光实现；本目标完成时尚未提交，随后按用户新指令随搜索与 Pages 配置一并提交。

## 范围与验收

- 星座名称和连线使用独立开关，默认关闭；覆盖现代 88 星座（巨蛇座分为两片）。连线是构图参考，不是星座边界或真实发光物体；接受同一摄影相机、参考折射、地平线和 DEM 遮挡。
- 星座数据采用固定版本 d3-celestial 的连线与中文名称位置，按 BSD-3-Clause 保留作者/许可。连线端点匹配现有 HYG 目录，补齐必需的暗星坐标，以同一自行/岁差模型推进，避免长焦下连线脱离星点。衍生 HYG 数据继续遵守 CC BY-SA 4.0。运行时不增加在线数据源。
- 星空开启时展示更多主要亮星名称：优先使用现有中文名称，其余采用目录固有名；避让过密标签，信息栏保留目标列表和朝向操作。名称与星点明暗、实际 DEM 遮挡联动。
- 预览下方的视场、朝向、光照、日月、星空及近似说明移至右侧“拍摄信息”；版权/数据署名留在预览区。共享同一场景状态，不复制渲染实例。保留预览/参数默认 2:1、面板交换与分隔条；空间不足时信息栏可收起，窄屏使用信息抽屉。

验证：目录/端点匹配、时间/姿态一致性和线段裁切固定输入检查；组件检查开关、信息迁移、朝向与状态生命周期；Chrome 检查亮星名称、星座开启/关闭、山体遮挡、桌面与窄屏，以及主栏交换、默认布局与版权。

暂不增加星座插画、星座边界、新深空天体、空间站、曝光或天气模拟。

## 限制与下一步

连线为一种现代星图画法，不是唯一画法或星座边界；星名采用图录命名，未接入星座插画。宽视场或小取景框会避让过密的亮星标签，全部主要目标仍可在信息栏展开查看；名称只代表参考点的 DEM 遮挡，不保证整个星座可见。星点明暗仍是构图近似。

下一小步建议增加信息栏中的目标搜索/筛选，避免长列表中查找亮星或星座时反复滚动；不同时扩展新天体类型。
