# 全局设计

巴纳德环和蛇夫座星云复合体作为深空目标提供搜索与朝向。较大角范围在宽幅镜头中查看整体，放大时按原始分辨率展示局部。资料说明明确标注分片注册、原生分辨率、蛇夫座区域中心以及反射云的颜色处理。

火树星云可用“火树”“火焰星云”“NGC2024”或“Flame Nebula”搜索并朝向。它与马头共享区域影像，分别显示名称、视场和地形遮挡状态。来源说明明确标注共享影像、1024 原始分辨率及暗区对比近似。

状态：地形、日月、星空、银河、星座及空间站参考已接入，信息与子设置集中在右侧折叠分组，水面高程和天空明暗仍为近似。更新于 2026-11-07。

本文描述工作区和操作原则，不确定最终视觉稿、控件尺寸或组件 API。范围与阶段以[全局规划](../plan/overview.md)为准。

## 1. 工作区

界面围绕“先定位、再看构图、随时调整参数”组织。桌面优先，地图独占较大一栏；较小的预览区和参数区默认在右栏上下排列。图层侧栏保持紧凑，地图、预览与参数在同一工作区持续可见。

```text
┌──────────────────────────────────────────────────────────────────┐
│ 顶部：项目名称 · 机位 · About                                       │
├──────────┬──────────────────────┬─────────────────┬───────────────┤
│ 图层侧栏 │ 地图区（主栏）       │ 预览区          │ 信息与设置    │
│ 日月     │ 全球浏览、机位、朝向 │ 信息条与构图    │ 全局信息      │
│ 星空     │ 水平视场提示         ├─────────────────┤ 日月、星空    │
│ 银河     │                      │ 参数区          │ 银河、深空    │
│ 深空等   │                      │ 时间、镜头、机位│ 空间站        │
└──────────┴──────────────────────┴─────────────────┴───────────────┘
```

桌面默认地图约占主工作区的 65%，右栏约占 35%。右栏上方为预览，下方为可滚动的参数区，默认高度比为 1:1。比例只是初始值，用户可以拖动地图与右栏之间、预览与参数之间的分隔条自由调整大小，空间不足时仍以分区最小尺寸保护基本可用性。

当前默认布局见[工作区示例](../plan/light-pollution-evidence/19-layout-1to1.png)。

三个面板的标题提供拖拽把手，拖到另一个面板可交换位置，同时提供面板位置选择作为键盘替代操作。布局调整只影响显示，拍摄计划独立保留。布局仅在当前会话中保留。

左栏只显示图层开关，不另设跳转按钮。右栏图层分组与开关联动：初始展开状态与开关一致；开启图层时展开对应分组并滚动到信息栏顶部，收起的右栏重新展开、搜索词清空，焦点留在开关上；关闭图层时折叠对应分组，不滚动、不改搜索。分组标题仍可手动展开或折叠，不改变图层。移动端开启图层时保留图层抽屉，下次打开信息抽屉时再定位到该分组，见[信息栏改进](../plan/info-sidebar.md)。右栏的全局信息排首位并默认展开，只保留取景参数、光照、光污染与天气读数；建筑、太阳、月亮、星空、银河、深空天体和空间站分别折叠，可同时展开多个分组。星座名称与连线归入星空，银河对比度归入银河。搜索保持独立入口。移动端沿用分组与跳转，并关闭原图层抽屉。详见[工作区调整](../plan/workspace-ui.md)。

预览上方信息条展示焦距、传感器与画幅、相机响应、机位高程与离地高度。鼠标滚轮调整焦距，拖拽调整方向。更新机位时保留上一画面，持续等待后显示进度，错误即时提示。画幅变化同步画布尺寸与投影。日期与时间输入同排，时间滑杆独占一行，其下为微调按钮和当日日月时刻；时区与折射同排，相机响应置于相机配置末尾。

左侧栏在图层下方提供可折叠的环境组，集中放置默认关闭的光污染与天气开关。开启光污染后按机位读取 2015 图集，夜空与天体对比度按显示近似更新。预览仅在失败或无覆盖时显示数据状态，加载状态、来源年份与当地天顶人工增亮集中于全局信息，来源许可与下载归入 About。详见[光污染首步](../plan/light-pollution.md)。

天气的预测模型子设置位于环境组内，支持自动匹配、GFS、ICON 和 ECMWF IFS，关闭效果时保留模型选择。全局信息显示天气状态、分层云量、降水概率与能见度，并保留 Open-Meteo 来源链接；过期、缺测和超出预报范围分别以状态表达。预览显示点位天气驱动的云层和降水示意，失败、缺测和超范围在画布外反馈，超范围可主动切换到当前时间。能见度缺测单独表达。标注转向连续性与模型验收见[环境优化](../plan/environment-refinement.md)。

窄屏通过“地图 / 预览 / 参数”切换保留可用操作空间，图层侧栏收为可展开区域。窄屏隐藏分隔条与面板拖拽，恢复宽屏后保留原桌面布局。分隔条支持方向键微调和 Home/End 调整到边界，拖拽过程中保证面板内容不会误选。

## 2. 各区域的职责

空间站图层提供 ISS 与天宫的拍摄时刻标记及前后各三分钟轨迹点。右侧显示轨道数据更新时间、过期与失败提示和朝向操作，搜索支持中文名称、ISS/CSS 和 NORAD 编号。页面刷新只检查已发布的快照，上游自动更新另行标注。超过推算窗口时保留原因反馈，提供主动切换到当前时刻的操作。变轨后需要等待新的轨道解。

header 右侧提供“机位”按钮：显示当前机位名称或“未保存的机位”，修改后加圆点；面板内可保存、另存、切换、重命名、删除（可撤销）、分享与导入。应用机位后一次替换整个拍摄计划并可撤销；刷新页面恢复上次的工作状态。机位只保存在此浏览器，分享使用分享码。格式说明不出现在界面中，导入出错时才列出带字段路径的问题。详见[机位保存与分享](../plan/shot-presets.md)。

header 同时提供固定可见的 About 入口，统一展示地图、高程、天文目录、银河、深空影像及开源软件的署名、许可、修改说明与数据下载。弹窗内部滚动，顶部关闭按钮持续可见，支持 Escape 关闭及焦点返回。完整清单不依赖图层开关，预览底部不再堆叠来源链接。地图保留紧凑署名控件。详见[本轮计划](../plan/about.md)。

| 区域 | 展示内容 | 主要操作 |
| --- | --- | --- |
| 地图区 | 底图、机位标记、拍摄方向与水平视场提示 | 浏览全球、点选或移动机位、调整水平朝向 |
| 预览区 | 相机视场中的地面、天空和已开启图层，必要的地平线与方向参考 | 观察构图，拖动或用方向键调整拍摄方位角与俯仰角 |
| 参数区 | 日期时间、显式时区、焦距、传感器尺寸、画幅比例、方位角、俯仰角、离地高度 | 精确输入、逐步调整，查看单位和合法性反馈 |
| 图层侧栏 | 图层开关 | 控制预览叠加内容，同时展开或折叠右侧对应分组 |
| 拍摄信息栏 | 当前预览的视场、实际姿态、光照与天体状态 | 查看反馈、主动朝向目标、独立滚动或收起 |

地面和基础天空属于预览基础。侧栏中的天文图层是构图辅助；开启银河或深空天体并不代表目标一定能拍到。

## 3. 主操作流程

1. 进入工作区，看到明确的初始示例机位、时间、时区与镜头假设；不自动将示例位置描述为用户当前位置。
2. 浏览地图并选择机位。机位变更后更新地理数据与预览；普通平移、缩放地图只改变地图浏览状态。
3. 调整拍摄方向。地图显示水平朝向和视场扇形，参数提供方位角与俯仰角精确输入；平面扇形不是完整三维可视范围。
4. 设置日期、时间和时区。时区可选任意 IANA 时区：按钮显示城市与拍摄时刻的 UTC 偏移，展开后支持中文城市、英文、IANA 名称和偏移搜索及键盘选择。时区仍由用户显式选择，不按机位推断；改变机位或时区都保留实际拍摄时刻。
5. 调整焦距、传感器和画幅。相关信息共同确定视场；画幅变化同步影响预览取景框。
6. 开启已接入的天文图层，查看目标与地面构图的关系，再反复修改参数。

初期可采用明确标注的全画幅传感器和横向 3:2 画幅作为默认假设；最终默认值在参数功能的小目标中确定。相机离地高度与地形海拔分别显示，避免把机位抬高误解为修改地形。

## 4. 图层与状态反馈

所有阶段共同遵守：控件有响应，数据状态可解释，尚未实现的能力不伪装成可用能力。

| 状态 | 界面反馈原则 |
| --- | --- |
| 尚未接入 | 标注“规划中”，不提供看似有效的开关 |
| 用户关闭 | 显示关闭状态，不触发无关数据请求 |
| 加载中 | 在受影响区域提示进度，允许继续编辑计划 |
| 加载失败或覆盖缺失 | 说明受影响的数据；提供适用的重试或降级反馈 |
| 数据过期 | 显示更新时间和预测限制，不冒充当前可靠数据 |
| 已开启但不在画面中 | 区分视场外、地平线下与当前筛选无结果 |

“目标处于几何地平线以上”和“目标未被地形遮挡”是不同信息；未实现地形遮挡或大气可见性判断时必须说明。银河与深空天体可先提供轮廓、位置或名称辅助，其实际亮度不作为相机成像预测。

预览需要显示数据精度或缺失状态。例如：使用平面占位时标注“示意地面”；真实地形加载失败时提示“地形不可用，无法评估地面遮挡”。保留上一次画面时应标记其对应旧参数，不能让旧结果看起来已经匹配新计划。

## 5. 通用交互原则

- 地图、预览、参数始终使用同一拍摄计划；输入错误在对应字段附近说明，不静默替换成别的有效值。
- 编辑时及时反馈，较重的数据请求可延后或合并；最终显示的结果必须对应最新计划。
- 方位角、俯仰角、焦距、距离与时间都展示单位；时间同时展示时区，夏令时导致的歧义或无效时间需要解释。
- 使用适合长时间看图的克制视觉风格，保证文字、选中状态、焦点与图层标记的对比度，不仅依靠颜色表达状态。
- 控件提供文字名称、键盘操作和明显焦点；地图点选提供经纬度输入替代路径。
- 完整数据来源、作者署名、许可和下载集中在 header 的 About 弹窗，入口在各尺寸下持续可见；地图另保留紧凑署名控件。

具体视觉风格、面板比例、移动端细节和快捷键在对应小目标中细化，不在本轮定稿。

## 6. P1 地图交互

- 地图区接入真实道路、地名与水系底图；初始北向上，支持右键拖动或双指旋转地图；地图浏览旋转与拍摄方位角各自独立，机位与扇形保持地理方向一致。
- 默认浏览，点击空白位置不改变机位或朝向。点击“放置机位”后，下一次地图点击放置一次机位并回到浏览；“定朝向”同样是一次性操作，再次点击按钮或按 Escape 取消。
- 机位和方向把手支持连续拖动，手势过程中实时更新机位、扇形及参数。缩放逐帧更新扇形，定位和全球视图使用平滑过渡；减少动态效果的系统偏好受到尊重。
- 预览取景框支持指针拖动，水平调整拍摄方位角，竖直调整俯仰角；与地图、参数实时联动。键盘方向键提供替代操作，机位坐标保持不变。
- 平移、缩放只改变浏览范围；“回到机位”恢复到当前机位，“全球视图”方便浏览远方。修改参数中的坐标会在必要时将该机位带入视野。
- 扇形表示水平视场角，其显示长度随地图缩放调整，不代表镜头拍摄距离、地形可视范围或三维视锥。
- 地图角落保留可展开的紧凑署名控件，完整来源也可从 About 查看。加载中、数据请求失败和图形环境无法启动分别反馈；重试只重建地图，保留计划和浏览状态。
- 当前平面底图约支持南北纬 85.05° 之间；超出范围仍可输入并保留机位坐标，但不将位置截断成别处，也不绘制假的机位或视场。界面说明覆盖限制，用户可继续浏览可覆盖区域。
- 窄屏切换、分隔条调整和面板换位后，地图适配新尺寸；换位保留地图浏览范围。

## 7. 时间与画幅操作

- 时间滑杆以当前所选日期和时区的当地钟点为准，范围为 00:00—23:59、步长一分钟，改变滑杆保留所选当地日期。夏令时重复或跳过的钟点保留原计划并给出提示。日期、秒级时间输入与滑杆双向同步。
- 滑杆背后的色带显示当日太阳高度（夜间、三种暮光、低角度日照、白昼）。日期两侧可前后一天并保留钟点；±1 分、±10 分、±1 时与“现在”按绝对时刻移动，可跨午夜。晨光、日出、日落、昏影、月出、月落按钮跳到所选当地日期的对应时刻：日月出没按海平面地平和所选折射计算，不含地形遮挡；当日没有的事件禁用并说明。详见[拍摄参数交互优化](../plan/parameter-controls.md)。
- 相机离地高度提供数字输入和 0.1—100 m 对数滑条，10 m 以下精确到 0.1 m。
- 焦距数字输入和滑杆均支持 8—1000 mm；常用值按钮供快速切换。
- 画幅方向支持“横幅 / 竖幅”，独立于 3:2、16:9、1:1 比例。先在传感器内按比例裁切，再按方向交换有效成像宽高；地图水平视场和预览宽高比同步更新。竖幅 3:2 的实际取景比例为 2:3。

## 8. 山体与水体预览

- 取景框显示实际 DEM 构成的山体及地图水体边界；以“地形模拟”标识能力，保留拖动转向和构图线。
- 显示机位高程与相机离地高度；水面高程为 DEM 近似，缺少实时水位与独立水面校准。水体先使用静态颜色，不提供倒影或波纹。
- 地形、水体和日月使用同一机位局部方向，实际网格已加入参考椭球曲率与方向修正。曲面构图、高程基准未核定与水面 DEM 近似的说明集中在 About，开发诊断仅用于专门校准流程，几何修正与实景精度分别表达。
- 参数和地图保存计划高度、角度，预览读数采用实际渲染姿态。近地防碰撞发生明显调整时，预览上方信息条显示引擎避让、实际离地近似值及俯仰，日月同时跟随实际姿态。
- 机位改变时保留上一有效画面，上方高程信息显示待更新，持续等待 800 ms 后显示进度。地形或水体请求失败即时反馈具体影响，并提供重试，地图与参数继续可用。
- 预览移除版权长列表，完整来源和下载入口统一由 About 提供；新增图层不会减少取景框高度。

## 9. 时间驱动的基础环境

- 调整时间后，天空、地平线、远景雾和地表明度连续变化；由机位与实际 UTC 时刻共同确定昼夜，不按固定钟点判断。地图底图继续作为浏览参考。
- 预览取景框外显示光照阶段和太阳几何高度，明确“晴空近似 · 不含天气与曝光”；水体仍标注 DEM 高程近似。夜景保留构图所需的地面参考，不代表相机能按该亮度成像。
- 无月深夜仍能勉强区分天空与山脊。月亮亮面越大、几何高度越高，夜空与地表参考越亮；月亮在地平线下不贡献亮度，日间淡出月光影响。夜间显示月亮亮面与几何高度作为亮度变化的参考，月亮标记关闭时仍保留环境效果。
- 切换显示时区只改变当地时间显示，环境保持相同；修改拍摄时刻不移动相机、不重置镜头、不重建地形。
- 太阳方向用于坡面明暗，日月图层在下一节单独控制；不承诺日出日落或山体遮挡，不模拟朝日与背日天空色差。

## 10. 日月构图辅助

- 侧栏太阳、月亮各有独立开关。日月开关只隐藏圆盘，不改变昼夜、月光与环境明度。星空、银河与深空见下节；空间站的独立图层提供位置、短轨迹与更新状态。
- 预览按摄影视场显示日月角尺寸，月亮亮面随月相与观察方向变化。宽角镜头下圆盘可能很小，名称与辅助轮廓不能冒充放大的天体。
- 取景框外逐项显示关闭、视场外、地平线下，以及当前 DEM 未遮挡、部分山体遮挡或山体遮挡。加载时显示遮挡待测；无覆盖像素显示像素不足；失败显示遮挡未知并保留错误与重试。完全遮挡时不显示名称标签，圆盘和辅助轮廓都被地形裁切。
- 图层开启、圆盘在参考地平线上且完全位于视场外时，在取景框边缘显示日月名称与方向箭头；相机后方附“后方”，两者接近时并排避免覆盖。小预览统一在上缘并排显示，以箭头方向区分目标，避免竖幅窄框互相覆盖。方向随实际相机、镜头和画幅联动；部分圆盘已入画或地平线下时不显示画外箭头。箭头只表示转向参考，不代表越过山体后可见，也不会自动转动相机；仍可使用取景框外的“朝向”按钮。
- 太阳、月亮分组顶部各有“运行轨迹”开关（默认关闭，从属于对应天体）。预览画出一次出没的中心视位置连线和当地整点标记：拍摄时刻在地平线上时取本次，否则取前后最近的一次；开阔天空为实线，山体或建筑后方为淡色虚线，地平线下不画。分组内只显示是哪一次出没、是否经过画面，口径说明在 About。详见[日月运行轨迹](../plan/sun-moon-paths.md)。
- 显示方位、视高度、几何高度和月亮亮面比例；参数区提供默认标准折射与无折射比较，明确标准折射为固定海平面参考大气。主动“朝向”使用视高度，只调整拍摄方向，不移动机位、修改时间或焦距。
- 画面内不等于确定可见，持续标注遮挡仅按当前 DEM，并显示所选折射模式；不包含建筑、植被、真实天气与完整远地形。白天月亮也不代表一定能看到，新月轮廓只作定位辅助。

## 11. 星空与银河首步

右侧信息栏增加固定搜索框，支持中文、星表原名和星座缩写，不区分英文大小写。搜索日月、亮星、银心或星座时显示匹配数量与目标状态；未开启的图层仍可发现，需点击“开启并朝向”或“开启图层”明确操作。清除查询恢复原信息，收起侧栏或交换面板保留查询；输入本身不改变构图。范围与验证见[搜索及发布计划](../plan/search-and-pages.md)。

“星座名称与连线”开关默认关闭，归入右侧星空子设置，需先开启星空。关闭星空同时关闭星座，搜索并开启星座时同时开启星空。星座作为构图辅助，白昼也可查看参考方向，星点仍遵守已有明暗近似。主要亮星使用中文名称优先，其余使用星表固有名。

右侧固定“拍摄信息”栏容纳原先预览下方的视场/姿态、光照、日月、星空、主动朝向及近似说明；预览保留画面与构图操作，版权署名统一由 About 提供。信息栏可收起以扩大工作区，窄屏通过“拍摄信息”按钮打开抽屉，关闭/切换面板不修改计划。目标列表独立滚动，不挤压取景框。细化范围见[本轮计划](../plan/constellations-and-info.md)。

- 侧栏“星空”控制亮星与金星、木星；“银河”独立控制银河亮云、暗尘带和银心参考点，默认均关闭。银河外观来自全天全景衍生纹理，首次开启按需加载；加载和失败信息直接显示在预览中，搜索或收起右栏仍能看到，关闭再开启可重试，其他图层保持可用。深空天体见下节；空间站的轨道历元、更新状态与短轨迹见上文。
- 星空绘制真实亮星方向，重点显示北极星、牛郎星、织女星、金星和木星名称；取景框外显示主要目标状态并提供主动朝向。银河开启时显示银心状态和“朝向银心”，银心位于地平线下时不自动居中。
- 右侧银河分组提供 25%—200% 的“对比度”滑杆与重置按钮，默认 100%，图层关闭时滑杆禁用。关闭图层保留数值，收起侧栏和交换面板不重置。该值仅调节银河纹理外观，白昼仍淡出、强月光仍减弱，星点与银心定位符号保持原样。
- 星点与银河接受地形遮挡，名称随遮挡隐藏。星点与银河全景衍生外观为构图参考，不将固定符号大小、摄影拼接细节、白昼参考点或显示亮度解释为精确天体位置或实拍结果。许可、原图署名与改动说明放在 About 及第三方许可中。
- 星点与银河轮廓按暮光和月光作明暗近似：白昼淡出，暗星更早消失，强月光时减少暗星并减弱银河。状态区说明原因；图层开启但天空较亮时保留目标方向及主动朝向。名称随星点隐藏，明暗隐藏不标为山体遮挡。
- 银心空心环与名称始终是方向参考，不代表黑洞或银河实际可见；轮廓淡出时仍按地平线、视场和 DEM 遮挡显示。显示月亮的开关不关闭月光影响。

## 12. 深空轮廓与改机对比

本轮扩展 M20、M33、玫瑰和马头，继续复用“深空天体”开关、右栏搜索、明确朝向与相机响应选项。目标逐一显示加载/失败状态；某个资料失败不把其他已加载目标标成失败。资料已经增强 Hα、覆盖有限或仅提供暗区对比近似时，在目标信息中说明。马头以暗轮廓和发射背景共同呈现，星表恒星仍独立显示，不将其暗区解释为对所有恒星的真实遮挡。范围见[四目标计划](../plan/deep-sky-next-four.md)。

- 左侧“深空天体”独立开关默认关闭；开启按需加载 8 个目标轮廓。右侧列出名称、目录角尺寸与状态，中文名或图录编号可搜索，明确点击才朝向；搜索和加载失败提示彼此独立。
- 相机参数提供“深空相机响应”，默认“未改机 · 近似参考”，可切换“天文改机 · Hα 增强示意”。未改机保留基础色彩，改机额外增加定性红色结构；保留时间、机位、焦距和其他图层，星系、星团不统一泛红。不模拟具体机型或曝光。
- 轮廓按实际角范围投影，中心在框外仍可部分入画；被山体挡住时裁切发光区域，区分部分/全部遮挡与像素不足。中心被遮挡时隐藏名称。白昼或强月光继续减弱扩散外观，“天空较亮”不写成山体遮挡。
- 加载、超时与失败只影响深空结构，关闭再开启可重试；保留地形和其他天体。来源署名和衍生数据下载持续可用。模型与验收见[深空首步](../plan/deep-sky.md)。

现有八个深空目标均显示影像结构，保留来源完整可用覆盖，不叠加椭圆遮罩或目录外壳。不增加额外开关，近似参考与增强示意由预览信息条标注；About 持续提供各幅影像的完整署名和各自许可。加州采用可见光资料；心脏/灵魂保留上游去星结构，不将有限分辨率包装成无限细节。见[剩余目标](../plan/deep-sky-remaining.md)。透明度随亮度连续变化，M45 反射云不因改机泛红。参考影像有明确的数据覆盖边界，照片中的星点只供外观参考，不作为新星历。M45/M8/北美保留原图细节，长焦不再显示整图强滤波后的光斑；仍受原始分辨率、设备纹理上限与色彩处理限制，未作具体相机定标。三图以来源扩散光结构控制透明度，外围照片星场淡出，减弱矩形覆盖痕迹；星云内部仍可保留参考照片星点。见[清晰度修正](../plan/deep-sky-sharpness.md)与[边界融合](../plan/deep-sky-boundary.md)。

两模式沿用已处理的源图，界面明确说明不是同一器材的实拍对比。未改机仍保留基础红色；Hα 增强只增加红光示意，不表示真实谱线、具体机型色彩或曝光结果。色彩核查见[审计记录](../plan/deep-sky-colour-audit.md)。

## 13. 流星雨

- 左栏“流星雨”图层默认关闭。开启后列出拍摄时刻处于 IMO 工作表活动期的流星雨，并在预览中以带放射线的圆环标出辐射点；名称被山体遮挡时隐藏，与其他天空标签相同。
- 右栏“流星雨”分组：
  - “预估密度”开关从属于图层，没有时长设置，直接按拍摄时刻所在的整晚累计：机位地方平太阳时正午到次日正午之间、太阳低于 −18° 的时段，凌晨的拍摄时刻仍属前一晚。
  - 开启后，预览按后期对齐叠加的成片画出示意流星：相机整晚固定在当前构图连续拍摄，含流星的帧按星空对齐到拍摄时刻（锚点帧）后贴回，因此流星都从拍摄时刻的辐射点发散。信息条显示整晚暗夜时长与画面内约多少颗。
  - 在同一夜内移动拍摄时刻只改变锚点，暗夜范围不变。
  - 分组列出整晚数量、带日期的暗夜起止、分流星雨数量和条件，并逐个给出辐射点方位、当前 ZHR、距极大天数和“朝向”按钮。
- 示意流星是固定样本，不表示实际会出现的位置或亮度。数量为量级参考，只计出现时在固定画面内、对齐后仍在画面内且在地平线以上的流星，离拍摄时刻越远、焦距越长，对齐后的有效天区越小；未计山体遮挡、云量和散发流星；光污染只在开启且读取成功时计入，否则写明“按自然天空”。来源、权利与模型集中在 About。详见[流星雨计划](../plan/meteor-showers.md)。

## 14. 彗星

- 左栏“彗星”图层默认关闭。开启后在预览中绘制拍摄时刻收录彗星的彗核、离子尾和尘埃尾，并标注名称与星等；彗核被山体遮挡时隐藏名称，彗尾随天空一起被地形遮住。
- 彗尾长度按暗夜长曝光口径：由日心星等估算物理长度，再按日、彗、地的实际三维位置投影到画面，指向或背向观察者时自然缩短，并随焦距缩放。离子尾笔直、偏蓝；尘埃尾弯曲、偏黄，长度取离子尾的一半，且不超过约 4500 万 km。
- 暮光、月光与光污染使天空变亮时，彗尾从末端开始变淡，可见长度随之缩短；白昼不显示彗尾。
- 右栏“彗星”分组：
  - 只列出亮于 12 等的彗星，按亮度排序；逐颗给出方位与视高度、星等（观测夜以外标“外推”）、离子尾与尘埃尾长度（天空偏亮时同时给出当前可见长度与暗夜长度）、日距与地距、彗发大小和“朝向”按钮。
  - 天空偏亮时说明比暗夜亮多少、彗尾约显示前百分之几；没有彗星处于回归期、或都暗于 12 等时分别提示。
  - 彗星目录随站点每 3 小时自动检查一次，分组末尾显示“目录更新于”。读取中、读取失败（带“重试”）、超过 1 天未更新、自动更新已暂停分别提示；后两种情况下继续使用已有目录，并说明新发现或新近变亮的彗星可能缺失。
  - 分组末尾说明长度口径、亮度来源、收录范围与数据快照日期。
- 彗星亮度与彗尾都是构图参考：亮度可能有 1 等以上出入，不预测爆发、碎裂与前向散射；彗尾亮度、宽度与颜色只作示意。来源、许可与模型集中在 About。详见[彗星计划](../plan/comets.md)。
