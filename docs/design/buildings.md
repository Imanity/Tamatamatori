# 建筑体块交互

左侧“图层”增加默认关闭的“建筑”，设置按钮展开右侧同名分组。移动端沿用同一图层入口。开启后读取当前机位附近有限范围，不改变地图浏览状态、拍摄时间或机位。

右栏显示数据状态、近景约 2 km、远景至约 5 km 的加载范围与远景至少 20 m 的高度筛选、来源版本、体块与高度近似；有范围/资源截断时明确提示。无建筑要素表示来源在所取区域未返回建筑，不能解释成实地没有建筑。失败可单独重试，地形和天空继续绘制，建筑遮挡读数暂不可用。关闭后释放当前建筑 GPU 网格，恢复纯 DEM 遮挡。

加载期间不弹出覆盖画面的进度文字。换机位立即停绘旧建筑，旧遮挡状态失效；同机位转向、调焦不重建网格，保持交互连续。建筑开启后的天体状态称为“已载场景”遮挡，不能等同于整条视线已确认无建筑。详细署名继续进入 About，不占用取景高度。

右栏的“已读取瓦片”表示来源扫描数量，“分块体块”以入选/候选显示；达到预算时给出省略分部数。采用跨瓦片高层优先与周边均衡分配，不能把读取所有瓦片解释为完整绘制。关闭和失败继续使用各自状态，转向调焦沿用同一批几何。

远景单列入选/候选分部数；远景预留份额会减少近处普通房屋的显示数量。缓存只保存建筑图层，重开仍需重新生成网格和采样基座，不能描述为立即恢复或整体离线。5 km 外未加载，高纬瓦片上限及来源缺失仍明确反馈。

晴空塔在约 50 km 内随“建筑”自动应用无纹理精细模型，不另加重复开关。普通建筑仍限周边五公里。右栏显示地标距离，并分别说明应用成功、模型失败回退或源分部对应关系未确认；近处失败保留粗体块，远处失败说明该距离未加载对应粗体块，沿用“重新读取建筑”恢复。三角面与网格量包含地标，显示全场 300,000 面上限；普通体块候选/入选数不把地标模型算作一个源分部。有限预算下继续展示不完整提示。加载距离不保证实际可见，地形、已载建筑和雾仍生效。作者、许可、处理说明及衍生模型下载集中于 About。无纹理不提供玻璃透光、灯光或实景测绘精度。
